استخدم هذه النظرة العامة عندما تحتاج إلى اختيار دليل الموفر الذي يتوافق مع الإعداد الخاص بك. ExtraBrain يدعم موفري المفاتيح API، وأوضاع موفر الاشتراك، ونقاط النهاية OpenAI-compatible المخصصة.

![ExtraBrain منتقي موفر الذكاء الاصطناعي](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## الوجبات السريعة الرئيسية

يعد موفر ExtraBrain AI هو المسار النموذجي الذي يستخدمه التطبيق عندما يقوم بتحويل النص أو المطالبة أو لقطة الشاشة أو سياق الجلسة إلى تحليل مباشر.

- ExtraBrain يدعم Google Gemma 4 الذكاء الاصطناعي المحلي، OpenAI، Anthropic، Claude الاشتراك، Codex الاشتراك، ونقاط النهاية OpenAI-compatible المخصصة.
- تتطلب أوضاع المفاتيح API بيانات اعتماد الموفر الحالي؛ تستخدم أوضاع الاشتراك مسار الاشتراك الذي تم تسجيل الدخول إليه والذي يدعمه التطبيق.
- يجب اختبار التحقق من صحة الموفر مرة واحدة قبل إجراء مقابلة مباشرة أو اجتماع أو محاضرة أو مكالمة بحثية.
- يتم التحكم في فواتير الموفر والاحتفاظ به والوصول إلى النموذج والحصة بواسطة حساب الموفر الذي تختاره.

## قائمة التحقق من إعداد الموفر

1. قرر ما إذا كنت تريد وضع المفتاح API أو وضع الاشتراك أو نقطة نهاية مخصصة.
2. افتح **الإعدادات -> LLM موفري الخدمة**.
3. أدخل تفاصيل المزود المطلوبة.
4. التحقق من صحة أو إعادة فحص اتصال الموفر.
5. تشغيل تحليل اختبار واحد.
6. قم بمراجعة [كيفية تعامل ExtraBrain مع البيانات](/ar/help/privacy-security/how-extrabrain-handles-data/) قبل استخدام السياق الحساس.

## أسئلة المزود

### هل أحتاج إلى مفتاح API لكل وضع مزود؟

رقم OpenAI وAnthropic API تتطلب أوضاع المفاتيح مفاتيح. يستخدم وضعا الاشتراك Claude وCodex الوصول إلى الاشتراك ولا يتطلبان مفتاح API في ExtraBrain.

### ما الذي يجب علي التحقق منه في حالة فشل التحقق من صحة الموفر؟

قم بتأكيد المفتاح والوصول إلى النموذج وعنوان URL الأساسي وحالة الاشتراك والوصول إلى الشبكة. تحتاج نقاط النهاية المخصصة أيضًا إلى اسم النموذج الدقيق الذي تتوقعه نقطة النهاية.
