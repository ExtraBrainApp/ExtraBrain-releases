يستخدم ExtraBrain موفر الذكاء الاصطناعي الذي تحدده للتحليل المباشر. يتحكم إعداد الموفر في المكان الذي قد يتم فيه إرسال المطالبات وسياق النص والسياق المشتق من لقطة الشاشة.

![منتقي موفر الذكاء الاصطناعي في ExtraBrain الإعداد](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## أوضاع الموفر العام

- OpenAI API مفتاح.
- Anthropic API مفتاح.
- Codex الاشتراك باستخدام ChatGPT Plus أو Pro مباشرة، بدون مفتاح API.
- Claude الاشتراك باستخدام Claude Pro أو Max مباشرة، بدون مفتاح API.
- نقطة نهاية OpenAI-compatible مخصصة مع عنوان URL الأساسي ومفتاح API واسم الطراز.

## قائمة التحقق من الإعداد

1. افتح الإعداد أو **الإعدادات -> LLM مقدمو الخدمة**.
2. اختر عائلة المزود.
3. اختر مفتاح API أو وضع الاشتراك.
4. أدخل بيانات الاعتماد عند الحاجة.
5. التحقق من صحة الاتصال أو إعادة فحصه.
6. قم بإجراء تحليل اختبار قصير.

![LLM علامة تبويب إعدادات الموفرين](/assets/screenshots/help/dark/settings-llm-providers.png)

## تدفق البيانات

عندما تطلب من ExtraBrain إجراء تحليل مع موفر السحابة، قد يتم إرسال المطالبات ذات الصلة وسياق النص والسياق المشتق من لقطة الشاشة والأسئلة المخصصة إلى هذا الموفر. تخضع فواتير الموفر، والاحتفاظ به، والحصص، وضوابط الحساب للمزود الذي تختاره.

## أسئلة موفر الذكاء الاصطناعي

### ما هو مزود الذكاء الاصطناعي الذي يجب أن أختاره أولاً؟

اختر المزود الذي تثق به بالفعل ويمكنك التحقق من صحته قبل الجلسة الحقيقية. بالنسبة لمعظم المستخدمين، يعني ذلك البدء بحساب OpenAI أو Anthropic أو Claude أو Codex موجود.

### هل يمكنني الاحتفاظ بأكثر من مسار مزود واحد جاهزًا؟

نعم. يعد الاحتفاظ بمسار موفر النسخ الاحتياطي مفيدًا قبل المقابلات أو الاجتماعات حيث يمكن أن تتغير الحصة النسبية أو الوصول إلى الشبكة أو حالة الحساب.
