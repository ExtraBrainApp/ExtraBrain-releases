ExtraBrain يدعم وضع المفتاح OpenAI API ووضع الاشتراك Codex.

## OpenAI API وضع المفتاح

استخدم هذا الوضع عندما تريد أن يتصل ExtraBrain بـ OpenAI من خلال مفتاح API الذي تديره.

1. افتح **الإعدادات -> LLM موفري الخدمة**.
2. حدد **OpenAI**.
3. الصق مفتاح API الخاص بك.
4. اختر النموذج وجهد الاستدلال عندما يكون ذلك متاحًا.
5. التحقق من صحة المفتاح.
6. قم بإجراء تحليل قصير للتأكد من أن الإجابات تأتي من OpenAI.

![OpenAI نموذج موفر الخدمة](/assets/screenshots/help/dark/onboarding-openai-provider-form.png)

## Codex وضع الاشتراك

استخدم اشتراك Codex عندما تريد ExtraBrain استخدام اشتراك ChatGPT Plus أو Pro مباشرةً. لا يتطلب هذا الوضع مفتاح API في ExtraBrain.

1. افتح **الإعدادات -> LLM موفري الخدمة**.
2. اختر **Codex الاشتراك**.
3. إعادة التحقق من حالة تسجيل الدخول.
4. اختر النموذج المتاح.
5. قم بإجراء تحليل الاختبار.

## استكشاف الأخطاء وإصلاحها

إذا فشلت عملية التحقق من الصحة، فتأكد من أن المفتاح محدث، ولديه حق الوصول إلى النموذج الذي حددته، وأنه غير محظور بواسطة وكيل أو سياسة مؤسسة. بالنسبة لوضع الاشتراك، تأكد من أن بيئة سطح المكتب يمكنها الوصول إلى أدوات الموفر الذي تم تسجيل الدخول إليه.

## OpenAI وCodex الأسئلة

### هل أحتاج إلى مفتاح OpenAI API لوضع الاشتراك Codex؟

لا. يستخدم وضع الاشتراك Codex الوصول إلى اشتراك ChatGPT Plus أو Pro مباشرة ولا يتطلب مفتاح OpenAI API في ExtraBrain.

### ما الذي يمكن أن يرسله ExtraBrain إلى OpenAI أو Codex؟

عند تحديده للتحليل، قد يرسل ExtraBrain مطالبات وسياق نص وسياق مشتق من لقطة الشاشة والأسئلة المخصصة اللازمة للاستجابة.
