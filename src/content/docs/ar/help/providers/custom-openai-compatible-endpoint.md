استخدم نقطة نهاية OpenAI-compatible مخصصة عندما يكشف الموفر أو الوكيل لديك عن نمط OpenAI API.

![ExtraBrain إعدادات موفر OpenAI-compatible المخصصة مع حقول عنوان URL الأساسي واسم النموذج](/assets/screenshots/help/dark/settings-custom-provider.png)

## الحقول المطلوبة

| مجال | ما يجب إدخاله |
| --- | --- |
| عنوان URL الأساسي | عنوان URL الأساسي للموفر أو الوكيل API. |
| مفتاح API | المفتاح المطلوب بواسطة نقطة النهاية تلك. |
| اسم النموذج | معرف النموذج الدقيق الذي تتوقعه نقطة النهاية. |

## خطوات الإعداد

1. افتح الإعداد أو **الإعدادات -> LLM مقدمو الخدمة**.
2. اختر خيار الموفر المخصص.
3. أدخل عنوان URL الأساسي.
4. أدخل المفتاح API.
5. أدخل اسم النموذج.
6. التحقق من صحة التكوين.
7. قم بإجراء تحليل اختبار قصير.

## الأخطاء الشائعة

- مفقود `/v1` عندما يتوقعه الموفر.
- استخدام اسم عرض النموذج بدلاً من معرف النموذج API.
- لصق مفتاح للموفر أو الوكيل الخطأ.
- نسيان أن قواعد الاحتفاظ بالمزود والفوترة والوصول يتم التحكم فيها بواسطة مشغل نقطة النهاية المخصص.

يمكن أن تتضمن طلبات الموفر المخصص المطالبات وسياق النص وسياق مشتق من لقطة الشاشة والأسئلة المخصصة.

## أسئلة نقطة النهاية المخصصة

### ما الذي يجعل نقطة النهاية OpenAI-compatible؟

يجب أن تقبل نقطة النهاية طلبات OpenAI-style API للدردشة أو الاستجابات باستخدام عنوان URL الأساسي والمفتاح واسم النموذج الذي تدخله في ExtraBrain.

### ما الذي يجب أن أختبره بعد حفظ نقطة النهاية المخصصة؟

قم بإجراء تحليل قصير باستخدام نص غير حساس أو سياق لقطة شاشة. تأكد من أن نقطة النهاية تُرجع استجابة وأن اسم النموذج يطابق ما يتوقعه المزود أو الوكيل.
