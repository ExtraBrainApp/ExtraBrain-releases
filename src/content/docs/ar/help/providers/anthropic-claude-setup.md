ExtraBrain يدعم وضع المفتاح Anthropic API ووضع الاشتراك Claude.

## Anthropic API وضع المفتاح

استخدم هذا الوضع عندما تريد أن يتصل ExtraBrain بـ Anthropic من خلال مفتاح API الذي تديره.

1. افتح **الإعدادات -> LLM موفري الخدمة**.
2. حدد **Anthropic**.
3. الصق مفتاح Anthropic API الخاص بك.
4. اختر النموذج.
5. التحقق من صحة المفتاح.
6. قم بإجراء تحليل اختبار قصير.

![LLM علامة تبويب إعدادات الموفرين مع تحديد Anthropic](/assets/screenshots/help/dark/settings-llm-providers.png)

## Claude وضع الاشتراك

استخدم اشتراك Claude عندما تريد ExtraBrain أن يستخدم Claude Pro أو اشتراك Max مباشرة. لا يتطلب هذا الوضع مفتاح API في ExtraBrain.

1. افتح **الإعدادات -> LLM موفري الخدمة**.
2. اختر **Claude الاشتراك**.
3. إعادة التحقق من حالة تسجيل الدخول.
4. اختر النموذج المتاح.
5. قم بإجراء تحليل الاختبار.

## استكشاف الأخطاء وإصلاحها

في حالة فشل التحقق من الصحة، تأكد من أن المفتاح API ينتمي إلى حساب Anthropic الصحيح، ولديه حق الوصول إلى النموذج، ويتم لصقه بدون مسافات إضافية. بالنسبة إلى وضع الاشتراك، تأكد من أن اشتراكك في Claude نشط وقم بتسجيل الدخول في المكان الذي يتوقعه ExtraBrain.

## Anthropic وClaude الأسئلة

### هل أحتاج إلى مفتاح Anthropic API لوضع الاشتراك Claude؟

رقم Claude وضع الاشتراك مخصص لـ Claude Pro أو الوصول إلى الاشتراك الأقصى ولا يتطلب مفتاح Anthropic API داخل ExtraBrain.

### ما هي البيانات التي يمكن إرسالها إلى Anthropic أو Claude؟

عند تحديده للتحليل، قد يتم إرسال المطالبات ذات الصلة وسياق النص والسياق المشتق من لقطة الشاشة والأسئلة المخصصة إلى Anthropic أو Claude وفقًا لوضع الموفر هذا.
