تم تصميم نافذة ExtraBrain الرئيسية حول التسجيل وسياق النص ولقطات الشاشة والتحليل.

![ExtraBrain نافذة رئيسية خاملة مع عناصر تحكم مباشرة](/assets/screenshots/help/dark/main-idle-controls.png)

## الضوابط الرئيسية

| يتحكم | ماذا يفعل |
| --- | --- |
| ابدأ التسجيل | يبدأ جلسة مباشرة ويبدأ في التقاط مصادر الصوت الممكنة. |
| قف | ينهي الجلسة النشطة. |
| بسأل | يرسل السياق الحالي إلى موفر الذكاء الاصطناعي المحدد لتحليله. |
| يأسر | إضافة لقطة شاشة إلى الجلسة النشطة. |
| توسيع أو طي | التبديل بين تخطيطات النوافذ المدمجة والموسعة. |

## سير العمل الأساسي

1. افتح ExtraBrain قبل بدء المكالمة.
2. انقر **بدء التسجيل**.
3. انتظر إدخالات النص أو بطاقات المواضيع المكتشفة.
4. انقر فوق **التقاط** إذا كان سياق الشاشة مهمًا.
5. انقر **اسأل** لطلب التحليل.
6. استخدم المتابعات أو اكتب سؤالاً مخصصًا.

![ExtraBrain تسجيل بالموضوع المكتشف](/assets/screenshots/help/dark/main-recording-topic.png)

## عندما يتم تعطيل الأزرار

يمكن تعطيل الأزرار أثناء بدء تشغيل ExtraBrain أو إيقافه أو تحليله أو التحقق من صحة وصول الموفر أو انتظار الإذن المطلوب وحالة الجلسة. إذا ظل الزر معطلاً، فحدد [استكشاف الأخطاء وإصلاحها](/ar/help/troubleshooting/).

قبل الجلسات المهمة، قم بمراجعة [إعدادات الصوت](/ar/help/settings/audio-settings/)، [إعدادات لقطة الشاشة](/ar/help/settings/screenshot-settings/)، و[الملفات الشخصية](/ar/help/settings/profiles/).

## تذكير الخصوصية

عند النقر فوق **اسأل** مع تحديد موفر السحابة LLM، قد يتم إرسال نص النص ذي الصلة والسياق المشتق من لقطة الشاشة والمطالبات والأسئلة المخصصة إلى هذا الموفر.

## أسئلة التسجيل

### متى يجب علي النقر فوق "اسأل"؟

انقر فوق **اسأل** بعد توفر سياق نص مفيد أو موضوع تم اكتشافه أو سؤال تم اكتشافه أو لقطة شاشة. يمكنك أيضًا أن تسأل مع الحد الأدنى من السياق للحصول على مطالبة سريعة.

### ماذا يحدث عندما أتوقف عن التسجيل؟

ExtraBrain ينهي الجلسة النشطة. يمكن أن يحتفظ سجل الجلسة المحلية بالنصوص والتحليلات ولقطات الشاشة والحقائق والإدخالات ما لم تقم بحذف تلك الجلسة لاحقًا.
