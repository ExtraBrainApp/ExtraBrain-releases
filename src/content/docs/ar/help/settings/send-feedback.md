استخدم **الإعدادات -> التعليقات** لإرسال تعليقات المنتج أو تقارير الأخطاء أو سياق الدعم من داخل ExtraBrain.

![ExtraBrain إعدادات التعليقات مع الرسائل وحقول البريد الإلكتروني الاختيارية](/assets/screenshots/help/dark/settings-feedback.png)

## ما يجب تضمينه

| مجال | توصية |
| --- | --- |
| رسالة ردود الفعل | قم بوصف ما حدث، وما كنت تتوقعه، وسير العمل الذي كنت تستخدمه. |
| البريد الإلكتروني الاختياري | أضف بريدًا إلكترونيًا إذا كنت تريد الدعم للمتابعة. |

بالنسبة للأخطاء، قم بتضمين منطقة الميزات والموفر ووضع النسخ وحالة الإذن macOS وما إذا كانت المشكلة قد حدثت أثناء الإعداد أو التسجيل أو التحليل أو لقطات الشاشة أو الإعدادات.

## قبل إرسال التفاصيل الحساسة

لا تلصق مفاتيح API أو مطالبات المقابلة الخاصة أو بيانات العميل أو لقطات الشاشة السرية في التعليقات. إذا كان الدعم يحتاج إلى مزيد من التفاصيل، فلا تشارك سوى الحد الأدنى من السياق المطلوب لإعادة إظهار المشكلة.

## الأسئلة الشائعة

### هل البريد الإلكتروني مطلوب؟

لا، البريد الإلكتروني اختياري، ولكن إضافته تجعل المتابعة ممكنة.

### ما الذي يجعل تقرير الأخطاء مفيدًا؟

قم بتضمين خطوات إعادة الإنتاج، والسلوك المتوقع، والسلوك الفعلي، وإعدادات Provider/transcription، وما إذا كانت المشكلة قد بدأت بعد التحديث.
