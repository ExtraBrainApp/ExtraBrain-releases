يتم تنظيم إعدادات ExtraBrain حسب منطقة سير العمل. افتح الإعدادات من النافذة الرئيسية، ثم اختر علامة التبويب التي تريدها.

![ExtraBrain علامة تبويب الإعدادات العامة](/assets/screenshots/help/dark/settings-general.png)

## علامات تبويب الإعدادات العامة

| فاتورة غير مدفوعة | ما يتحكم فيه |
| --- | --- |
| عام | [السياق الشخصي، ولغة الترميز المفضلة، والتحليل الموسع، وسلوك عرض التحليل الأخير](/ar/help/settings/general-context-language/). |
| الملفات الشخصية | [المساعد، والبرمجة، وتصميم النظام، والسلوك، والاجتماع، وسلوك الملف الشخصي المخصص](/ar/help/settings/profiles/). |
| UI | [حجم الخط، والتعتيم، والإعدادات المسبقة للمظهر، والنصائح، وموضوع كتلة التعليمات البرمجية](/ar/help/settings/ui-appearance/). |
| الاختصارات | التسجيل، ولقطات الشاشة، والتحليل، والمتابعة، وعناصر التحكم في النوافذ، واختصارات النقر والتمرير. |
| صوتي | [موفر النسخ، مفتاح Deepgram، جهاز الميكروفون، تنظيف النص، ومشغل الصوت](/ar/help/settings/audio-settings/). |
| لقطة الشاشة | [التقاط النافذة النشطة مقابل التقاط ملء الشاشة والتقاطها قبل التحليل](/ar/help/settings/screenshot-settings/). |
| تتبع كاميرا الويب | [عناصر التحكم في التواجد التجريبي وتتبع النظرات](/ar/help/settings/webcam-tracking-experimental/) عند عرضها في الإصدار الحالي. |
| LLM مقدمي الخدمة | OpenAI، Anthropic، Claude الاشتراك، Codex الاشتراك، وإعداد نقطة النهاية المخصصة. |
| الجلسات | سجل الجلسة المحلية والنصوص والتحليلات والحقائق ولقطات الشاشة والحذف. |
| خصوصية | حماية لقطة الشاشة، ورؤية التطبيق، والنقر، وتأخير التمرير، ومشاركة الاستخدام. |
| التحديثات | [تفضيل التحديث التلقائي](/ar/help/settings/automatic-updates/). |
| رخصة | Pro تنشيط الترخيص وحالته وإلغاء تنشيطه. |
| تعليق | [رسالة التعليقات والبريد الإلكتروني الاختياري وحالة الإرسال](/ar/help/settings/send-feedback/). |

علامة التبويب "عن بعد" مخصصة للتطوير فقط ولا يجب توثيقها كميزة عامة.

## أسئلة الإعدادات

### ما هي الإعدادات التي يجب أن أتحقق منها قبل الجلسة المباشرة؟

تحقق من الصوت وموفري LLM ولقطات الشاشة والخصوصية والاختصارات. تتحكم علامات التبويب هذه في الالتقاط والموفر وسياق الشاشة والرؤية وسلوك الأمر الذي من المرجح أن يؤثر على سير العمل المباشر.

### هل يجب أن أقوم بتوثيق أو استخدام علامة التبويب "الإعدادات عن بعد"؟

لا. علامة التبويب "عن بعد" مخصصة للتطوير فقط ولا ينبغي معاملتها كميزة عامة لمركز المساعدة.
