استخدم **الإعدادات -> الصوت** لاختيار سلوك النسخ وإدخال الميكروفون.

![ExtraBrain إعدادات الصوت مع موفر النسخ وعناصر التحكم في الميكروفون](/assets/screenshots/help/dark/settings-audio.png)

## ضوابط الصوت

| يتحكم | ما يتغير |
| --- | --- |
| مزود خدمة تحويل الكلام إلى نص | النسخ السحابي المحلي Parakeet أو Deepgram. |
| Deepgram API مفتاح | مطلوب فقط عند تحديد Deepgram. |
| مصدر الصوت | إدخال الميكروفون المفضل. |
| الزناد الصوتي | التحكم في العبارة المنطوقة لبدء التحليل أثناء الجلسة النشطة. |
| تنظيف النص | إزالة كلمة الحشو قبل بطاقات النصوص والتحليل. |
| إذن صوت النظام | macOS تدفق الإذن لالتقاط صوت التطبيق/system عند الحاجة. |

## ملحوظات

- تنطبق تغييرات جهاز الصوت على الجلسات الجديدة.
- يحتفظ Parakeet المحلي بالنسخ المحلي.
- يرسل Deepgram الصوت إلى Deepgram للنسخ.
- قد يحتاج ExtraBrain إلى macOS أذونات صوت الميكروفون والنظام قبل أن يعمل التسجيل.

## الأسئلة الشائعة

### لماذا يقول ExtraBrain أنه لم يتم العثور على أي أجهزة؟

ربما لم يمنح macOS إذن الميكروفون بعد، أو قد يكون الإدخال المحدد غير متاح. امنح الإذن، وأعد توصيل الميكروفون، ثم ابدأ جلسة جديدة.

### هل يؤثر تبديل موفري النسخ على الجلسة الحالية؟

تكون تغييرات الموفر والجهاز أكثر أمانًا عند تطبيقها قبل بدء الجلسة. أوقف التسجيل وابدأ جلسة جديدة بعد إجراء تغييرات صوتية كبيرة.
