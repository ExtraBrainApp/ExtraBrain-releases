## Supported platform

ExtraBrain currently supports **macOS** on Apple Silicon and Intel Macs. Windows and Linux are planned, not current release targets.

Use the current Mac release when you need a desktop AI interview assistant, local-first meeting copilot, local transcription workflow, or provider-connected live assistant. Confirm hardware support before assuming on-device AI is available.

## Install from GitHub Releases

1. Open the [ExtraBrain download page](/download/).
2. Download the current macOS build.
3. Open the downloaded installer or app bundle.
4. Move the app into your Applications folder if the release instructions call for it.
5. Launch ExtraBrain once to confirm the app opens cleanly.

## First launch checklist

- Confirm the app window renders normally.
- Confirm you can reach settings.
- Confirm any required microphone or accessibility prompts are completed.
- Confirm the release version matches what you expected to install.
- Review the current release notes for any published checksum, signing, or notarization details if your environment requires them.
- Confirm local transcription or optional Deepgram settings before a live call.
- Confirm on-device AI availability or provider access before relying on live answers.

:::caution
Do not wait until five minutes before an interview to install the app for the first time. Test the release, permissions, local AI availability, and provider setup well before the live session.
:::

Move to [Set up AI providers](/help/setup-api-keys/) and then [Getting started](/help/getting-started/) if you have not already done that.

## Common installation questions

### Where should I download ExtraBrain?

Use the [ExtraBrain download page](/download/), which points to the latest official GitHub release and release metadata.

### Does ExtraBrain support Windows or Linux?

Not today. ExtraBrain is available for Mac today, including Apple Silicon and Intel Macs. Windows and Linux are planned.

### Should I test ExtraBrain before an interview?

Yes. Launch the app, grant permissions, test transcription, verify local AI or provider routing, and run a short rehearsal before any high-stakes session.
