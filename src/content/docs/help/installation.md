## Supported Platform

ExtraBrain is macOS-first today. Windows and Linux are planned, not current public release targets.

Use the official macOS release when you need the desktop overlay, live recording controls, local session history, screenshot context, and provider setup described in this help center.

![ExtraBrain onboarding welcome screen after installation](/assets/screenshots/help/dark/onboarding-welcome.png)

## Install From GitHub Releases

1. Open the [ExtraBrain download page](/download/).
2. Download the current macOS build.
3. Open the downloaded installer or app bundle.
4. Move the app into Applications if the release instructions call for it.
5. Launch ExtraBrain.

## First Launch Checklist

- Complete onboarding.
- Grant microphone, Screen Recording, and system audio permissions.
- Choose Local Parakeet or Deepgram transcription.
- Connect OpenAI, Anthropic, Claude Subscription, Codex Subscription, or a custom OpenAI-compatible endpoint.
- Run one short test session before using ExtraBrain in a real interview or meeting.

If macOS blocks microphone or screen access, open [Grant macOS permissions](/help/getting-started/macos-permissions/) and follow the System Settings recovery steps.

:::caution
Do not wait until five minutes before an interview to install the app for the first time. Test the release, permissions, transcription, and provider setup well before the live session.
:::

## Installation Questions

### Where should I download ExtraBrain?

Use the official [ExtraBrain download page](/download/). It points to the current macOS release and avoids stale third-party builds.

### What should I test after installing ExtraBrain?

Start a short session, confirm transcription appears, capture one screenshot, run one analysis, and verify the response uses the provider you selected.
