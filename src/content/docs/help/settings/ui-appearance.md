Use **Settings -> UI** to tune how ExtraBrain looks during repeated live use.

![ExtraBrain UI settings with appearance and code theme controls](/assets/screenshots/help/dark/settings-ui.png)

## Appearance Controls

| Control | What It Changes |
| --- | --- |
| Font size | Text density across the app. |
| Opacity | Main window transparency. |
| Appearance presets | Window color palette. |
| Tips | Whether in-app tips appear. |
| Code block theme | Syntax highlighting style for code shown in answers. |

## Recommended Setup

1. Choose a font size you can read quickly under pressure.
2. Keep opacity high if you take documentation screenshots or need maximum legibility.
3. Pick an appearance preset that works over the apps you use most.
4. Choose a code block theme that keeps syntax readable in your current light or dark workflow.
5. Disable tips once you know the core controls.

Opacity and appearance affect visibility. They do not change what ExtraBrain stores locally or what may be sent to your selected providers during analysis.

## Common Questions

### Should I lower opacity during interviews or meetings?

Only if it helps you keep context visible. For readability, screenshots, and reduced visual noise, 100% opacity is usually better.

### Does the code block theme affect the model response?

No. It only changes how code is displayed in the app.
