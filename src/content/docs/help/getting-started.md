## Recommended Setup Order

1. Read the product overview if you are new to ExtraBrain.
2. Complete onboarding.
3. Grant microphone, screen recording, and system audio permissions.
4. Choose Local Parakeet or Deepgram transcription.
5. Connect the AI provider you want ExtraBrain to use for analysis.
6. Run a short test session before a real interview or meeting.

## Getting Started Questions

### What is the fastest way to start using ExtraBrain?

Complete onboarding, choose Local Parakeet transcription, connect one AI provider, then test recording and analysis with a short non-sensitive session.

### What should I configure before a live interview or meeting?

Confirm permissions, microphone behavior, transcription provider, AI provider validation, screenshot capture, and the privacy controls you plan to use.
