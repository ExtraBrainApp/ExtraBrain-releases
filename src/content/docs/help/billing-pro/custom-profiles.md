Custom profiles are a Pro feature for saving reusable prompt guidance. Use them when a built-in profile is close but you want more specific behavior. ExtraBrain Pro is $9.99/month ($6.99 Founder), $79/year, or $149 Lifetime, with purchase and activation in **Settings -> License**.

![ExtraBrain profiles settings focused on custom profile Pro controls](/assets/screenshots/help/dark/settings-custom-profiles.png)

## What A Custom Profile Includes

| Field Or Control | Purpose |
| --- | --- |
| Name | Short label shown in the profile list and profile selector. |
| Description | Reminder of when to use the profile. |
| Prompt | Detailed guidance for how ExtraBrain should analyze and respond. |
| Enabled | Controls whether the custom profile is available. |
| Pin | Makes the profile the active pinned profile. |
| Delete | Removes the custom profile from local settings. |

## Profile Settings

Custom profiles can also control workflow behavior:

| Setting | Behavior |
| --- | --- |
| Expand window on analysis | Opens the expanded window when the profile starts analysis. |
| Start analysis after region screenshot | Runs analysis immediately after a region capture. |
| Use full session context | Gives each analysis more session history when that profile is active. |

## Setup Steps

1. [Activate ExtraBrain Pro](/help/billing-pro/activate-license/).
2. Open **Settings -> Profiles**.
3. Choose **Create Profile**.
4. Add a name, description, and prompt.
5. Configure profile settings.
6. Pin the profile if you want it active by default.

Custom profile text is stored in local settings. When you run cloud-provider analysis, relevant prompt guidance, transcript context, screenshot-derived context, and questions may be sent to the provider you selected.

## Common Questions

### Can I create custom profiles without Pro?

No. Free users can use the built-in system profiles. Creating and editing custom profiles requires Pro.

### What should I put in a custom profile prompt?

Describe the response style, constraints, and priorities you want ExtraBrain to follow. Keep it reusable and avoid secrets.
