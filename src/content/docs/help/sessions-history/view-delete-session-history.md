Open **Settings -> Sessions** to review saved local session history.

![ExtraBrain sessions settings tab](/assets/screenshots/help/dark/settings-sessions.png)

## What Session History Shows

Session history can include:

- session summaries
- transcript entries
- analyses
- facts
- screenshots
- entry counts and timestamps

## Delete A Session

1. Open **Settings -> Sessions**.
2. Select the session.
3. Click delete.
4. Confirm deletion.

Deletion removes the selected session history, including associated analyses, entries, screenshots, and facts.

## Why Delete May Be Disabled

Active sessions cannot be deleted. Stop recording first, then return to Settings -> Sessions.

## Privacy Note

Session history is local to your Mac. It can still contain sensitive transcripts or screenshot artifacts, so delete sessions you no longer want to keep.

## Session History Questions

### Can I delete an active ExtraBrain session?

No. Stop recording first, then return to **Settings -> Sessions**. Active sessions are protected so recording and persistence do not conflict with deletion.

### What is removed when I delete a session?

The selected local session record is removed with its transcripts, analyses, facts, screenshots, entries, and related counts.
