ExtraBrain's core Mac app can be used separately from provider billing. External provider usage costs are governed by the providers you choose, such as OpenAI, Anthropic, Deepgram, Claude, Codex, or a custom endpoint.

![ExtraBrain license settings tab](/assets/screenshots/help/dark/settings-license.png)

## Key Takeaways

ExtraBrain billing separates the Mac app workflow from external model and transcription accounts, so app access, Pro features, and provider usage should be reviewed as separate cost categories.

- The core Mac workflow is free to use.
- Provider costs are controlled by OpenAI, Anthropic, Deepgram, Claude, Codex, or the custom endpoint you connect.
- Pro is for workflow controls such as custom profiles and premium controls where enabled.
- Provider retention, logging, quota, and billing do not automatically change when you activate Pro.

## Free Core Product

The free core workflow covers the desktop app, local session flow, BYO provider setup, Local Parakeet transcription, screenshots, and basic live analysis controls. This is the right path when you want to use your own provider access and keep ExtraBrain itself separate from model billing.

## Provider Costs

Provider billing is separate from ExtraBrain. When you use a cloud LLM provider, selected prompts, transcript context, screenshot-derived context, and custom questions may be sent to that provider. When you use Deepgram, audio is sent to Deepgram for transcription.

## Pro

Pro can unlock workflow features such as custom profiles and premium model controls where enabled. Pro is for users who want repeatable interview, meeting, and analysis workflows with more control over how ExtraBrain behaves.

Use [Activate ExtraBrain Pro](/help/billing-pro/activate-license/) for license setup.

## Cost Checklist

- ExtraBrain app access and provider usage are separate.
- Local Parakeet transcription does not require a Deepgram API key.
- Deepgram usage is controlled by your Deepgram account.
- OpenAI, Anthropic, Claude, Codex, and custom endpoint usage is controlled by those providers.
- Pro unlocks ExtraBrain workflow features; it does not automatically change provider retention or billing.

## Billing Questions

### Does ExtraBrain Pro include AI provider credits?

No. Provider usage is separate unless ExtraBrain explicitly says otherwise for a future plan. Keep provider quotas, billing limits, and organization policies configured in the provider account you use.

### Do I need Pro to use my own API key?

No. Bring-your-own-provider setup is part of the core workflow. Pro is for advanced workflow controls such as custom profiles and premium model controls where enabled.
