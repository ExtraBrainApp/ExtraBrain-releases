主 ExtraBrain 窗口围绕记录、转录上下文、屏幕截图和分析构建。

![ExtraBrain 带实时控件的空闲主窗口](/assets/screenshots/help/dark/main-idle-controls.png)

## 主要控制装置

| 控制 | 它的作用 |
| --- | --- |
| 开始录音 | 启动实时会话并开始捕获启用的音频源。 |
| 停止 | 结束活动会话。 |
| 问 | 将当前上下文发送给选定的 AI 提供商进行分析。 |
| 捕获 | 将屏幕截图添加到活动会话。 |
| 展开或折叠 | 在紧凑和扩展窗口布局之间切换。 |

## 基本工作流程

1. 在通话开始前打开 ExtraBrain。
2. 单击**开始录制**。
3. 等待成绩单条目或检测到的主题卡。
4. 如果屏幕上下文很重要，请单击“**捕获**”。
5. 单击“**询问**”请求分析。
6. 使用后续问题或输入自定义问题。

![ExtraBrain 记录检测到的主题](/assets/screenshots/help/dark/main-recording-topic.png)

## 当按钮被禁用时

当 ExtraBrain 启动、停止、分析、验证提供程序访问或等待所需的权限和会话状态时，可以禁用按钮。如果按钮保持禁用状态，请检查[故障排除](/zh/help/troubleshooting/)。

在重要会话之前，请查看[音频设置](/zh/help/settings/audio-settings/)、[屏幕截图设置](/zh/help/settings/screenshot-settings/) 和[配置文件](/zh/help/settings/profiles/)。

## 隐私提醒

当您在选择云 LLM 提供商的情况下单击 **询问** 时，相关的文字记录、屏幕截图派生的上下文、提示和自定义问题可能会发送到该提供商。

## 录音问题

### 我什么时候应该点击“询问”？

在有用的文字记录上下文、检测到的主题、检测到的问题或屏幕截图可用后，单击“**询问**”。您还可以用最少的上下文询问以获得快速提示。

### 当我停止录音时会发生什么？

ExtraBrain 结束活动会话。本地会话历史记录可以保留记录、分析、屏幕截图、事实和条目，除非您稍后删除该会话。
