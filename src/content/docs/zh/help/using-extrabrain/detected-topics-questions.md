ExtraBrain 可以在会话进行时检测记录中的值得注意的主题和问题。这些在成绩单面板中显示为系统卡。

![录制期间检测到主题卡](/assets/screenshots/help/dark/main-recording-topic.png)

## 卡片的含义

| 卡片 | 意义 |
| --- | --- |
| 新主题 | ExtraBrain 检测到值得分析或跟踪的主题。 |
| 新问题 | ExtraBrain 在对话中检测到一个问题。 |
| 信心 | 估计的检测强度。 |
| 分析 | 使用检测到的主题或问题作为焦点开始分析。 |

## 良好的用途

- 说出语音后捕获编码提示。
- 跟踪系统设计要求。
- 拿出一个会议问题。
- 要求对最新主题做出简洁的回应。

只有最新的主题或问题可能会显示快捷方式提示，具体取决于您的快捷方式设置。

## 检测问题

### 为什么 ExtraBrain 检测到主题而不是问题？

主题和问题卡取决于文字记录上下文。广泛的讨论可能会成为新主题，而直接口头问题可能会成为新问题。

### 我应该如何处理检测到的主题卡？

当主题足够重要，需要向选定的人工智能提供商询问结构、权衡、后续步骤或简洁的答案时，请使用**分析**。
