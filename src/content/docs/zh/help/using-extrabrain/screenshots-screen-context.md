屏幕截图有助于 ExtraBrain 理解代码、提示、图表、幻灯片、终端、浏览器页面和其他视觉上下文。

![ExtraBrain 记录中的屏幕截图条目](/assets/screenshots/help/dark/main-screenshot-entry.png)

## 拍摄模式

打开 **设置 -> 屏幕截图** 以选择屏幕截图的工作方式。

![屏幕截图设置选项卡](/assets/screenshots/help/dark/settings-screenshot.png)

| 环境 | 何时使用 |
| --- | --- |
| 活动窗口 | 您希望屏幕截图的范围仅限于当前应用程序窗口。 |
| 全屏 | 您需要更广泛的桌面上下文。 |
| 先捕获后分析 | 您希望 ExtraBrain 在运行分析之前自动捕获屏幕截图。 |

## 会话期间

1. 开始录音。
2. 单击**捕获**。
3. 确认屏幕截图条目出现在记录面板中。
4. 单击 **询问** 将当前上下文包含在分析中。

如果未出现屏幕截图，请确认会话处于活动状态并且已授予 macOS 屏幕录制权限。

## 删除屏幕截图

当您捕获了错误的上下文或不希望将屏幕截图保留在本地会话记录中时，请使用屏幕截图删除。

## 数据流

屏幕截图作为会话工件存储在本地。当您要求云提供商进行分析时，屏幕截图派生的上下文可能会发送到所选提供商。

## 截图问题

### 我应该使用活动窗口还是全屏捕获？

当您希望当前应用程序的上下文更窄时，请使用活动窗口捕获。仅当更广泛的桌面视图与会话相关且可以接受时，才使用全屏捕获。

### 为什么分析中没有出现屏幕截图？

在分析开始之前，检查录制是否处于活动状态、屏幕录制权限是否已授予以及屏幕截图条目是否出现在脚本面板中。
