ExtraBrain 的核心 Mac 应用程序可以与提供商计费分开使用。外部提供商使用成本由您选择的提供商控制，例如 OpenAI、Anthropic、Deepgram、Claude、Codex 或自定义端点。

![ExtraBrain 许可证设置选项卡](/assets/screenshots/help/dark/settings-license.png)

## 要点

ExtraBrain 计费将 Mac 应用程序工作流程与外部模型和转录帐户分开，因此应用程序访问、Pro 功能和提供商使用情况应作为单独的成本类别进行审核。

- 核心 Mac 工作流程可免费使用。
- ExtraBrain Pro 是 $9.99/month 常规（$6.99/month 早期用户的创始人定价）、$79/year 或 $149 终身（启动价格）。
- 购买、激活、状态和停用均在应用程序内的**设置 -> 许可证**中处理。
- 提供商成本由 OpenAI、Anthropic、Deepgram、Claude、Codex 或您连接的自定义端点控制。
- Pro 用于工作流程控制，例如自定义配置文件、可重复使用的提示指导、更丰富的会话上下文、摘要和启用的高级控制。
- 当您激活 Pro 时，提供商保留、日志记录、配额和计费不会自动更改。

## 免费核心产品

免费的核心工作流程涵盖桌面应用程序、本地会话流程、BYO 提供程序设置、本地 Parakeet 转录、屏幕截图和基本实时分析控件。当您想要使用自己的提供商访问权限并将 ExtraBrain 本身与模型计费分开时，这是正确的路径。

## 提供者成本

提供商计费与 ExtraBrain 是分开的。当您使用云 LLM 提供商时，选定的提示、抄本上下文、屏幕截图派生的上下文和自定义问题可能会发送到该提供商。当您使用 Deepgram 时，音频将发送到 Deepgram 进行转录。

## Pro

Pro 是 $9.99/month（$6.99 创始人）、$79/year 或 $149 生命周期。 Pro 可以解锁工作流程功能，例如自定义配置文件、可重复使用的提示指导、特定于配置文件的行为、更丰富的会话上下文、会话后摘要以及启用的高级模型控件。 Pro 适用于需要可重复采访、会议和分析工作流程并更好地控制 ExtraBrain 行为的用户。

打开应用程序中的 **设置 -> 许可证** 以购买、激活、查看状态或停用 Pro。使用[激活ExtraBrain Pro](/zh/help/billing-pro/activate-license/)进行许可证设置，或比较[ExtraBrain免费和Pro](/zh/pricing/free-vs-pro/)。

## 成本清单

- ExtraBrain 应用程序访问和提供商使用是分开的。
- 本地 Parakeet 转录不需要 Deepgram API 密钥。
- Deepgram 使用由您的 Deepgram 帐户控制。
- OpenAI、Anthropic、Claude、Codex 和自定义端点使用由这些提供商控制。
- Pro 解锁 ExtraBrain 工作流程功能；它不会自动更改提供商保留或计费。
- 免费与 Pro 的详细信息发布于 [ExtraBrain 免费与 Pro](/zh/pricing/free-vs-pro/)。

## 计费问题

### ExtraBrain Pro 是否包含人工智能提供商积分？

不会。除非 ExtraBrain 对未来计划明确说明，否则提供商的使用是单独的。保留您使用的提供商帐户中配置的提供商配额、计费限制和组织策略。

### 我是否需要 Pro 才能使用我自己的 API 密钥？

不需要。自带提供商设置是核心工作流程的一部分。 Pro 用于高级工作流程控制，例如启用的自定义配置文件和高级模型控制。
