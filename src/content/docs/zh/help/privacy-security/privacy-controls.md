打开 **设置 -> 隐私** 以控制应用程序可见性、叠加行为和使用共享。

![ExtraBrain 隐私控制](/assets/screenshots/help/dark/settings-privacy.png)

## 可用的控件

| 控制 | 它的作用 |
| --- | --- |
| 截图保护 | 帮助隐藏操作系统支持的屏幕截图或屏幕捕获上下文中的叠加层。 |
| 从 Dock 和菜单栏隐藏 | 减少 macOS 应用程序镶边中可见的应用程序存在。 |
| 从托盘中隐藏 | 在支持的情况下隐藏托盘可见性。 |
| 点击模式 | 让点击穿过叠加层。 |
| 悬停动作延迟 | 控制悬停操作在点击工作流程中激活之前等待的时间。 |
| 共享匿名使用数据 | 控制是否共享使用数据以改进 ExtraBrain。 |

## 从隐藏或难以点击的窗口中恢复

如果窗口被隐藏或点击使交互变得困难：

1. 使用切换窗口快捷方式。
2. 如果可以的话，请从“设置”中禁用点击。
3. 如果启用了 Dock 或菜单栏可见性，请从 macOS 重新打开应用程序。

隐私控制影响可见性和遥测；它们不会改变云提供商分析可能会将选定的上下文发送到您选择的提供商的事实。

## 隐私控制问题

### 屏幕截图保护是否会取代提供商隐私设置？

不。屏幕截图保护是本地可见性控制。当您要求云 LLM 提供商分析转录或屏幕截图派生的上下文时，它不会更改可能发送的内容。

### 在敏感会议之前我应该做什么？

如果音频应保留在本地，请选择本地 Parakeet，确认您计划使用的 AI 提供商，如果需要禁用匿名使用共享，并删除您不想保留的本地会话历史记录。
