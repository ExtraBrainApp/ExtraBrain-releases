自定义配置文件是一项 Pro 功能，用于保存可重复使用的提示指导。当内置配置文件很接近但您想要更具体的行为时使用它们。 ExtraBrain Pro 是 $9.99/month（$6.99 创始人）、$79/year 或 $149 终身，可在 **设置 -> 许可证** 中购买和激活。

![ExtraBrain 配置文件设置侧重于自定义配置文件 Pro 控件](/assets/screenshots/help/dark/settings-custom-profiles.png)

## 自定义配置文件包括什么

| 现场或控制 | 目的 |
| --- | --- |
| 姓名 | 配置文件列表和配置文件选择器中显示的短标签。 |
| 描述 | 提醒何时使用配置文件。 |
| 迅速的 | 有关 ExtraBrain 应如何分析和响应的详细指导。 |
| 启用 | 控制自定义配置文件是否可用。 |
| 别针 | 使配置文件成为活动固定配置文件。 |
| 删除 | 从本地设置中删除自定义配置文件。 |

## 配置文件设置

自定义配置文件还可以控制工作流程行为：

| 环境 | 行为 |
| --- | --- |
| 扩大分析窗口 | 当配置文件开始分析时打开扩展窗口。 |
| 区域截图后开始分析 | 区域捕获后立即运行分析。 |
| 使用完整的会话上下文 | 当该配置文件处于活动状态时，为每个分析提供更多会话历史记录。 |

## 设置步骤

1. [激活 ExtraBrain Pro](/zh/help/billing-pro/activate-license/)。
2. 打开 **设置 -> 配置文件**。
3. 选择**创建配置文件**。
4. 添加名称、描述和提示。
5. 配置配置文件设置。
6. 如果您希望默认情况下激活配置文件，请固定该配置文件。

自定义配置文件文本存储在本地设置中。当您运行云提供商分析时，相关的提示指导、记录上下文、屏幕截图派生的上下文和问题可能会发送到您选择的提供商。

## 常见问题

### 我可以在没有 Pro 的情况下创建自定义配置文件吗？

不需要。免费用户可以使用内置的系统配置文件。创建和编辑自定义配置文件需要 Pro。

### 我应该在自定义配置文件提示中添加什么内容？

描述您希望 ExtraBrain 遵循的响应方式、限制和优先级。保持其可重复使用并避免秘密。
