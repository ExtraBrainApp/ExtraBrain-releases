打开 **设置 -> 许可证** 以购买、激活或管理 ExtraBrain Pro。 Pro 是 $9.99/month 常规（$6.99/month 早期用户的创始人定价）、$79/year 或 $149 终身（启动价格）。

![ExtraBrain 许可证设置选项卡](/assets/screenshots/help/dark/settings-license.png)

## 购买或激活许可证

1. 打开**设置 -> 许可证**。
2. 如果您仍需要购买，请选择每月或终身 Pro 选项。
3. 如果您已有许可证密钥，请粘贴您的许可证密钥。
4. 单击**激活**。
5. 等待验证。
6. 确认出现 Pro 状态。

使用您的购买或帐户电子邮件中的确切许可证密钥。避免在密钥前后添加空格，并像任何其他帐户凭据一样保持密钥的私密性。

## 激活后

许可证选项卡可以显示许可证状态和屏蔽密钥。 Pro 可以解锁高级工作流程控制，例如自定义配置文件、可重复使用的提示指导、特定于配置文件的行为、更丰富的会话上下文、会话后摘要以及启用的高级模型控制。

如果您想要针对特定工作流程、面试风格或会议格式的可重复使用的提示指导，请参阅[自定义配置文件](/zh/help/billing-pro/custom-profiles/)。

## 停用

将许可证移至另一个设置或从当前 Mac 中删除 Pro 时，请使用停用功能。

提供商使用成本与 ExtraBrain Pro 保持独立。 OpenAI、Anthropic、Deepgram、Claude、Codex 或自定义提供商成本由这些提供商管辖。

## 激活问题

### 为什么我的 ExtraBrain Pro 许可证未激活？

检查密钥是否完整，粘贴时没有多余的空格，并且用于当前 ExtraBrain 帐户或设备。另请确认 Mac 可以访问许可证验证服务。

### ExtraBrain Pro 激活后会发生什么变化？

许可证选项卡应显示活动 Pro 状态。 Pro 可以解锁高级工作流程控制，例如自定义配置文件、可重复使用的提示指导、特定于配置文件的行为、更丰富的会话上下文、会话后摘要以及当前版本公开的高级模型控件。
