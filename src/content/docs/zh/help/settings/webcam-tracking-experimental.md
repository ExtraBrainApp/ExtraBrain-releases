网络摄像头跟踪在当前应用程序中显示为实验性设置选项卡。仅当您有意想要基于摄像头的存在或面部跟踪行为时才使用它。

![ExtraBrain 实验性网络摄像头跟踪设置](/assets/screenshots/help/dark/settings-webcam-tracking.png)

## 实验对照

| 控制 | 它的作用 |
| --- | --- |
| 启用网络摄像头跟踪 | 打开或关闭实验功能。 |
| 相机选择器 | 当有多个相机设备可用时选择相机设备。 |
| 预览 | 显示所选相机是否正在生成可用的预览。 |
| 地位 | 根据设备访问和检测，指示活动、无面、不可用或重试状态。 |
| 打开设置或重试 | 帮助解决相机权限或设备问题。 |

## 隐私说明

摄像头访问权限与麦克风和屏幕权限分开。在启用此功能之前检查 macOS 相机权限，并在不需要基于相机的行为时禁用它。

此功能是实验性的。除非您在自己的设置中对其进行了测试，否则请勿依赖它来执行关键工作流程。

## 常见问题

### 使用 ExtraBrain 是否需要网络摄像头跟踪？

不需要。无需网络摄像头跟踪即可进行录音、转录、屏幕截图、分析、配置文件和会话历史记录。

### 我应该发布该功能还是依赖该功能稳定？

将其视为实验性的。在本地进行测试，如果它与您的工作流程不匹配，则将其禁用。
