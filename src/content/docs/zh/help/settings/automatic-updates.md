使用 **设置 -> 更新** 控制 ExtraBrain 是否自动检查并应用应用程序更新。

![ExtraBrain 使用自动更新切换更新设置](/assets/screenshots/help/dark/settings-updates.png)

## 自动更新有什么作用

| 控制 | 行为 |
| --- | --- |
| 自动更新 | 让 ExtraBrain 检查较新的版本并在后台准备更新。 |
| 更新通知 | ExtraBrain 在需要应用更新之前通知您。 |

自动更新有助于使提供商集成、权限处理和应用程序修复保持最新状态。如果禁用它们，请在重要会话之前手动检查版本。

## 推荐工作流程

1. 保持自动更新处于启用状态以供正常使用。
2. 当 ExtraBrain 要求完成应用更新时重新启动或重新启动。
3. 在关键会话之前，尽早打开 ExtraBrain 以让任何挂起的更新完成。

## 常见问题

### 下载更新时可以使用 ExtraBrain 吗？

是的。更新是在后台准备的。当出现提示并且可以安全地重新启动应用程序时应用它们。

### 我应该在实时会话之前禁用更新吗？

通常不会。相反，请提前打开 ExtraBrain 并在会话开始之前确认其已准备好。
