打开 **设置 -> 快捷方式** 以查看、编辑或重置快捷方式。

![ExtraBrain 快捷方式设置选项卡](/assets/screenshots/help/dark/settings-shortcuts.png)

## 编辑或重置

使用“快捷方式”选项卡可以编辑单个快捷方式或将所有快捷方式重置为默认值。如果您希望主 UI 在控件附近显示可用的快捷方式，请启用快捷方式提示。

## 快捷问题

### 我可以隐藏主窗口中的快捷方式提示吗？

是的。如果您想要更清晰的实时界面或文档屏幕截图，请打开 **设置 -> 快捷方式** 并关闭快捷方式提示。

### 我应该先学习哪些捷径？

从切换录制、捕获屏幕截图、切换分析、切换窗口和切换点击开始。这些控件涵盖了最常见的实时会话恢复路径。
