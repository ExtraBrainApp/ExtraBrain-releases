ExtraBrain 设置按工作流程区域组织。从主窗口打开设置，然后选择您需要的选项卡。

![ExtraBrain 常规设置选项卡](/assets/screenshots/help/dark/settings-general.png)

## 公共设置选项卡

| 选项卡 | 它控制什么 |
| --- | --- |
| 一般的 | [个人背景、首选编码语言、分析扩展和最新分析显示行为](/zh/help/settings/general-context-language/)。 |
| 型材 | [助理、编码、系统设计、行为、会议和自定义配置文件行为](/zh/help/settings/profiles/)。 |
| UI | [字体大小、不透明度、外观预设、提示和代码块主题](/zh/help/settings/ui-appearance/)。 |
| 快捷方式 | 录制、屏幕截图、分析、跟踪、窗口控制、点击和滚动快捷方式。 |
| 声音的 | [转录提供程序、Deepgram 键、麦克风设备、转录清理和语音触发器](/zh/help/settings/audio-settings/)。 |
| 截屏 | [活动窗口与全屏捕获和分析前捕获](/zh/help/settings/screenshot-settings/)。 |
| 网络摄像头追踪 | [实验存在和注视跟踪控件](/zh/help/settings/webcam-tracking-experimental/) 在当前版本中公开。 |
| LLM 提供商 | OpenAI、Anthropic、Claude 订阅、Codex 订阅和自定义端点设置。 |
| 会议 | 本地会话历史记录、记录、分析、事实、屏幕截图和删除。 |
| 隐私 | 屏幕截图保护、应用可见性、点击、悬停延迟和使用共享。 |
| 更新 | [自动更新首选项](/zh/help/settings/automatic-updates/)。 |
| 执照 | Pro 许可证激活、状态和停用。 |
| 反馈 | [反馈消息、可选电子邮件和提交状态](/zh/help/settings/send-feedback/)。 |

“远程”选项卡仅供开发使用，不应记录为公共功能。

## 设置问题

### 在实时会话之前我应该检查哪些设置？

检查音频、LLM 提供商、屏幕截图、隐私和快捷方式。这些选项卡控制最有可能影响实时工作流程的捕获、提供程序、屏幕上下文、可见性和命令行为。

### 我应该记录或使用“远程设置”选项卡吗？

不可以。“远程”选项卡仅供开发使用，不应被视为公共帮助中心功能。
