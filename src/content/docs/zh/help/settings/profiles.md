个人资料告诉 ExtraBrain 优先考虑哪种实时帮助。打开 **设置 -> 配置文件** 选择自动或固定配置文件行为。

![ExtraBrain 配置文件设置与系统和自定义配置文件控件](/assets/screenshots/help/dark/settings-profiles.png)

## 系统配置文件

| 轮廓 | 用它来 |
| --- | --- |
| 助手 | 混合对话中的一般实时帮助。 |
| 编码 | 实现问题、调试、代码审查和算法讨论。 |
| 系统设计 | 架构、权衡、可扩展性、可靠性和产品限制。 |
| 行为方面 | 体验故事、STAR 式结构、冲突、领导力和团队合作。 |
| 会议 | 摘要、决策、风险、后续行动和现场会议贡献。 |

## 自动与固定

| 模式 | 行为 |
| --- | --- |
| 汽车 | ExtraBrain 根据检测到的上下文在启用的系统配置文件中进行选择。 |
| 已固定 | ExtraBrain 保留在您选择的配置文件上，直到您更改它为止。 |

当会话在主题之间移动时，自动模式非常有用。当整个会议有明确的格式时（例如编码面试或系统设计回合），固定模式会更好。

## 管理个人资料

- 禁用您不希望使用自动检测的系统配置文件。
- 当您需要稳定的响应方式时固定配置文件。
- 当您需要快速切换时，可以从主窗口循环配置文件。
- 当 Pro 处于活动状态并且您需要内置配置文件之外的可重复使用的提示指导时，请使用 [自定义配置文件](/zh/help/billing-pro/custom-profiles/)。

## 常见问题

### 我应该使用自动模式还是固定模式？

使用“自动”进行混合会议和探索性会议。当会话格式是可预测的并且您想要一致的答案时，请使用固定。

### 自动模式下是否使用自定义配置文件？

不会。自动检测使用系统配置文件。自定义配置文件在选择或固定时使用。
