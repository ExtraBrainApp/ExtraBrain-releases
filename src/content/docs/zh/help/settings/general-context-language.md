使用 **设置 -> 常规** 为 ExtraBrain 提供有关您的稳定上下文，并调整分析在实时会话期间的显示方式。

![ExtraBrain 具有个人上下文和语言控制的常规设置](/assets/screenshots/help/dark/settings-general.png)

## 要配置什么

| 环境 | 它改变了什么 |
| --- | --- |
| 你的背景 | 生成答案时可以使用背景 ExtraBrain，例如您的角色、面试目标或首选的沟通方式。 |
| 首选语言 | 当编码上下文不明确时，编程语言 ExtraBrain 应该假设。 |
| 扩大分析窗口 | 当新分析开始时，打开展开的两面板视图。 |
| 仅显示最新分析 | 让分析小组专注于最新答案，而不是堆叠旧答案。 |

## 推荐设置

1. 添加简洁的上下文，帮助答案符合您的情况。
2. 选择您最常使用的编码语言。
3. 如果您希望立即看到答案，请保持启用**扩展分析窗口**。
4. 当您喜欢更安静的实时工作流程时，启用**仅显示最新分析**。
5. 开始一个简短的测试记录并要求进行分析以确认行为。

好的语境是具体的，但又不超载。例如，包括您的角色、目标面试类型、产品领域或演讲偏好。避免添加您不希望包含在发送给所选 AI 提供商的提示中的机密、客户数据或详细信息。

## 常见问题

### 我应该在你的上下文中添加什么？

使用简短而持久的指导：您的角色、面试类型、首选的编码语言和响应风格。请勿粘贴机密项目详细信息。

### 首选语言是否会覆盖屏幕截图？

不会。当上下文不明确时它会有所帮助。如果屏幕截图或文字记录清楚地显示另一种语言，ExtraBrain 仍然可以使用该可见上下文。
