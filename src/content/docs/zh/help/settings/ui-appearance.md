使用 **设置 -> UI** 调整 ExtraBrain 在重复实时使用过程中的外观。

![ExtraBrain UI 具有外观和代码主题控件的设置](/assets/screenshots/help/dark/settings-ui.png)

## 外观控制

| 控制 | 它改变了什么 |
| --- | --- |
| 字体大小 | 应用程序中的文本密度。 |
| 不透明度 | 主窗口透明度。 |
| 外观预设 | 窗口调色板。 |
| 尖端 | 是否出现应用内提示。 |
| 代码块主题 | 答案中显示的代码的语法突出显示样式。 |

## 推荐设置

1. 选择您可以在压力下快速阅读的字体大小。
2. 如果您拍摄文档屏幕截图或需要最大程度的易读性，请保持较高的不透明度。
3. 选择适用于您最常使用的应用程序的外观预设。
4. 选择一个代码块主题，使语法在当前的浅色或深色工作流程中保持可读性。
5. 一旦您了解了核心控件，请禁用提示。

不透明度和外观影响可见性。它们不会更改 ExtraBrain 在本地存储的内容或在分析过程中可能发送给您选择的提供商的内容。

## 常见问题

### 我应该在采访或会议期间降低不透明度吗？

仅当它可以帮助您保持上下文可见时。为了提高可读性、屏幕截图和减少视觉噪音，100% 不透明度通常更好。

### 代码块主题会影响模型响应吗？

不会。它只会更改代码在应用程序中的显示方式。
