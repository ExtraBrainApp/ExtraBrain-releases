使用 **设置 -> 反馈** 从 ExtraBrain 内部发送产品反馈、错误报告或支持上下文。

![ExtraBrain 带有消息和可选电子邮件字段的反馈设置](/assets/screenshots/help/dark/settings-feedback.png)

## 包括什么

| 场地 | 推荐 |
| --- | --- |
| 反馈留言 | 描述发生了什么、您的期望以及您正在使用的工作流程。 |
| 可选电子邮件 | 如果您需要支持跟进，请添加电子邮件。 |

对于错误，包括功能区域、提供商、转录模式、macOS 权限状态，以及问题是否发生在入门、记录、分析、屏幕截图或设置过程中。

## 发送敏感详细信息之前

请勿将 API 密钥、私人面试提示、客户数据或机密屏幕截图粘贴到反馈中。如果支持需要更多详细信息，请仅分享重现问题所需的最少上下文。

## 常见问题

### 需要电子邮件吗？

不需要。电子邮件是可选的，但添加它可以使后续操作成为可能。

### 怎样才算一份有用的错误报告？

包括重现步骤、预期行为、实际行为、provider/transcription 设置以及问题是否在更新后开始。
