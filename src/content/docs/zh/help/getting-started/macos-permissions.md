ExtraBrain 需要 macOS 权限才能使用实时音频和屏幕上下文。在入职期间或从 macOS 系统设置中授予这些权限。

![ExtraBrain 入职期间的权限步骤](/assets/screenshots/help/dark/onboarding-permissions.png)

## 权限 ExtraBrain 用途

| 允许 | 为什么 ExtraBrain 使用它 |
| --- | --- |
| 麦克风 | 在现场会议期间转录您的口语音频。 |
| 屏幕录制 | 捕获您要求 ExtraBrain 分析的屏幕截图和屏幕上下文。 |
| 系统音频 | 当会话需要系统声音时捕获会议、通话或视频音频。 |

## 打开 macOS 设置

1. 打开**系统设置**。
2. 转到**隐私与安全**。
3. 检查 **麦克风**、**屏幕录制** 和系统音频相关提示（如果 macOS 显示）。
4. 启用 ExtraBrain。
5. 如果 macOS 要求或者权限状态没有立即更新，请重新启动 ExtraBrain。

## 如果权限看起来仍然被阻止

- 退出并重新打开 ExtraBrain。
- 在系统设置中关闭和打开权限。
- 如果屏幕录制仍然卡住，请重新启动 Mac。
- 重新启动后重新打开入门或设置。

“麦克风已停止”、“系统音频已停止”或“音频已停止”等权限警告表示 ExtraBrain 失去了对部分捕获管道的访问权限，需要权限或设备恢复。

## 权限问题

### 为什么 ExtraBrain 需要屏幕录制权限？

屏幕录制可让 ExtraBrain 捕获您明确用于分析的屏幕截图和屏幕上下文。如果没有它，屏幕截图捕获和屏幕上下文工作流程可能会失败。

### 为什么ExtraBrain需要系统音频权限？

系统音频可帮助 ExtraBrain 捕获会议、通话、视频或共享音频上下文（如果支持）。如果没有它，您可能只能看到麦克风转录。
