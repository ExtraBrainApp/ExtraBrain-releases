## 支持平台

ExtraBrain 今天是 macOS。 Windows 和 Linux 是计划中的，不是当前的公开发布目标。

当您需要本帮助中心中描述的桌面覆盖、实时录制控件、本地会话历史记录、屏幕截图上下文和提供程序设置时，请使用官方 macOS 版本。

![ExtraBrain 安装后欢迎屏幕](/assets/screenshots/help/dark/onboarding-welcome.png)

## 要点

ExtraBrain 安装是 macOS 设置路径，可在实时会话之前准备好桌面应用程序、实时录制控件、本地会话历史记录、屏幕截图、转录和 AI 提供程序访问。

- ExtraBrain 目前支持 Mac，包括 Apple Silicon 和 Intel Mac。
- Windows 和 Linux 是计划中的，不是当前的公开发布目标。
- 可靠的首次设置需要进行 5 项检查：应用程序启动、麦克风权限、屏幕录制权限、转录选择和提供商验证。
- 本地 Parakeet 转录不需要 Deepgram API 密钥；可选 Deepgram 使用您的 Deepgram 帐户。

## 从 GitHub Releases 安装

1. 打开 [ExtraBrain 下载页面](/zh/download/)。
2. 下载当前的 macOS 版本。
3. 打开下载的安装程序或应用程序包。
4. 如果发布说明需要，则将应用程序移至应用程序中。
5. 启动 ExtraBrain。

## 首次启动清单

- 完成入职。
- 授予麦克风、屏幕录制和系统音频权限。
- 选择本地 Parakeet 或 Deepgram 转录。
- 连接 OpenAI、Anthropic、Claude 订阅、Codex 订阅或自定义 OpenAI-compatible 端点。
- 在真正的面试或会议中使用 ExtraBrain 之前运行一个简短的测试会话。

如果 macOS 阻止麦克风或屏幕访问，请打开 [授予 macOS 权限](/zh/help/getting-started/macos-permissions/) 并按照系统设置恢复步骤进行操作。

:::caution
不要等到面试前五分钟才首次安装该应用程序。在实时会话之前测试发布、权限、转录和提供程序设置。
:::

## 安装问题

### 我应该在哪里下载ExtraBrain？

使用官方 [ExtraBrain 下载页面](/zh/download/)。它指向当前的 macOS 版本并避免过时的第三方构建。

### 安装ExtraBrain后我应该测试什么？

启动一个简短的会话，确认出现转录，捕获一张屏幕截图，运行一项分析，并验证使用您选择的提供商的响应。
