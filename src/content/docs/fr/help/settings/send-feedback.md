Utilisez **Paramètres -> Commentaires** pour envoyer des commentaires sur le produit, des rapports de bugs ou un contexte d'assistance depuis ExtraBrain.

![ExtraBrain paramètres de commentaires avec champs de message et de courrier électronique facultatifs](/assets/screenshots/help/dark/settings-feedback.png)

## Que faut-il inclure

| Champ | Recommandation |
| --- | --- |
| Message de commentaires | Décrivez ce qui s'est passé, ce à quoi vous vous attendiez et le flux de travail que vous utilisiez. |
| Courriel facultatif | Ajoutez un e-mail si vous souhaitez que l'assistance fasse un suivi. |

Pour les bogues, indiquez la zone de fonctionnalités, le fournisseur, le mode de transcription, l'état d'autorisation macOS et si le problème s'est produit lors de l'intégration, de l'enregistrement, de l'analyse, des captures d'écran ou des paramètres.

## Avant d'envoyer des informations sensibles

Ne collez pas les clés API, les invites d'entretien privé, les données client ou les captures d'écran confidentielles dans les commentaires. Si l'assistance a besoin de plus de détails, partagez uniquement le contexte minimum nécessaire pour reproduire le problème.

## Questions courantes

### L'e-mail est-il requis ?

Non. L’e-mail est facultatif, mais son ajout permet un suivi.

### Qu'est-ce qui rend un rapport de bug utile ?

Incluez les étapes de reproduction, le comportement attendu, le comportement réel, les paramètres du fournisseur/transcription et si le problème a commencé après une mise à jour.
