Utilisez **Paramètres -> Général** pour donner à ExtraBrain un contexte stable sur vous et ajuster la façon dont l'analyse apparaît lors d'une session en direct.

![ExtraBrain paramètres généraux avec contexte personnel et commandes de langue](/assets/screenshots/help/dark/settings-general.png)

## Que configurer

| Paramètre | Ce que ça change |
| --- | --- |
| Votre contexte | Contexte ExtraBrain peut être utilisé pour générer des réponses, telles que votre rôle, vos objectifs d'entretien ou votre style de communication préféré. |
| Langue préférée | Le langage de programmation ExtraBrain doit le supposer lorsque le contexte de codage est ambigu. |
| Agrandir la fenêtre sur l'analyse | Ouvre la vue développée à deux panneaux lorsqu'une nouvelle analyse démarre. |
| Afficher uniquement la dernière analyse | Maintient le panneau d’analyse concentré sur la réponse la plus récente au lieu d’empiler les réponses plus anciennes. |

## Configuration recommandée

1. Ajoutez un contexte concis qui aide les réponses à correspondre à votre situation.
2. Choisissez le langage de codage que vous utilisez le plus souvent.
3. Gardez **Agrandir la fenêtre d'analyse** activé si vous souhaitez que les réponses soient visibles immédiatement.
4. Activez **Afficher uniquement la dernière analyse** lorsque vous préférez un flux de travail en direct plus silencieux.
5. Démarrez un court enregistrement de test et demandez une analyse pour confirmer le comportement.

Un bon contexte est spécifique mais pas surchargé. Par exemple, indiquez votre rôle, le type d'entretien cible, le domaine de produit ou vos préférences de parole. Évitez d'ajouter des secrets, des données client ou des détails que vous ne voudriez pas inclure dans les invites envoyées à votre fournisseur d'IA sélectionné.

## Questions courantes

### Que dois-je mettre dans votre contexte ?

Utilisez des conseils courts et durables : votre rôle, votre type d’entretien, votre langage de codage préféré et votre style de réponse. Ne collez pas les détails confidentiels du projet.

### La langue préférée remplace-t-elle les captures d'écran ?

Non. Cela aide lorsque le contexte est ambigu. Si une capture d'écran ou une transcription montre clairement une autre langue, ExtraBrain peut toujours utiliser ce contexte visible.
