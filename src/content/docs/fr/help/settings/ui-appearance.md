Utilisez **Paramètres -> UI** pour régler l'apparence de ExtraBrain lors d'une utilisation répétée en direct.

![Paramètres ExtraBrain UI avec commandes d'apparence et de thème de code](/assets/screenshots/help/dark/settings-ui.png)

## Contrôles d'apparence

| Contrôle | Ce que ça change |
| --- | --- |
| Taille de la police | Densité du texte dans l'application. |
| Opacité | Transparence de la fenêtre principale. |
| Préréglages d'apparence | Palette de couleurs de fenêtre. |
| Conseils | Si des conseils dans l'application apparaissent. |
| Thème du bloc de code | Style de coloration syntaxique pour le code affiché dans les réponses. |

## Configuration recommandée

1. Choisissez une taille de police que vous pouvez lire rapidement sous pression.
2. Maintenez une opacité élevée si vous prenez des captures d'écran de la documentation ou si vous avez besoin d'une lisibilité maximale.
3. Choisissez un préréglage d'apparence qui fonctionne sur les applications que vous utilisez le plus.
4. Choisissez un thème de bloc de code qui maintient la syntaxe lisible dans votre flux de travail clair ou sombre actuel.
5. Désactivez les astuces une fois que vous connaissez les commandes principales.

L'opacité et l'apparence affectent la visibilité. Ils ne modifient pas ce que ExtraBrain stocke localement ou ce qui peut être envoyé aux fournisseurs sélectionnés lors de l'analyse.

## Questions courantes

### Dois-je réduire l'opacité lors des entretiens ou des réunions ?

Seulement si cela vous aide à garder le contexte visible. Pour la lisibilité, les captures d'écran et la réduction du bruit visuel, l'opacité 100% est généralement meilleure.

### Le thème du bloc de code affecte-t-il la réponse du modèle ?

Non, cela change uniquement la façon dont le code est affiché dans l’application.
