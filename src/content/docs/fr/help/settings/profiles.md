Les profils indiquent à ExtraBrain quel type d'aide en direct prioriser. Ouvrez **Paramètres -> Profils** pour choisir le comportement du profil automatique ou épinglé.

![Paramètres des profils ExtraBrain avec commandes système et profils personnalisés](/assets/screenshots/help/dark/settings-profiles.png)

## Profils système

| Profil | Utilisez-le pour |
| --- | --- |
| Assistante | Aide générale en direct sur des conversations mixtes. |
| Codage | Questions d'implémentation, débogage, révision du code et discussion sur les algorithmes. |
| Conception du système | Architecture, compromis, évolutivité, fiabilité et contraintes du produit. |
| Comportemental | Découvrez des histoires, une structure de style STAR, des conflits, du leadership et du travail d'équipe. |
| Réunion | Résumés, décisions, risques, suivis et contribution aux réunions en direct. |

## Auto vs épinglé

| Mode | Comportement |
| --- | --- |
| Automobile | ExtraBrain choisit parmi les profils système activés en fonction du contexte détecté. |
| Épinglé | ExtraBrain reste sur le profil que vous avez sélectionné jusqu'à ce que vous le modifiiez. |

Le mode automatique est utile lorsqu'une session passe d'un sujet à l'autre. Le mode épinglé est préférable lorsque l'ensemble de la session a un format clair, comme un entretien de codage ou un cycle de conception de système.

## Gestion des profils

- Désactivez les profils système que vous ne souhaitez pas que la détection automatique utilise.
- Épinglez un profil lorsque vous souhaitez un style de réponse stable.
- Parcourez les profils depuis la fenêtre principale lorsque vous devez changer rapidement.
- Utilisez [profils personnalisés] (/help/billing-pro/custom-profiles/) lorsque Pro est actif et que vous avez besoin de conseils rapides réutilisables au-delà des profils intégrés.

## Questions courantes

### Dois-je utiliser le mode Auto ou Épinglé ?

Utilisez Auto pour les réunions mixtes et les sessions exploratoires. Utilisez Épinglé lorsque le format de la session est prévisible et que vous souhaitez des réponses cohérentes.

### Les profils personnalisés sont-ils utilisés en mode Auto ?

Non. La détection automatique utilise des profils système. Les profils personnalisés sont utilisés lorsqu'ils sont sélectionnés ou épinglés.
