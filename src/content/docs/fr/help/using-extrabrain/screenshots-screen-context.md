Les captures d'écran aident ExtraBrain à comprendre le code, les invites, les diagrammes, les diapositives, les terminaux, les pages du navigateur et tout autre contexte visuel.

![Capture d'écran dans une transcription ExtraBrain](/assets/screenshots/help/dark/main-screenshot-entry.png)

## Modes de capture

Ouvrez **Paramètres -> Capture d'écran** pour choisir le fonctionnement des captures d'écran.

![Onglet Paramètres de capture d'écran](/assets/screenshots/help/dark/settings-screenshot.png)

| Paramètre | Utilisez-le quand |
| --- | --- |
| Fenêtre active | Vous souhaitez que les captures d'écran soient étendues à la fenêtre actuelle de l'application. |
| Plein écran | Vous avez besoin d’un contexte de bureau plus large. |
| Capture avant analyse | Vous souhaitez que ExtraBrain capture automatiquement une capture d'écran avant d'exécuter l'analyse. |

## Pendant une session

1. Commencez l'enregistrement.
2. Cliquez sur **Capturer**.
3. Confirmez que l'entrée de capture d'écran apparaît dans le panneau de transcription.
4. Cliquez sur **Demander** pour inclure le contexte actuel dans l'analyse.

Si une capture d'écran n'apparaît pas, confirmez que la session est active et que l'autorisation d'enregistrement d'écran macOS est accordée.

## Supprimer les captures d'écran

Utilisez la suppression de capture d'écran lorsque vous avez capturé le mauvais contexte ou que vous ne souhaitez pas qu'une capture d'écran soit conservée dans l'enregistrement de session locale.

## Flux de données

Les captures d'écran sont stockées localement en tant qu'artefacts de session. Lorsque vous demandez une analyse à un fournisseur de cloud, le contexte dérivé de la capture d'écran peut être envoyé au fournisseur sélectionné.

## Questions de capture d'écran

### Dois-je utiliser la capture en fenêtre active ou en plein écran ?

Utilisez la capture de fenêtre active lorsque vous souhaitez un contexte plus étroit à partir de l'application actuelle. Utilisez la capture plein écran uniquement lorsque la vue plus large du bureau est pertinente et acceptable pour la session.

### Pourquoi les captures d'écran n'apparaissent-elles pas dans l'analyse ?

Vérifiez que l'enregistrement est actif, que l'autorisation d'enregistrement d'écran est accordée et qu'une entrée de capture d'écran apparaît dans le panneau de transcription avant le début de l'analyse.
