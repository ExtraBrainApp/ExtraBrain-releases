Une fois que ExtraBrain a terminé une analyse, la carte peut afficher des suggestions de questions de suivi. Utilisez-les pour maintenir la session en mouvement sans réécrire le contexte.

![Carte d'analyse complétée avec questions de suivi](/assets/screenshots/help/dark/main-analysis-followups.png)

## Suivis suggérés

Les suivis suggérés sont des boutons sur la carte d’analyse complétée. Cliquez sur l'un d'entre eux pour poser une question connexe en utilisant le contexte de la session en cours et l'analyse de la source.

## Questions personnalisées

Utilisez la case Demander lorsque les suivis suggérés ne sont pas suffisamment spécifiques. Les bonnes questions personnalisées sont courtes et directes :

- "Donnez-moi des cas extrêmes pour cette invite."
- "Quel compromis dois-je expliquer ensuite ?"
- "Transformez-le en éléments d'action."
- "Quel est le risque dans cette conception ?"

## Analyse de copie

Utilisez les contrôles de copie sur une carte d'analyse lorsque vous devez déplacer une réponse dans des notes, un document ou un autre flux de travail local.

## Raccourcis clavier

Si les astuces de raccourci sont activées, des raccourcis de suivi peuvent apparaître sur les derniers boutons de suivi disponibles. Modifiez les raccourcis dans [Raccourcis clavier] (/help/settings/keyboard-shortcuts/).

## Questions de suivi

### Quand dois-je utiliser les suivis suggérés ?

Utilisez les suivis suggérés lorsque la première analyse est utile d’un point de vue directionnel et que vous souhaitez explorer les compromis, les prochaines étapes, les cas limites ou les risques sans retaper le contexte.

### Quand dois-je saisir une question personnalisée ?

Tapez une question personnalisée lorsque la session a un objectif spécifique, comme préparer une réponse, demander des puces concises ou se concentrer sur une capture d'écran ou un segment de transcription.
