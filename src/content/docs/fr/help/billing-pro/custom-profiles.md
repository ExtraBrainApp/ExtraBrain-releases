Les profils personnalisés sont une fonctionnalité Pro permettant d'enregistrer des instructions d'invite réutilisables. Utilisez-les lorsqu'un profil intégré est proche mais que vous souhaitez un comportement plus spécifique. ExtraBrain Pro correspond à $9.99/month ($6.99 Fondateur), $79/year ou $149 à vie, avec achat et activation dans **Paramètres -> Licence**.

![Paramètres des profils ExtraBrain axés sur les commandes du profil personnalisé Pro](/assets/screenshots/help/dark/settings-custom-profiles.png)

## Ce que comprend un profil personnalisé

| Champ ou contrôle | Objectif |
| --- | --- |
| Nom | Étiquette courte affichée dans la liste de profils et le sélecteur de profil. |
| Descriptif | Rappel du moment d'utiliser le profil. |
| Invite | Des conseils détaillés sur la façon dont ExtraBrain doit analyser et répondre. |
| Activé | Contrôle si le profil personnalisé est disponible. |
| Épingle | Fait du profil le profil épinglé actif. |
| Supprimer | Supprime le profil personnalisé des paramètres locaux. |

## Paramètres du profil

Les profils personnalisés peuvent également contrôler le comportement du flux de travail :

| Paramètre | Comportement |
| --- | --- |
| Agrandir la fenêtre sur l'analyse | Ouvre la fenêtre développée lorsque le profil démarre l'analyse. |
| Démarrer l'analyse après la capture d'écran de la région | Exécute l'analyse immédiatement après la capture d'une région. |
| Utiliser le contexte de session complet | Donne à chaque analyse plus d’historique de session lorsque ce profil est actif. |

## Étapes de configuration

1. [Activer ExtraBrain Pro](/fr/help/billing-pro/activate-license/).
2. Ouvrez **Paramètres -> Profils**.
3. Choisissez **Créer un profil**.
4. Ajoutez un nom, une description et une invite.
5. Configurez les paramètres de profil.
6. Épinglez le profil si vous souhaitez qu'il soit actif par défaut.

Le texte du profil personnalisé est stocké dans les paramètres locaux. Lorsque vous exécutez une analyse du fournisseur de cloud, des instructions pertinentes, le contexte de la transcription, le contexte dérivé de la capture d'écran et les questions peuvent être envoyés au fournisseur que vous avez sélectionné.

## Questions courantes

### Puis-je créer des profils personnalisés sans Pro ?

Non. Les utilisateurs gratuits peuvent utiliser les profils système intégrés. La création et la modification de profils personnalisés nécessitent Pro.

### Que dois-je mettre dans une invite de profil personnalisé ?

Décrivez le style de réponse, les contraintes et les priorités que vous souhaitez que ExtraBrain suive. Gardez-le réutilisable et évitez les secrets.
