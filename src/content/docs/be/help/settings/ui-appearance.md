Выкарыстоўвайце **Настройкі -> UI**, каб наладзіць, як ExtraBrain выглядае падчас шматразовага выкарыстання ў жывым эфіры.

![ExtraBrain UI налады з элементамі кіравання знешнім выглядам і тэмай кода](/assets/screenshots/help/dark/settings-ui.png)

## Элементы кіравання знешнім выглядам

| Кантроль | Што гэта мяняе |
| --- | --- |
| Памер шрыфта | Шчыльнасць тэксту ў праграме. |
| Непразрыстасць | Празрыстасць галоўнага акна. |
| Прасэты знешняга выгляду | Колеравая палітра вокнаў. |
| Саветы | Ці з'яўляюцца падказкі ў дадатку. |
| Тэма блока кода | Стыль падсвятлення сінтаксісу для кода, паказанага ў адказах. |

## Рэкамендуемая ўстаноўка

1. Выберыце памер шрыфта, які можна хутка чытаць пад націскам.
2. Падтрымлівайце высокую непразрыстасць, калі вы робіце скрыншоты дакументацыі або вам патрэбна максімальная разборлівасць.
3. Выберыце папярэднюю наладу знешняга выгляду, якая працуе над праграмамі, якімі вы часцей за ўсё карыстаецеся.
4. Выберыце тэму блока кода, якая дазваляе чытаць сінтаксіс у вашым бягучым светлым або цёмным працоўным працэсе.
5. Адключыце падказкі, калі даведаецеся асноўныя элементы кіравання.

Непразрыстасць і знешні выгляд уплываюць на бачнасць. Яны не змяняюць тое, што ExtraBrain захоўвае лакальна або тое, што можа быць адпраўлена выбраным пастаўшчыкам падчас аналізу.

## Агульныя пытанні

### Ці варта зніжаць непразрыстасць падчас інтэрв'ю або сустрэч?

Толькі калі гэта дапаможа вам захаваць кантэкст бачным. Для зручнасці чытання, скрыншотаў і зніжэння візуальнага шуму звычайна лепш непразрыстасць 100%.

### Ці ўплывае тэма блока кода на рэакцыю мадэлі?

Не. Гэта змяняе толькі спосаб адлюстравання кода ў праграме.
