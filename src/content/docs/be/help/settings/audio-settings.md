Выкарыстоўвайце **Настройкі -> Аўдыя**, каб выбраць паводзіны транскрыпцыі і ўвод мікрафона.

![ExtraBrain налады гуку з пастаўшчыком транскрыпцыі і элементамі кіравання мікрафонам](/assets/screenshots/help/dark/settings-audio.png)

## Элементы кіравання гукам

| Кантроль | Што гэта мяняе |
| --- | --- |
| Пастаўшчык пераўтварэння маўлення ў тэкст | Лакальная воблачная транскрыпцыя Parakeet або Deepgram. |
| Ключ Deepgram API | Патрабуецца, толькі калі выбрана Deepgram. |
| Крыніца гуку | Пераважны ўваход для мікрафона. |
| Галасавы трыгер | Кіраванне прамоўленай фразай для пачатку аналізу падчас актыўнага сеансу. |
| Ачыстка стэнаграмы | Выдаленне слоў-запаўняльнікаў перад картамі расшыфроўкі і аналізам. |
| Дазвол сістэмнага гуку | Паток дазволаў macOS для запісу аўдыяпрыкладання/system, калі патрабуецца. |

## Заўвагі

- Змены аўдыяпрылад прымяняюцца да новых сеансаў.
- Лакальны Parakeet захоўвае лакальную транскрыпцыю.
- Deepgram адпраўляе аўдыя на Deepgram для транскрыпцыі.
- ExtraBrain можа спатрэбіцца macOS дазвол мікрафона і сістэмнага аўдыё перад пачаткам запісу.

## Агульныя пытанні

### Чаму ExtraBrain кажа, што прылады не знойдзены?

Магчыма, macOS яшчэ не даў дазвол на мікрафон, або выбраны ўваход можа быць недаступны. Дайце дазвол, паўторна падключыце мікрафон і пачніце новы сеанс.

### Ці ўплывае пераключэнне пастаўшчыкоў транскрыпцыі на бягучы сеанс?

Змены пастаўшчыка і прылады найбольш бяспечныя, калі ўносяцца перад пачаткам сеансу. Спыніце запіс і пачніце новы сеанс пасля сур'ёзных змяненняў гуку.
