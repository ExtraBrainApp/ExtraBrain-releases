ExtraBrain выкарыстоўвае абранага вамі пастаўшчыка штучнага інтэлекту для аналізу ў рэальным часе. Налады пастаўшчыка кантралююць, куды могуць адпраўляцца падказкі, кантэкст расшыфроўкі і кантэкст, атрыманы са скрыншотаў.

![Сродак выбару пастаўшчыка AI пры ўсталёўцы ExtraBrain](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## Рэжымы грамадскага пастаўшчыка

- Ключ OpenAI API.
- Ключ Anthropic API.
- Codex Падпіска з выкарыстаннем ChatGPT Plus або Pro непасрэдна, без ключа API.
- Claude Падпіска з выкарыстаннем Claude Pro або Max непасрэдна, без ключа API.
- Карыстальніцкая канчатковая кропка OpenAI-compatible з базавым URL, ключом API і назвай мадэлі.

## Кантрольны спіс наладкі

1. Адкрыйце адаптацыю або **Настройкі -> LLM Пастаўшчыкі**.
2. Выберыце сямейства правайдэраў.
3. Выберыце ключ API або рэжым падпіскі.
4. Пры неабходнасці ўвядзіце ўліковыя даныя.
5. Пацвердзіце або паўторна праверце злучэнне.
6. Правядзіце кароткі тэставы аналіз.

![LLM Укладка налад правайдэраў](/assets/screenshots/help/dark/settings-llm-providers.png)

## Паток даных

Калі вы запытваеце ExtraBrain аб аналізе ў воблачнага пастаўшчыка, гэтаму пастаўшчыку могуць быць адпраўлены адпаведныя падказкі, кантэкст стэнаграмы, кантэкст, атрыманы са скрыншотаў, і карыстальніцкія пытанні. Выстаўленне рахункаў, утрыманне, квоты і кантроль уліковых запісаў пастаўшчыка рэгулююцца абраным вамі пастаўшчыком.

## Пытанні пастаўшчыка AI

### Якога пастаўшчыка AI мне выбраць у першую чаргу?

Выберыце пастаўшчыка, якому вы ўжо давяраеце і якога можна праверыць перад рэальным сеансам. Для большасці карыстальнікаў гэта азначае пачаць з існуючага ўліковага запісу OpenAI, Anthropic, Claude або Codex.

### Ці магу я падрыхтаваць больш чым адзін шлях пастаўшчыка?

так. Захаванне шляху рэзервовага пастаўшчыка карысна перад інтэрв'ю або сустрэчамі, дзе могуць змяніцца квота, доступ да сеткі або статус уліковага запісу.
