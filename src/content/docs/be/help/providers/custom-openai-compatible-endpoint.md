Выкарыстоўвайце карыстальніцкую канчатковую кропку OpenAI-compatible, калі ваш пастаўшчык або проксі-сервер паказвае API у стылі OpenAI.

![ExtraBrain карыстальніцкія налады пастаўшчыка OpenAI-compatible з базавым URL і палямі назвы мадэлі](/assets/screenshots/help/dark/settings-custom-provider.png)

## Абавязковыя палі

| Палявы | Што ўвесці |
| --- | --- |
| Базавы URL | Базавы URL пастаўшчыка або проксі API. |
| Ключ API | Ключ, неабходны гэтай канчатковай кропцы. |
| Назва мадэлі | Дакладны ідэнтыфікатар мадэлі, які чакае канчатковая кропка. |

## Крокі наладкі

1. Адкрыйце адаптацыю або **Настройкі -> LLM Пастаўшчыкі**.
2. Выберыце опцыю карыстальніцкага пастаўшчыка.
3. Увядзіце базавы URL.
4. Увядзіце ключ API.
5. Увядзіце назву мадэлі.
6. Праверце канфігурацыю.
7. Правядзіце кароткі тэставы аналіз.

## Тыповыя памылкі

- Адсутнічае `/v1`, калі правайдэр чакае яго.
- Выкарыстанне адлюстраванага імя мадэлі замест ідэнтыфікатара мадэлі API.
- Устаўка ключа няправільнага пастаўшчыка або проксі.
- Забываючы, што правілы ўтрымання пастаўшчыка, выстаўлення рахункаў і доступу кантралююцца карыстальніцкім аператарам канчатковай кропкі.

Карыстальніцкія запыты пастаўшчыка могуць уключаць падказкі, кантэкст стэнаграмы, кантэкст, атрыманы са скрыншотаў, і карыстальніцкія пытанні.

## Карыстальніцкія пытанні канчатковай кропкі

### Што робіць канечную кропку OpenAI-compatible?

Канчатковая кропка павінна прымаць запыты API ў стылі OpenAI для чата або адказы з выкарыстаннем базавага URL-адраса, ключа і назвы мадэлі, якія вы ўводзіце ў ExtraBrain.

### Што я павінен праверыць пасля захавання карыстальніцкай канчатковай кропкі?

Правядзіце кароткі аналіз з неканфідэнцыяльнай расшыфроўкай або кантэкстам скрыншота. Пацвердзіце, што канчатковая кропка вяртае адказ і што назва мадэлі адпавядае чаканням вашага пастаўшчыка або проксі.
