ExtraBrain падтрымлівае рэжым ключа Anthropic API і рэжым падпіскі Claude.

## Anthropic API Ключавы рэжым

Выкарыстоўвайце гэты рэжым, калі хочаце, каб ExtraBrain выклікаў Anthropic праз ключ API, якім вы кіруеце.

1. Адкрыйце **Настройкі -> LLM Пастаўшчыкі**.
2. Выберыце **Anthropic**.
3. Устаўце свой ключ Anthropic API.
4. Выберыце мадэль.
5. Праверыць ключ.
6. Правядзіце кароткі тэставы аналіз.

![LLM Укладка налад правайдэраў з выбраным Anthropic](/assets/screenshots/help/dark/settings-llm-providers.png)

## Claude Рэжым падпіскі

Выкарыстоўвайце падпіску Claude, калі хочаце, каб ExtraBrain выкарыстоўваў вашу падпіску Claude Pro або Max непасрэдна. Гэты рэжым не патрабуе ключа API у ExtraBrain.

1. Адкрыйце **Настройкі -> LLM Пастаўшчыкі**.
2. Выберыце **Claude Падпіска**.
3. Паўторна праверце статус уваходу.
4. Выберыце даступную мадэль.
5. Правядзіце тэставы аналіз.

## Ліквідацыю непаладак

Калі праверка не атрымоўваецца, пераканайцеся, што ключ API належыць праваму ўліковаму запісу Anthropic, мае доступ да мадэлі і ўстаўлены без лішніх прабелаў. Для рэжыму падпіскі пацвердзіце, што ваша падпіска Claude актыўная і ўвайшлі ў сістэму там, дзе чакае ExtraBrain.

## Anthropic і Claude Пытанні

### Ці патрэбны мне ключ Anthropic API для рэжыму падпіскі Claude?

Няма. Рэжым падпіскі Claude прызначаны для доступу па падпісцы Claude Pro або Max і не патрабуе ключа Anthropic API унутры ExtraBrain.

### Якія дадзеныя можна адпраўляць на Anthropic або Claude?

Пры выбары для аналізу адпаведныя падказкі, кантэкст стэнаграмы, кантэкст, атрыманы са скрыншотаў, і карыстальніцкія пытанні могуць быць адпраўлены на Anthropic або Claude у адпаведнасці з рэжымам гэтага пастаўшчыка.
