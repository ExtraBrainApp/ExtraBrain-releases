ExtraBrain падтрымлівае рэжым ключа OpenAI API і рэжым падпіскі Codex.

## OpenAI API Ключавы рэжым

Выкарыстоўвайце гэты рэжым, калі хочаце, каб ExtraBrain выклікаў OpenAI праз ключ API, якім вы кіруеце.

1. Адкрыйце **Настройкі -> LLM Пастаўшчыкі**.
2. Выберыце **OpenAI**.
3. Устаўце свой ключ API.
4. Выберыце мадэль і спробу аргументацыі, калі яны даступныя.
5. Праверыць ключ.
6. Правядзіце кароткі аналіз, каб пацвердзіць, што адказы паступаюць ад OpenAI.

![OpenAI форма пастаўшчыка ў рэкамендацыі](/assets/screenshots/help/dark/onboarding-openai-provider-form.png)

## Codex Рэжым падпіскі

Выкарыстоўвайце падпіску Codex, калі хочаце, каб ExtraBrain выкарыстоўваў вашу падпіску ChatGPT Plus або Pro непасрэдна. Гэты рэжым не патрабуе ключа API у ExtraBrain.

1. Адкрыйце **Настройкі -> LLM Пастаўшчыкі**.
2. Выберыце **Codex Падпіска**.
3. Паўторна праверце статус уваходу.
4. Выберыце даступную мадэль.
5. Правядзіце тэставы аналіз.

## Ліквідацыю непаладак

Калі праверка не атрымоўваецца, пераканайцеся, што ключ актуальны, мае доступ да абранай вамі мадэлі і не заблакіраваны проксі-серверам або палітыкай арганізацыі. Для рэжыму падпіскі пацвердзіце, што асяроддзе працоўнага стала можа атрымаць доступ да інструментаў пастаўшчыка, які ўвайшоў у сістэму.

## OpenAI і Codex Пытанні

### Ці патрэбны мне ключ OpenAI API для рэжыму падпіскі Codex?

Няма. Рэжым падпіскі Codex выкарыстоўвае доступ да падпіскі ChatGPT Plus або Pro непасрэдна і не патрабуе ключа OpenAI API у ExtraBrain.

### Што ExtraBrain можа адправіць OpenAI або Codex?

Калі абраны для аналізу, ExtraBrain можа адпраўляць падказкі, кантэкст стэнаграмы, кантэкст, атрыманы са скрыншотаў, і карыстальніцкія пытанні, неабходныя для адказу.
