Скарыстайцеся гэтым аглядам, калі вам трэба выбраць кіраўніцтва пастаўшчыка, якое адпавядае вашым наладам. ExtraBrain падтрымлівае пастаўшчыкоў ключоў API, рэжымы пастаўшчыкоў падпіскі і карыстальніцкія канечныя кропкі OpenAI-compatible.

![ExtraBrain Выбар пастаўшчыка AI](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## Ключавыя вывады

Пастаўшчык штучнага інтэлекту ExtraBrain - гэта мадэльны шлях, які праграма выкарыстоўвае, калі ператварае стэнаграму, падказку, скрыншот або кантэкст сеансу ў жывы аналіз.

- ExtraBrain падтрымлівае Google Gemma 4 лакальныя AI, OpenAI, Anthropic, Claude падпіску, Codex падпіску і карыстальніцкія канчатковыя кропкі OpenAI-compatible.
- Ключавыя рэжымы API патрабуюць уліковых дадзеных бягучага пастаўшчыка; рэжымы падпіскі выкарыстоўваюць шлях падпіскі пры ўваходзе ў сістэму, які падтрымліваецца дадаткам.
- Праверку пастаўшчыка трэба правяраць адзін раз перад інтэрв'ю ў прамым эфіры, сустрэчай, лекцыяй або даследчым званком.
- Выстаўленне рахункаў пастаўшчыком, утрыманне, доступ да мадэлі і квота кантралююцца выбраным вамі ўліковым запісам пастаўшчыка.

## Кантрольны спіс наладкі правайдэра

1. Вырашыце, ці хочаце вы рэжым ключа API, рэжым падпіскі або карыстальніцкую канечную кропку.
2. Адкрыйце **Настройкі -> LLM Пастаўшчыкі**.
3. Увядзіце неабходныя дадзеныя пастаўшчыка.
4. Праверце або яшчэ раз праверце злучэнне з правайдэрам.
5. Выканайце адзін тэставы аналіз.
6. Праглядзіце [Як ExtraBrain апрацоўвае даныя] (/help/privacy-security/how-extrabrain-handles-data/), перш чым выкарыстоўваць канфідэнцыяльны кантэкст.

## Пытанні правайдэра

### Ці патрэбны мне ключ API для кожнага рэжыму пастаўшчыка?

Ключавыя рэжымы No. OpenAI і Anthropic API патрабуюць ключоў. Рэжымы падпіскі Claude і падпіскі Codex выкарыстоўваюць доступ па падпісцы і не патрабуюць ключа API у ExtraBrain.

### Што я павінен праверыць, калі праверка пастаўшчыка не праходзіць?

Пацвердзіце ключ, доступ да мадэлі, базавы URL, стан падпіскі і доступ да сеткі. Карыстальніцкія канечныя кропкі таксама маюць патрэбу ў дакладнай назве мадэлі, чаканай канечнай кропкай.
