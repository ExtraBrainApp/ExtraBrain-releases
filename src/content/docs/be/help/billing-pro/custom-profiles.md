Карыстальніцкія профілі - гэта функцыя Pro для захавання шматразовых падказак. Выкарыстоўвайце іх, калі ўбудаваны профіль блізкі, але вам патрэбны больш канкрэтныя паводзіны. ExtraBrain Pro - гэта $9.99/month ($6.99 Заснавальнік), $79/year або $149 Пажыццёвы, з купляй і актывацыяй у **Наладах -> Ліцэнзія**.

![ExtraBrain налады профіляў сканцэнтраваны на карыстальніцкіх элементах кіравання профілем Pro](/assets/screenshots/help/dark/settings-custom-profiles.png)

## Што ўключае карыстацкі профіль

| Поле або кантроль | Прызначэнне |
| --- | --- |
| Імя | Кароткая пазнака паказваецца ў спісе профіляў і ў селектары профіляў. |
| Апісанне | Напамін аб тым, калі выкарыстоўваць профіль. |
| Падкажыце | Падрабязныя інструкцыі аб тым, як ExtraBrain павінен аналізаваць і рэагаваць. |
| Уключаны | Кантралюе, ці даступны карыстальніцкі профіль. |
| Pin | Робіць профіль актыўным замацаваным профілем. |
| Выдаліць | Выдаляе карыстальніцкі профіль з лакальных налад. |

## Налады профілю

Карыстальніцкія профілі таксама могуць кантраляваць паводзіны працоўнага працэсу:

| Налада | Паводзіны |
| --- | --- |
| Разгарнуць акно аналізу | Адкрывае разгорнутае акно, калі профіль пачынае аналіз. |
| Пачаць аналіз пасля скрыншота рэгіёну | Запускае аналіз адразу пасля захопу вобласці. |
| Выкарыстоўвайце поўны кантэкст сеанса | Дае кожнаму аналізу больш гісторыі сеансаў, калі гэты профіль актыўны. |

## Крокі наладкі

1. [Актываваць ExtraBrain Pro](/be/help/billing-pro/activate-license/).
2. Адкрыйце **Настройкі -> Профілі**.
3. Выберыце **Стварыць профіль**.
4. Дадайце назву, апісанне і падказку.
5. Наладзьце параметры профілю.
6. Замацуеце профіль, калі вы хочаце, каб ён быў актыўны па змаўчанні.

Карыстальніцкі тэкст профілю захоўваецца ў лакальных наладах. When you run cloud-provider analysis, relevant prompt guidance, transcript context, screenshot-derived context, and questions may be sent to the provider you selected.

## Агульныя пытанні

### Ці магу я стварыць уласныя профілі без Pro?

Не, бясплатныя карыстальнікі могуць выкарыстоўваць убудаваныя профілі сістэмы. Для стварэння і рэдагавання карыстальніцкіх профіляў патрабуецца Pro.

### Што я павінен змясціць у запыце карыстальніцкага профілю?

Апішыце стыль адказу, абмежаванні і прыярытэты, якім вы хочаце прытрымлівацца ExtraBrain. Захоўвайце яго шматразовым і пазбягайце сакрэтаў.
