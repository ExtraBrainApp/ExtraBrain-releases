Адкрыйце **Настройкі -> Ліцэнзія**, каб купіць, актываваць або кіраваць ExtraBrain Pro. Pro - гэта $9.99/month звычайны ($6.99/month цана заснавальніка для першых карыстальнікаў), $79/year або $149 Пажыццёвы (цана запуску).

![ExtraBrain укладка налад ліцэнзіі](/assets/screenshots/help/dark/settings-license.png)

## Купіце або актывуйце ліцэнзію

1. Адкрыйце **Настройкі -> Ліцэнзія**.
2. Выберыце штомесячны або пажыццёвы варыянт Pro, калі вам усё яшчэ трэба набыць.
3. Устаўце ліцэнзійны ключ, калі ён у вас ужо ёсць.
4. Націсніце **Актываваць**.
5. Дачакайцеся праверкі.
6. Пацвердзіце, што з'явіўся статус Pro.

Выкарыстоўвайце дакладны ліцэнзійны ключ з вашай пакупкі або электроннай пошты ўліковага запісу. Пазбягайце дадавання прабелаў перад або пасля ключа і захоўвайце ключ закрытым, як і любыя іншыя ўліковыя дадзеныя ўліковага запісу.

## Пасля актывацыі

Укладка "Ліцэнзія" можа паказваць статус ліцэнзіі і замаскіраваны ключ. Pro можа разблакіраваць пашыраныя элементы кіравання працоўным працэсам, такія як карыстальніцкія профілі, падказкі для шматразовага выкарыстання, спецыфічныя паводзіны профілю, больш багаты кантэкст сеанса, зводкі пасля сеанса і элементы кіравання прэміум-мадэллю, калі яны ўключаны.

Глядзіце [карыстальніцкія профілі](/be/help/billing-pro/custom-profiles/), калі вам патрэбныя падказкі для шматразовага выкарыстання для пэўнага працоўнага працэсу, стылю інтэрв'ю або фармату сустрэчы.

## Дэактываваць

Выкарыстоўвайце дэактывацыю пры перамяшчэнні ліцэнзіі ў іншую ўстаноўку або пры выдаленні Pro з бягучага Mac.

Выдаткі на выкарыстанне правайдэрам застаюцца асобнымі ад ExtraBrain Pro. OpenAI, Anthropic, Deepgram, Claude, Codex або выдаткі карыстальніцкага пастаўшчыка рэгулююцца гэтымі пастаўшчыкамі.

## Пытанні актывацыі

### Чаму мая ліцэнзія ExtraBrain Pro не актывуецца?

Пераканайцеся, што ключ поўны, устаўлены без дадатковых прабелаў і прызначаны для бягучага ўліковага запісу або прылады ExtraBrain. Таксама пацвердзіце, што Mac можа звязацца са службай праверкі ліцэнзіі.

### Што змяняецца пасля актывацыі ExtraBrain Pro?

Укладка "Ліцэнзія" павінна паказваць актыўны статус Pro. Pro можа разблакіраваць пашыраныя элементы кіравання рабочым працэсам, такія як карыстальніцкія профілі, падказкі для шматразовага выкарыстання, спецыфічныя паводзіны профілю, больш багаты кантэкст сеанса, зводкі пасля сеанса і элементы кіравання прэміум-мадэллю, дзе яны прадстаўлены ў бягучым выпуску.
