Los perfiles personalizados son una característica Pro para guardar orientación rápida reutilizable. Úselos cuando un perfil integrado esté cerca pero desee un comportamiento más específico. ExtraBrain Pro es $9.99/month ($6.99 Fundador), $79/year o $149 de por vida, con compra y activación en **Configuración -> Licencia**.

![ExtraBrain configuración de perfiles centrada en controles de perfil personalizado Pro](/assets/screenshots/help/dark/settings-custom-profiles.png)

## Qué incluye un perfil personalizado

| Campo O Control | Propósito |
| --- | --- |
| Nombre | Etiqueta corta que se muestra en la lista de perfiles y en el selector de perfiles. |
| Descripción | Recordatorio de cuándo utilizar el perfil. |
| Aviso | Orientación detallada sobre cómo ExtraBrain debe analizar y responder. |
| Habilitado | Controla si el perfil personalizado está disponible. |
| Alfiler | Convierte el perfil en el perfil anclado activo. |
| Eliminar | Elimina el perfil personalizado de la configuración local. |

## Configuración de perfil

Los perfiles personalizados también pueden controlar el comportamiento del flujo de trabajo:

| Configuración | Comportamiento |
| --- | --- |
| Ampliar ventana de análisis | Abre la ventana ampliada cuando el perfil comienza a analizarse. |
| Iniciar análisis después de la captura de pantalla de la región | Ejecuta el análisis inmediatamente después de la captura de una región. |
| Usar contexto de sesión completo | Proporciona a cada análisis más historial de sesiones cuando ese perfil está activo. |

## Pasos de configuración

1. [Activar ExtraBrain Pro](/es/help/billing-pro/activate-license/).
2. Abra **Configuración -> Perfiles**.
3. Elija **Crear perfil**.
4. Agregue un nombre, una descripción y un mensaje.
5. Configure los ajustes del perfil.
6. Fija el perfil si quieres que esté activo de forma predeterminada.

El texto del perfil personalizado se almacena en la configuración local. Cuando ejecuta un análisis de proveedor en la nube, es posible que se envíen instrucciones relevantes, contexto de transcripción, contexto derivado de capturas de pantalla y preguntas al proveedor que seleccionó.

## Preguntas comunes

### ¿Puedo crear perfiles personalizados sin Pro?

No. Los usuarios gratuitos pueden utilizar los perfiles integrados del sistema. La creación y edición de perfiles personalizados requiere Pro.

### ¿Qué debo poner en un mensaje de perfil personalizado?

Describe el estilo de respuesta, las limitaciones y las prioridades que deseas que siga ExtraBrain. Mantenlo reutilizable y evita secretos.
