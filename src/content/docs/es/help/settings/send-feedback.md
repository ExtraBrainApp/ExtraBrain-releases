Utilice **Configuración -> Comentarios** para enviar comentarios sobre el producto, informes de errores o contexto de soporte desde dentro de ExtraBrain.

![ExtraBrain configuración de comentarios con mensaje y campos de correo electrónico opcionales](/assets/screenshots/help/dark/settings-feedback.png)

## Qué incluir

| Campo | Recomendación |
| --- | --- |
| Mensaje de comentarios | Describe lo que sucedió, lo que esperabas y el flujo de trabajo que estabas utilizando. |
| Correo electrónico opcional | Agregue un correo electrónico si desea que el soporte realice un seguimiento. |

Para errores, incluya el área de funciones, el proveedor, el modo de transcripción, el estado del permiso macOS y si el problema ocurrió durante la incorporación, la grabación, el análisis, las capturas de pantalla o la configuración.

## Antes de enviar detalles confidenciales

No pegue claves API, indicaciones de entrevistas privadas, datos de clientes ni capturas de pantalla confidenciales en los comentarios. Si el soporte técnico necesita más detalles, comparta solo el contexto mínimo necesario para reproducir el problema.

## Preguntas comunes

### ¿Se requiere correo electrónico?

No. El correo electrónico es opcional, pero agregarlo hace posible el seguimiento.

### ¿Qué hace que un informe de error sea útil?

Incluya los pasos para reproducir, el comportamiento esperado, el comportamiento real, la configuración del proveedor/transcription y si el problema comenzó después de una actualización.
