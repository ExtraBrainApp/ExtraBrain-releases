La configuración de ExtraBrain está organizada por área de flujo de trabajo. Abra la configuración desde la ventana principal, luego elija la pestaña que necesita.

![ExtraBrain pestaña de configuración general](/assets/screenshots/help/dark/settings-general.png)

## Pestañas de configuración pública

| Pestaña | Qué controla |
| --- | --- |
| Generalidades | [Contexto personal, lenguaje de codificación preferido, análisis ampliado y comportamiento de visualización del análisis más reciente](/es/help/settings/general-context-language/). |
| Perfiles | [Asistente, codificación, diseño de sistemas, comportamiento, reuniones y comportamiento de perfil personalizado](/es/help/settings/profiles/). |
| UI | [Tamaño de fuente, opacidad, ajustes preestablecidos de apariencia, sugerencias y tema de bloque de código](/es/help/settings/ui-appearance/). |
| Atajos | Grabación, capturas de pantalla, análisis, seguimientos, controles de ventanas, accesos directos para hacer clic y desplazarse. |
| Audio | [Proveedor de transcripción, clave Deepgram, dispositivo de micrófono, limpieza de transcripción y activador de voz](/es/help/settings/audio-settings/). |
| Captura de pantalla | [Captura de ventana activa versus captura de pantalla completa y captura antes del análisis] (/help/settings/screenshot-settings/). |
| Seguimiento de cámara web | [Controles experimentales de presencia y seguimiento de la mirada](/es/help/settings/webcam-tracking-experimental/) cuando se exponen en la compilación actual. |
| Proveedores de LLM | OpenAI, Anthropic, Claude Suscripción, Codex Suscripción y configuración personalizada de punto final. |
| Sesiones | Historial de sesiones locales, transcripciones, análisis, hechos, capturas de pantalla y eliminación. |
| Privacidad | Protección de captura de pantalla, visibilidad de aplicaciones, clics, retraso del desplazamiento y uso compartido. |
| Actualizaciones | [Preferencia de actualización automática](/es/help/settings/automatic-updates/). |
| Licencia | Pro activación, estado y desactivación de licencia. |
| Comentarios | [Mensaje de comentarios, correo electrónico opcional y estado de envío](/es/help/settings/send-feedback/). |

La pestaña Remoto es solo de desarrollo y no debe documentarse como una característica pública.

## Preguntas de configuración

### ¿Qué configuraciones debo verificar antes de una sesión en vivo?

Marque Audio, Proveedores de LLM, Captura de pantalla, Privacidad y Accesos directos. Estas pestañas controlan la captura, el proveedor, el contexto de la pantalla, la visibilidad y el comportamiento de los comandos con mayor probabilidad de afectar un flujo de trabajo en vivo.

### ¿Debo documentar o utilizar la pestaña Configuración remota?

No. La pestaña Remoto es solo de desarrollo y no debe tratarse como una función del centro de ayuda pública.
