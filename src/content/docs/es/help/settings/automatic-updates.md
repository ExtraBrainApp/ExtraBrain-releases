Utilice **Configuración -> Actualizaciones** para controlar si ExtraBrain busca y aplica actualizaciones de aplicaciones automáticamente.

![ExtraBrain actualiza la configuración con alternancia de actualización automática](/assets/screenshots/help/dark/settings-updates.png)

## ¿Qué hacen las actualizaciones automáticas?

| Controlar | Comportamiento |
| --- | --- |
| Actualizaciones automáticas | Permitamos que ExtraBrain busque compilaciones más nuevas y prepare actualizaciones en segundo plano. |
| Notificación de actualización | ExtraBrain le notifica antes de que sea necesario aplicar una actualización. |

Las actualizaciones automáticas ayudan a mantener actualizadas las integraciones de proveedores, el manejo de permisos y las correcciones de aplicaciones. Si los desactiva, verifique las versiones manualmente antes de sesiones importantes.

## Flujo de trabajo recomendado

1. Mantenga las actualizaciones automáticas habilitadas para un uso normal.
2. Reinicie o reinicie cuando ExtraBrain solicite terminar de aplicar una actualización.
3. Antes de una sesión crítica, abra ExtraBrain con suficiente anticipación para permitir que finalice cualquier actualización pendiente.

## Preguntas comunes

### ¿Puedo usar ExtraBrain mientras se descarga una actualización?

Sí. Las actualizaciones se preparan en segundo plano. Aplíquelos cuando se le solicite y cuando sea seguro reiniciar la aplicación.

### ¿Debo desactivar las actualizaciones antes de una sesión en vivo?

Generalmente no. En su lugar, abra ExtraBrain con anticipación y confirme que esté listo antes de que comience la sesión.
