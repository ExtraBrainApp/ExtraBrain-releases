Utilice **Configuración -> Captura de pantalla** para controlar cómo ExtraBrain captura el contexto de la pantalla.

![ExtraBrain configuración de captura de pantalla con controles del modo de captura](/assets/screenshots/help/dark/settings-screenshot.png)

## Controles de captura de pantalla

| Configuración | Comportamiento |
| --- | --- |
| Ventana activa | Captura la ventana activa actual cuando sea posible. |
| Pantalla completa | Captura un contexto de pantalla más amplio. |
| Captura antes del análisis | Toma una captura de pantalla automáticamente antes de que comience el análisis. |

## Elegir un modo

Utilice la captura de ventana activa cuando desee que ExtraBrain se centre en la aplicación o ventana del navegador que está analizando. Utilice la captura de pantalla completa cuando el contexto relevante abarque varias áreas visibles. Utilice la captura antes del análisis cuando el contexto de la pantalla suele ser parte de la pregunta y no desea presionar Capturar manualmente.

Se pueden utilizar capturas de pantalla y contexto derivado de capturas de pantalla en los mensajes enviados al proveedor de IA seleccionado cuando solicita un análisis.

## Preguntas comunes

### ¿Por qué no aparecen las capturas de pantalla?

Verifique el permiso de grabación de pantalla macOS, confirme que hay una sesión activa y verifique que el modo de captura seleccionado se ajuste a la aplicación que está intentando capturar.

### ¿Debería habilitar la captura antes del análisis?

Habilítelo cuando el contexto de la pantalla sea casi siempre relevante. Déjelo desactivado cuando normalmente desee realizar un análisis solo de transcripción.
