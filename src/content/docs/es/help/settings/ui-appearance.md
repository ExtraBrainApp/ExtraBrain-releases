Utilice **Configuración -> UI** para ajustar el aspecto de ExtraBrain durante el uso repetido en vivo.

![ExtraBrain UI configuración con controles de tema de apariencia y código](/assets/screenshots/help/dark/settings-ui.png)

## Controles de apariencia

| Controlar | Lo que cambia |
| --- | --- |
| Tamaño de fuente | Densidad de texto en toda la aplicación. |
| Opacidad | Transparencia de la ventana principal. |
| Ajustes preestablecidos de apariencia | Paleta de colores de ventana. |
| Consejos | Si aparecen sugerencias en la aplicación. |
| Tema de bloque de código | Estilo de resaltado de sintaxis para el código que se muestra en las respuestas. |

## Configuración recomendada

1. Elija un tamaño de fuente que pueda leer rápidamente bajo presión.
2. Mantenga la opacidad alta si realiza capturas de pantalla de la documentación o necesita la máxima legibilidad.
3. Elija un ajuste preestablecido de apariencia que funcione con las aplicaciones que utiliza con más frecuencia.
4. Elija un tema de bloque de código que mantenga la sintaxis legible en su flujo de trabajo actual claro u oscuro.
5. Desactive las sugerencias una vez que conozca los controles principales.

La opacidad y la apariencia afectan la visibilidad. No cambian lo que ExtraBrain almacena localmente ni lo que puede enviarse a los proveedores seleccionados durante el análisis.

## Preguntas comunes

### ¿Debería reducir la opacidad durante las entrevistas o reuniones?

Solo si te ayuda a mantener el contexto visible. Para mejorar la legibilidad, realizar capturas de pantalla y reducir el ruido visual, la opacidad 100% suele ser mejor.

### ¿El tema del bloque de código afecta la respuesta del modelo?

No. Solo cambia la forma en que se muestra el código en la aplicación.
