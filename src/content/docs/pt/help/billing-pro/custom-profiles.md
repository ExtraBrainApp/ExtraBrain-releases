Perfis personalizados são um recurso Pro para salvar orientações imediatas reutilizáveis. Use-os quando um perfil integrado estiver próximo, mas você desejar um comportamento mais específico. ExtraBrain Pro é $9.99/month ($6.99 Fundador), $79/year ou $149 Vitalício, com compra e ativação em **Configurações -> Licença**.

![ExtraBrain configurações de perfis focadas em controles Pro de perfil personalizado](/assets/screenshots/help/dark/settings-custom-profiles.png)

## O que um perfil personalizado inclui

| Campo ou controle | Finalidade |
| --- | --- |
| Nome | Rótulo curto mostrado na lista de perfis e no seletor de perfis. |
| Descrição | Lembrete de quando usar o perfil. |
| Alerta | Orientação detalhada sobre como ExtraBrain deve analisar e responder. |
| Habilitado | Controla se o perfil personalizado está disponível. |
| Pino | Torna o perfil o perfil fixado ativo. |
| Excluir | Remove o perfil personalizado das configurações locais. |

## Configurações de perfil

Perfis personalizados também podem controlar o comportamento do fluxo de trabalho:

| Configuração | Comportamento |
| --- | --- |
| Expandir janela de análise | Abre a janela expandida quando o perfil inicia a análise. |
| Iniciar análise após captura de tela da região | Executa a análise imediatamente após a captura de uma região. |
| Usar contexto de sessão completo | Fornece a cada análise mais histórico de sessão quando esse perfil está ativo. |

## Etapas de configuração

1. [Ativar ExtraBrain Pro](/pt/help/billing-pro/activate-license/).
2. Abra **Configurações -> Perfis**.
3. Escolha **Criar perfil**.
4. Adicione um nome, uma descrição e um prompt.
5. Defina as configurações do perfil.
6. Fixe o perfil se desejar que ele esteja ativo por padrão.

O texto do perfil personalizado é armazenado nas configurações locais. Ao executar a análise do provedor de nuvem, orientações imediatas relevantes, contexto de transcrição, contexto derivado de captura de tela e perguntas podem ser enviadas ao provedor selecionado.

## Perguntas comuns

### Posso criar perfis personalizados sem Pro?

Não. Usuários gratuitos podem usar os perfis de sistema integrados. A criação e edição de perfis personalizados requer Pro.

### O que devo colocar em um prompt de perfil personalizado?

Descreva o estilo de resposta, restrições e prioridades que você deseja que ExtraBrain siga. Mantenha-o reutilizável e evite segredos.
