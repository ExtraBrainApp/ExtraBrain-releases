Os perfis informam ao ExtraBrain que tipo de ajuda ao vivo priorizar. Abra **Configurações -> Perfis** para escolher o comportamento do perfil automático ou fixado.

![ExtraBrain configurações de perfis com controles de sistema e de perfil personalizado](/assets/screenshots/help/dark/settings-profiles.png)

## Perfis do sistema

| Perfil | Use-o para |
| --- | --- |
| Assistente | Ajuda geral ao vivo em conversas mistas. |
| Codificação | Perguntas de implementação, depuração, revisão de código e discussão de algoritmos. |
| Projeto de sistema | Arquitetura, compensações, escalabilidade, confiabilidade e restrições de produto. |
| Comportamental | Histórias de experiência, estrutura estilo STAR, conflito, liderança e trabalho em equipe. |
| Reunião | Resumos, decisões, riscos, acompanhamentos e contribuições para reuniões ao vivo. |

## Auto Vs Fixado

| Modo | Comportamento |
| --- | --- |
| Automóvel | ExtraBrain escolhe entre os perfis de sistema habilitados com base no contexto detectado. |
| Fixado | ExtraBrain permanece no perfil selecionado até você alterá-lo. |

O modo automático é útil quando uma sessão alterna entre tópicos. O modo fixado é melhor quando toda a sessão tem um formato claro, como uma entrevista de codificação ou uma rodada de design de sistema.

## Gerenciando Perfis

- Desative os perfis do sistema que você não deseja que a detecção automática use.
- Fixe um perfil quando desejar um estilo de resposta estável.
- Percorra os perfis na janela principal quando precisar alternar rapidamente.
- Use [perfis personalizados](/pt/help/billing-pro/custom-profiles/) quando Pro estiver ativo e você precisar de orientação imediata reutilizável além dos perfis integrados.

## Perguntas comuns

### Devo usar o modo Automático ou Fixado?

Use Auto para reuniões mistas e sessões exploratórias. Use Fixado quando o formato da sessão for previsível e você quiser respostas consistentes.

### Os perfis personalizados são usados no modo Automático?

Não. A detecção automática usa perfis de sistema. Perfis personalizados são usados quando selecionados ou fixados.
