Use **Configurações -> Feedback** para enviar feedback sobre o produto, relatórios de bugs ou contexto de suporte de dentro de ExtraBrain.

![ExtraBrain configurações de feedback com mensagem e campos de e-mail opcionais](/assets/screenshots/help/dark/settings-feedback.png)

## O que incluir

| Campo | Recomendação |
| --- | --- |
| Mensagem de feedback | Descreva o que aconteceu, o que você esperava e o fluxo de trabalho que estava usando. |
| E-mail opcional | Adicione um e-mail se desejar suporte para acompanhamento. |

Para bugs, inclua a área de recursos, provedor, modo de transcrição, estado de permissão macOS e se o problema ocorreu durante a integração, gravação, análise, capturas de tela ou configurações.

## Antes de enviar detalhes confidenciais

Não cole chaves API, solicitações de entrevistas privadas, dados de clientes ou capturas de tela confidenciais no feedback. Se o suporte precisar de mais detalhes, compartilhe apenas o contexto mínimo necessário para reproduzir o problema.

## Perguntas comuns

### O e-mail é obrigatório?

Não. O e-mail é opcional, mas adicioná-lo torna possível o acompanhamento.

### O que torna um relatório de bug útil?

Inclua etapas para reproduzir, comportamento esperado, comportamento real, configurações do provedor/transcription e se o problema começou após uma atualização.
