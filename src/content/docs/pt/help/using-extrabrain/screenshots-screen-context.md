As capturas de tela ajudam ExtraBrain a entender códigos, prompts, diagramas, slides, terminais, páginas do navegador e outros contextos visuais.

![Entrada de captura de tela em uma transcrição ExtraBrain](/assets/screenshots/help/dark/main-screenshot-entry.png)

## Modos de captura

Abra **Configurações -> Captura de tela** para escolher como as capturas de tela funcionam.

![Guia configurações de captura de tela](/assets/screenshots/help/dark/settings-screenshot.png)

| Configuração | Use-o quando |
| --- | --- |
| Janela ativa | Você deseja que as capturas de tela tenham como escopo a janela atual do aplicativo. |
| Tela inteira | Você precisa de um contexto de área de trabalho mais amplo. |
| Captura antes da análise | Você deseja que ExtraBrain capture automaticamente uma captura de tela antes de executar a análise. |

## Durante uma sessão

1. Comece a gravar.
2. Clique em **Capturar**.
3. Confirme se a entrada da captura de tela aparece no painel de transcrição.
4. Clique em **Perguntar** para incluir o contexto atual na análise.

Se uma captura de tela não aparecer, confirme se a sessão está ativa e se a permissão de gravação de tela macOS foi concedida.

## Excluir capturas de tela

Use a exclusão de captura de tela quando capturar o contexto errado ou não quiser que uma captura de tela seja mantida no registro da sessão local.

## Fluxo de dados

As capturas de tela são armazenadas localmente como artefatos de sessão. Quando você solicita análise a um provedor de nuvem, o contexto derivado da captura de tela pode ser enviado ao provedor selecionado.

## Perguntas sobre captura de tela

### Devo usar captura de janela ativa ou tela inteira?

Use a captura de janela ativa quando desejar um contexto mais restrito do aplicativo atual. Use a captura de tela inteira somente quando a visualização mais ampla da área de trabalho for relevante e aceitável para a sessão.

### Por que as capturas de tela não aparecem na análise?

Verifique se a gravação está ativa, se a permissão de gravação de tela foi concedida e se uma entrada de captura de tela aparece no painel de transcrição antes do início da análise.
