**설정 -> 세션**을 열어 저장된 로컬 세션 기록을 검토하세요.

![ExtraBrain 세션 설정 탭](/assets/screenshots/help/dark/settings-sessions.png)

## 세션 기록에 표시되는 내용

세션 기록에는 다음이 포함될 수 있습니다.

- 세션 요약
- 성적표 항목
- 복수
- 사리
- 스크린샷
- 항목 수 및 타임스탬프

## 세션 삭제

1. **설정 -> 세션**을 엽니다.
2. 세션을 선택합니다.
3. 삭제를 클릭하세요.
4. 삭제를 확인하세요.

삭제하면 관련 분석, 항목, 스크린샷 및 사실을 포함하여 선택한 세션 기록이 제거됩니다.

## 삭제가 비활성화될 수 있는 이유

활성 세션은 삭제할 수 없습니다. 먼저 녹음을 중지한 다음 설정 -> 세션으로 돌아갑니다.

## 개인정보 보호정책

세션 기록은 Mac에 로컬입니다. 민감한 기록이나 스크린샷 아티팩트가 여전히 포함될 수 있으므로 더 이상 보관하지 않으려는 세션을 삭제하세요.

## 세션 기록 질문

### 활성 ExtraBrain 세션을 삭제할 수 있나요?

아니요. 먼저 녹음을 중지한 다음 **설정 -> 세션**으로 돌아가세요. 활성 세션은 보호되므로 기록 및 지속성이 삭제와 충돌하지 않습니다.

### 세션을 삭제하면 무엇이 제거되나요?

선택한 로컬 세션 기록은 해당 기록, 분석, 사실, 스크린샷, 항목 및 관련 개수와 함께 제거됩니다.
