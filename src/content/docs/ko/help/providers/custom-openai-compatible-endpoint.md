공급자 또는 프록시가 OpenAI 스타일 API을 노출하는 경우 사용자 지정 OpenAI-compatible 엔드포인트를 사용하세요.

![ExtraBrain 기본 URL 및 모델 이름 필드가 있는 사용자 정의 OpenAI-compatible 공급자 설정](/assets/screenshots/help/dark/settings-custom-provider.png)

## 필수항목

| 필드 | 무엇을 입력해야 할까요? |
| --- | --- |
| 기본 URL | 공급자 또는 프록시 API 기본 URL입니다. |
| API 키 | 해당 엔드포인트에 필요한 키입니다. |
| 모델명 | 엔드포인트가 예상하는 정확한 모델 식별자입니다. |

## 설정 단계

1. 온보딩을 열거나 **설정 -> LLM 제공자**를 엽니다.
2. 사용자 정의 공급자 옵션을 선택하십시오.
3. 기본 URL을 입력하세요.
4. API 키를 입력하세요.
5. 모델명을 입력하세요.
6. 구성을 검증합니다.
7. 간단한 테스트 분석을 실행합니다.

## 일반적인 실수

- 공급자가 예상하는 `/v1`이 누락되었습니다.
- API 모델 식별자 대신 모델 표시 이름을 사용합니다.
- 잘못된 공급자 또는 프록시에 대한 키를 붙여넣었습니다.
- 제공자 보존, 청구 및 액세스 규칙은 사용자 정의 엔드포인트 운영자에 의해 제어된다는 사실을 잊어버린 것입니다.

사용자 정의 공급자 요청에는 프롬프트, 스크립트 컨텍스트, 스크린샷에서 파생된 컨텍스트 및 사용자 정의 질문이 포함될 수 있습니다.

## 사용자 정의 엔드포인트 질문

### 엔드포인트를 OpenAI-compatible로 만드는 것은 무엇입니까?

엔드포인트는 ExtraBrain에 입력한 기본 URL, 키 및 모델 이름을 사용하여 채팅 또는 응답에 대한 OpenAI 스타일 API 요청을 수락해야 합니다.

### 사용자 지정 엔드포인트를 저장한 후 무엇을 테스트해야 합니까?

민감하지 않은 기록 또는 스크린샷 컨텍스트를 사용하여 간단한 분석을 실행합니다. 엔드포인트가 응답을 반환하는지, 모델 이름이 공급자 또는 프록시가 예상하는 것과 일치하는지 확인하세요.
