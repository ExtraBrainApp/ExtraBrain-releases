## 주요 시사점

ExtraBrain 개인 정보 보호는 전사, 스크린샷, 프롬프트, 모델 요청, 공급자 자격 증명 및 로컬 세션 기록을 위해 선택한 데이터 경로에 의해 제어됩니다.

- 로컬 Parakeet 전사는 Mac에서 음성-텍스트 작업을 유지할 수 있습니다.
- 로컬 Gemma 4는 설치되고 Mac과 호환되는 경우 AI 프롬프트를 로컬로 유지할 수 있습니다.
- 외부 모델 제공자는 ExtraBrain에게 사용을 요청하면 기록 텍스트, 스크린샷에서 파생된 컨텍스트, 프롬프트 및 메모를 받을 수 있습니다.
- 선택 사항인 Deepgram은 구성 시 클라우드 기록을 위한 오디오를 수신할 수 있습니다.

- [ExtraBrain이 데이터를 처리하는 방법](/ko/help/privacy-security/how-extrabrain-handles-data/)
- [개인정보 보호 제어](/ko/help/privacy-security/privacy-controls/)
- [앱 가격 및 제공업체 비용 비교](/ko/pricing/)

ExtraBrain은 Mac에 설정, API 키, 로컬 세션 기록 및 로컬 Parakeet 기록 데이터를 저장합니다. 클라우드 LLM 공급자를 사용하면 관련 텍스트, 스크립트 컨텍스트, 스크린샷에서 파생된 컨텍스트 및 프롬프트가 선택한 공급자에게 전송될 수 있습니다. Deepgram을 선택하면 텍스트 변환을 위해 오디오가 Deepgram로 전송됩니다. 익명 사용 공유를 비활성화할 수 있습니다.

## 개인정보 보호 체크리스트

- 오디오 전사가 Mac에 유지되어야 하는 경우 로컬 Parakeet을 사용합니다.
- 민감한 기록이나 스크린샷에서 파생된 컨텍스트를 보내기 전에 선택한 LLM 제공자를 검토하세요.
- 사용 데이터를 공유하지 않으려면 익명 사용 공유를 비활성화하십시오.
- 더 이상 필요하지 않은 로컬 세션 기록을 삭제하세요.
- AI 지원을 사용하기 전에 인터뷰, 직장, 학교 및 고객 정책을 따르십시오.

## 개인정보 보호 관련 질문

### ExtraBrain은 모든 것을 서버로 보내나요?

아니요. ExtraBrain은 Mac에 설정, API 키 및 로컬 세션 기록을 저장합니다. 클라우드 공급자는 선택한 워크플로가 콘텐츠를 보내는 경우에만 컨텍스트를 받습니다.

### 스크린샷 컨텍스트가 내 Mac을 떠날 수 있나요?

예, 클라우드 LLM 제공자에게 분석을 요청하면 스크린샷에서 파생된 컨텍스트가 전송될 수 있습니다. 개인 정보 보호 제어 및 공급자 선택을 사용하여 세션을 일치시킵니다.
