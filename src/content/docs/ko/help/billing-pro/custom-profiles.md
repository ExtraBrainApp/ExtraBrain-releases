사용자 정의 프로필은 재사용 가능한 프롬프트 지침을 저장하기 위한 Pro 기능입니다. 기본 제공 프로필이 닫혀 있지만 보다 구체적인 동작을 원할 때 사용하세요. ExtraBrain Pro은(는) $9.99/month($6.99 창립자), $79/year 또는 $149 평생이며 **설정 -> 라이선스**에서 구매 및 활성화할 수 있습니다.

![사용자 정의 프로필 Pro 컨트롤에 초점을 맞춘 ExtraBrain 프로필 설정](/assets/screenshots/help/dark/settings-custom-profiles.png)

## 사용자 정의 프로필에 포함되는 내용

| 필드 또는 컨트롤 | 목적 |
| --- | --- |
| 이름 | 프로필 목록 및 프로필 선택기에 표시되는 짧은 레이블입니다. |
| 설명 | 프로필을 언제 사용해야 하는지 알려줍니다. |
| 즉각적인 | ExtraBrain이 어떻게 분석하고 대응해야 하는지에 대한 자세한 지침입니다. |
| 활성화됨 | 사용자 정의 프로필을 사용할 수 있는지 여부를 제어합니다. |
| 핀 | 프로필을 활성 고정 프로필로 만듭니다. |
| 삭제 | 로컬 설정에서 사용자 정의 프로필을 제거합니다. |

## 프로필 설정

사용자 정의 프로필은 작업 흐름 동작을 제어할 수도 있습니다.

| 환경 | 행동 |
| --- | --- |
| 분석 창 확장 | 프로필이 분석을 시작하면 확장된 창이 열립니다. |
| 지역 스크린샷 후 분석 시작 | 영역 캡처 후 즉시 분석을 실행합니다. |
| 전체 세션 컨텍스트 사용 | 해당 프로필이 활성화되면 각 분석에 더 많은 세션 기록을 제공합니다. |

## 설정 단계

1. [ExtraBrain Pro 활성화](/ko/help/billing-pro/activate-license/).
2. **설정 -> 프로필**을 엽니다.
3. **프로필 만들기**를 선택합니다.
4. 이름, 설명, 프롬프트를 추가합니다.
5. 프로필 설정을 구성합니다.
6. 기본적으로 프로필을 활성화하려면 프로필을 고정하세요.

사용자 정의 프로필 텍스트는 로컬 설정에 저장됩니다. 클라우드 공급자 분석을 실행하면 관련 프롬프트 지침, 기록 컨텍스트, 스크린샷에서 파생된 컨텍스트 및 질문이 선택한 공급자에게 전송될 수 있습니다.

## 일반적인 질문

### Pro 없이 사용자 정의 프로필을 만들 수 있나요?

아니요. 무료 사용자는 내장된 시스템 프로필을 사용할 수 있습니다. 사용자 정의 프로필을 생성하고 편집하려면 Pro이 필요합니다.

### 사용자 정의 프로필 프롬프트에 무엇을 입력해야 합니까?

ExtraBrain이 따르기를 원하는 응답 스타일, 제약 조건 및 우선 순위를 설명하십시오. 재사용이 가능하도록 유지하고 비밀을 피하세요.
