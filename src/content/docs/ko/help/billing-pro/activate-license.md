**설정 -> 라이선스**를 열어 ExtraBrain Pro을 구매, 활성화 또는 관리하세요. Pro은 $9.99/month 일반(초기 사용자를 위한 $6.99/month Founder 가격), $79/year 또는 $149 평생(출시 가격)입니다.

![ExtraBrain 라이선스 설정 탭](/assets/screenshots/help/dark/settings-license.png)

## 라이센스 구매 또는 활성화

1. **설정 -> 라이센스**를 엽니다.
2. 여전히 구매해야 하는 경우 월간 또는 평생 Pro 옵션을 선택하세요.
3. 라이센스 키가 이미 있는 경우 붙여넣습니다.
4. **활성화**를 클릭합니다.
5. 검증을 기다립니다.
6. Pro 상태가 나타나는지 확인하세요.

구매 또는 계정 이메일에 있는 정확한 라이센스 키를 사용하세요. 키 앞이나 뒤에 공백을 추가하지 말고 다른 계정 자격 증명과 마찬가지로 키를 비공개로 유지하세요.

## 활성화 후

라이센스 탭에는 라이센스 상태와 마스크된 키가 표시될 수 있습니다. Pro은 사용자 정의 프로필, 재사용 가능한 프롬프트 지침, 프로필별 동작, 풍부한 세션 컨텍스트, 세션 후 요약 및 프리미엄 모델 제어(활성화된 경우)와 같은 고급 워크플로 제어를 잠금 해제할 수 있습니다.

특정 작업 흐름, 인터뷰 스타일 또는 회의 형식에 대해 재사용 가능한 프롬프트 지침을 원하는 경우 [맞춤 프로필](/ko/help/billing-pro/custom-profiles/)을 참조하세요.

## 비활성화

라이센스를 다른 설정으로 이동하거나 현재 Mac에서 Pro을 제거할 때 비활성화를 사용하십시오.

공급자 사용 비용은 ExtraBrain Pro과 별도로 유지됩니다. OpenAI, Anthropic, Deepgram, Claude, Codex 또는 맞춤형 제공자 비용은 해당 제공자가 관리합니다.

## 활성화 질문

### 내 ExtraBrain Pro 라이선스가 활성화되지 않는 이유는 무엇입니까?

키가 완전한지, 추가 공백 없이 붙여넣었는지, 현재 ExtraBrain 계정 또는 장치용인지 확인하세요. 또한 Mac이 라이센스 검증 서비스에 접근할 수 있는지 확인하십시오.

### ExtraBrain Pro이 활성화된 후 어떤 변화가 있나요?

라이선스 탭에 활성 Pro 상태가 표시되어야 합니다. Pro은 사용자 정의 프로필, 재사용 가능한 프롬프트 지침, 프로필별 동작, 풍부한 세션 컨텍스트, 세션 후 요약 및 현재 릴리스에서 노출되는 프리미엄 모델 제어와 같은 고급 워크플로 제어를 잠금 해제할 수 있습니다.
