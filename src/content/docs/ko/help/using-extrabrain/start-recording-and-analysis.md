기본 ExtraBrain 창은 녹음, 기록 컨텍스트, 스크린샷 및 분석을 중심으로 구축되었습니다.

![ExtraBrain 라이브 컨트롤이 있는 유휴 기본 창](/assets/screenshots/help/dark/main-idle-controls.png)

## 주요 컨트롤

| 제어 | 그것이 하는 일 |
| --- | --- |
| 녹음 시작 | 라이브 세션을 시작하고 활성화된 오디오 소스 캡처를 시작합니다. |
| 멈추다 | 활성 세션을 종료합니다. |
| 묻다 | 분석을 위해 선택한 AI 제공자에게 현재 컨텍스트를 보냅니다. |
| 포착 | 활성 세션에 스크린샷을 추가합니다. |
| 확장 또는 축소 | 소형 창 레이아웃과 확장 창 레이아웃 사이를 전환합니다. |

## 기본 작업 흐름

1. 통화가 시작되기 전에 ExtraBrain을(를) 열어보세요.
2. **녹화 시작**을 클릭합니다.
3. 성적표 항목이나 감지된 주제 카드를 기다립니다.
4. 화면 상황이 중요한 경우 **캡처**를 클릭하세요.
5. 분석을 요청하려면 **질문**을 클릭하세요.
6. 후속 조치를 사용하거나 맞춤 질문을 입력하세요.

![ExtraBrain 감지된 주제로 녹음](/assets/screenshots/help/dark/main-recording-topic.png)

## 버튼이 비활성화된 경우

ExtraBrain이 공급자 액세스를 시작, 중지, 분석, 검증하는 동안 또는 필요한 권한 및 세션 상태를 기다리는 동안 버튼을 비활성화할 수 있습니다. 버튼이 계속 비활성화된 경우 [문제 해결](/ko/help/troubleshooting/)을 확인하세요.

중요한 세션 전에 [오디오 설정](/ko/help/settings/audio-settings/), [스크린샷 설정](/ko/help/settings/screenshot-settings/) 및 [프로필](/ko/help/settings/profiles/)을 검토하세요.

## 개인정보 보호 알림

클라우드 LLM 제공자를 선택한 상태에서 **질문**을 클릭하면 관련 기록 텍스트, 스크린샷에서 파생된 컨텍스트, 프롬프트 및 맞춤 질문이 해당 제공자에게 전송될 수 있습니다.

## 녹음 질문

### 언제 질문을 클릭해야 합니까?

유용한 스크립트 컨텍스트, 감지된 주제, 감지된 질문 또는 스크린샷을 사용할 수 있으면 **묻기**를 클릭하세요. 빠른 프롬프트를 위해 최소한의 맥락으로 질문할 수도 있습니다.

### 녹음을 중단하면 어떻게 되나요?

ExtraBrain은 활성 세션을 종료합니다. 로컬 세션 기록은 나중에 해당 세션을 삭제하지 않는 한 기록, 분석, 스크린샷, 사실 및 항목을 유지할 수 있습니다.
