스크린샷은 ExtraBrain이 코드, 프롬프트, 다이어그램, 슬라이드, 터미널, 브라우저 페이지 및 기타 시각적 컨텍스트를 이해하는 데 도움이 됩니다.

![ExtraBrain 성적표의 스크린샷 항목](/assets/screenshots/help/dark/main-screenshot-entry.png)

## 캡처 모드

**설정 -> 스크린샷**을 열어 스크린샷 작동 방식을 선택하세요.

![스크린샷 설정 탭](/assets/screenshots/help/dark/settings-screenshot.png)

| 환경 | 언제 사용하세요 |
| --- | --- |
| 활성 창 | 현재 앱 창 범위의 스크린샷을 원합니다. |
| 전체 화면 | 더 넓은 데스크탑 컨텍스트가 필요합니다. |
| 분석 전 캡처 | 분석을 실행하기 전에 ExtraBrain이 자동으로 스크린샷을 캡처하기를 원합니다. |

## 세션 중

1. 녹음을 시작하세요.
2. **캡처**를 클릭합니다.
3. 스크립트 패널에 스크린샷 항목이 나타나는지 확인합니다.
4. 분석에 현재 컨텍스트를 포함하려면 **질문**을 클릭하세요.

스크린샷이 나타나지 않으면 세션이 활성 상태이고 macOS 화면 녹화 권한이 부여되었는지 확인하세요.

## 스크린샷 삭제

잘못된 컨텍스트를 캡처했거나 로컬 세션 기록에 스크린샷을 보관하고 싶지 않은 경우 스크린샷 삭제를 사용하세요.

## 데이터 흐름

스크린샷은 세션 아티팩트로 로컬에 저장됩니다. 클라우드 제공자에게 분석을 요청하면 스크린샷에서 파생된 컨텍스트가 선택한 제공자에게 전송될 수 있습니다.

## 스크린샷 질문

### 활성 창 또는 전체 화면 캡처를 사용해야 합니까?

현재 앱의 컨텍스트를 더 좁히려면 활성 창 캡처를 사용하세요. 더 넓은 데스크탑 보기가 세션에 적합하고 허용되는 경우에만 전체 화면 캡처를 사용하십시오.

### 분석에 스크린샷이 표시되지 않는 이유는 무엇입니까?

분석이 시작되기 전에 녹화가 활성화되어 있는지, 화면 녹화 권한이 부여되었는지, 스크립트 패널에 스크린샷 항목이 나타나는지 확인하세요.
