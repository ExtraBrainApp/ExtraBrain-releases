ExtraBrain의 핵심 Mac 앱은 공급자 청구와 별도로 사용할 수 있습니다. 외부 공급자 사용 비용은 OpenAI, Anthropic, Deepgram, Claude, Codex 또는 사용자 지정 엔드포인트 등 귀하가 선택한 공급자에 따라 결정됩니다.

![ExtraBrain 라이선스 설정 탭](/assets/screenshots/help/dark/settings-license.png)

## 주요 시사점

ExtraBrain 청구는 Mac 앱 워크플로를 외부 모델 및 전사 계정과 분리하므로 앱 액세스, Pro 기능 및 공급자 사용량을 별도의 비용 범주로 검토해야 합니다.

- 핵심 Mac 작업 흐름은 무료로 사용할 수 있습니다.
- ExtraBrain Pro은 $9.99/month 일반(초기 사용자를 위한 $6.99/month Founder 가격), $79/year 또는 $149 평생(출시 가격)입니다.
- 구매, 활성화, 상태, 비활성화는 앱 내부의 **설정 -> 라이선스**에서 처리됩니다.
- 공급자 비용은 OpenAI, Anthropic, Deepgram, Claude, Codex 또는 연결하는 사용자 지정 엔드포인트에 의해 제어됩니다.
- Pro은 사용자 정의 프로필, 재사용 가능한 프롬프트 지침, 더욱 풍부한 세션 컨텍스트, 요약 및 활성화된 프리미엄 제어와 같은 워크플로 제어용입니다.
- Pro을 활성화해도 공급자 보존, 로깅, 할당량 및 청구는 자동으로 변경되지 않습니다.

## 무료 핵심 제품

무료 핵심 워크플로에는 데스크톱 앱, 로컬 세션 흐름, BYO 공급자 설정, 로컬 Parakeet 기록, 스크린샷 및 기본 라이브 분석 제어가 포함됩니다. 이는 자체 공급자 액세스를 사용하고 ExtraBrain 자체를 모델 청구와 별도로 유지하려는 경우 올바른 경로입니다.

## 공급자 비용

공급자 청구는 ExtraBrain과 별개입니다. 클라우드 LLM 제공자를 사용하는 경우 선택한 프롬프트, 스크립트 컨텍스트, 스크린샷에서 파생된 컨텍스트 및 사용자 정의 질문이 해당 제공자에게 전송될 수 있습니다. Deepgram을 사용하면 텍스트 변환을 위해 오디오가 Deepgram로 전송됩니다.

## Pro

Pro은(는) $9.99/month($6.99 창립자), $79/year 또는 $149 평생입니다. Pro은 사용자 정의 프로필, 재사용 가능한 프롬프트 지침, 프로필별 동작, 풍부한 세션 컨텍스트, 세션 후 요약 및 활성화된 경우 프리미엄 모델 제어와 같은 워크플로 기능을 잠금 해제할 수 있습니다. Pro은 ExtraBrain의 작동 방식을 보다 효과적으로 제어할 수 있는 반복 가능한 인터뷰, 회의 및 분석 워크플로를 원하는 사용자를 위한 것입니다.

앱에서 **설정 -> 라이선스**를 열어 Pro를 구매, 활성화, 상태 확인 또는 비활성화하세요. 라이선스 설정을 위해 [ExtraBrain Pro 활성화](/ko/help/billing-pro/activate-license/)를 사용하거나 [ExtraBrain 무료 및 Pro](/ko/pricing/free-vs-pro/)을 비교하세요.

## 비용 체크리스트

- ExtraBrain 앱 액세스와 공급자 사용은 별개입니다.
- 로컬 Parakeet 전사에는 Deepgram API 키가 필요하지 않습니다.
- Deepgram 사용량은 Deepgram 계정에 의해 제어됩니다.
- OpenAI, Anthropic, Claude, Codex 및 사용자 정의 엔드포인트 사용은 해당 공급자에 의해 제어됩니다.
- Pro은 ExtraBrain 워크플로 기능을 잠금 해제합니다. 공급자 유지 또는 청구를 자동으로 변경하지 않습니다.
- 무료 및 Pro 세부 정보는 [ExtraBrain 무료 및 Pro](/ko/pricing/free-vs-pro/)에 게시됩니다.

## 기업

팀 출시, 정책, 배포 또는 사용자 정의 워크플로 질문이 있는 경우 [info@extrabrain.app](mailto:info@extrabrain.app?subject=ExtraBrain%20enterprise%20inquiry)에 문의하세요.

## 청구 관련 질문

### ExtraBrain Pro에는 AI 공급자 크레딧이 포함되나요?

아니요. ExtraBrain이 향후 계획에 대해 명시적으로 달리 명시하지 않는 한 공급자 사용은 별개입니다. 사용하는 공급자 계정에 구성된 공급자 할당량, 청구 한도 및 조직 정책을 유지하세요.

### 내 API 키를 사용하려면 Pro이 필요합니까?

아니요. 자체 제공업체 가져오기 설정은 핵심 작업 흐름의 일부입니다. Pro은 활성화된 경우 사용자 정의 프로필 및 프리미엄 모델 제어와 같은 고급 워크플로 제어용입니다.
