**설정 -> 바로가기**를 열어 바로가기를 보거나 편집하거나 재설정하세요.

![ExtraBrain 단축키 설정 탭](/assets/screenshots/help/dark/settings-shortcuts.png)

## 기본 단축키

ExtraBrain은 macOS-우선이므로 아래 기본값은 사용자가 누르는 Mac 키를 보여줍니다: <kbd>⌘</kbd> 명령, <kbd>⌥</kbd> 옵션 및 <kbd>⇧</kbd> Shift.

| 행동 | 기본 |
| --- | --- |
| 녹화 전환 | <kbd>⌘</kbd><kbd>⌥</kbd><kbd>R</kbd> |
| 스크린샷 캡처 | <kbd>⌘</kbd><kbd>⌥</kbd><kbd>S</kbd> |

## 편집 또는 재설정

바로가기 탭을 사용하여 개별 바로가기를 편집하거나 모든 바로가기를 기본값으로 재설정합니다. 기본 UI에서 컨트롤 근처에 사용 가능한 바로 가기를 표시하려면 바로 가기 힌트를 활성화하세요.

## 바로가기 질문

### 기본 창에서 바로가기 힌트를 숨길 수 있나요?

예. 더 깔끔한 라이브 인터페이스나 문서 스크린샷을 원한다면 **설정 -> 바로가기**를 열고 바로가기 힌트를 끄세요.

### 어떤 단축키를 먼저 배워야 할까요?

토글 녹화, 스크린샷 캡처, 분석 토글, 창 토글, 클릭 연결 토글로 시작하세요. 이러한 제어는 가장 일반적인 라이브 세션 복구 경로를 다룹니다.
