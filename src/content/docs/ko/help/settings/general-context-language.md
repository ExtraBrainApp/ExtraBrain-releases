**설정 -> 일반**을 사용하여 ExtraBrain에게 자신에 대한 안정적인 컨텍스트를 제공하고 라이브 세션 중에 분석이 표시되는 방식을 조정하세요.

![ExtraBrain 개인 상황 및 언어 제어가 포함된 일반 설정](/assets/screenshots/help/dark/settings-general.png)

## 구성할 내용

| 환경 | 무엇이 바뀌는가 |
| --- | --- |
| 귀하의 상황 | 배경 ExtraBrain은 귀하의 역할, 인터뷰 목표 또는 선호하는 의사소통 스타일과 같은 답변을 생성할 때 사용할 수 있습니다. |
| 선호하는 언어 | 프로그래밍 언어 ExtraBrain은 코딩 컨텍스트가 모호할 때 가정해야 합니다. |
| 분석 창 확장 | 새 분석이 시작되면 확장된 두 패널 보기가 열립니다. |
| 최신 분석만 표시 | 이전 답변을 쌓는 대신 최신 답변에 집중하여 분석 패널을 유지합니다. |

## 권장 설정

1. 귀하의 상황에 맞는 답변을 제공하는 데 도움이 되는 간결한 맥락을 추가하세요.
2. 가장 자주 사용하는 코딩 언어를 선택하세요.
3. 답변을 즉시 표시하려면 **분석 창 확장**을 활성화 상태로 유지하세요.
4. 보다 조용한 라이브 워크플로를 선호하는 경우 **최신 분석만 표시**를 활성화하세요.
5. 짧은 테스트 기록을 시작하고 분석을 요청하여 동작을 확인하십시오.

좋은 맥락은 구체적이지만 과부하되지는 않습니다. 예를 들어 귀하의 역할, 대상 인터뷰 유형, 제품 영역 또는 연설 선호도를 포함하십시오. 선택한 AI 공급자에게 전송되는 메시지에 포함하고 싶지 않은 비밀, 고객 데이터 또는 세부 정보를 추가하지 마세요.

## 일반적인 질문

### 귀하의 컨텍스트에 무엇을 넣어야 합니까?

역할, 인터뷰 유형, 선호하는 코딩 언어, 응답 스타일 등 짧고 지속적인 지침을 사용하세요. 기밀 프로젝트 세부정보를 붙여넣지 마세요.

### 선호하는 언어가 스크린샷보다 우선 적용되나요?

아니요. 맥락이 모호할 때 도움이 됩니다. 스크린샷이나 스크립트에 다른 언어가 명확하게 표시되어 있는 경우에도 ExtraBrain은(는) 해당 시각적 컨텍스트를 계속 사용할 수 있습니다.
