음성 트리거를 사용하면 ExtraBrain이 활성 세션 중에 구성된 짧은 문구를 들으면 분석을 시작할 수 있습니다. **설정 -> 오디오**에서 찾아보세요.

![ExtraBrain 음성 트리거 컨트롤에 초점을 맞춘 오디오 설정](/assets/screenshots/help/dark/settings-voice-trigger.png)

## 작동 방식

| 세부 사항 | 행동 |
| --- | --- |
| 활성 세션만 | ExtraBrain은 녹음이 활성화된 동안에만 트리거 문구를 수신합니다. |
| 문구 목록 | 기본 문구를 사용하거나 자신만의 짧은 문구를 추가할 수 있습니다. |
| 성적표 정리 | 일치하는 트리거 문구는 기록 내역에서 제거되고 트리거된 후 분석 입력에서 제외됩니다. |
| 분석 행위 | 이 문구는 분석을 시작하기 위한 음성 컨트롤처럼 작동합니다. |

## 구문 팁

- 일반적인 대화에서는 나올 것 같지 않은 짧은 문구를 사용하세요.
- 참가자가 자연스럽게 말할 수 있는 일반적인 단어나 문구는 피하십시오.
- 실제 사용하기 전에 짧은 세션에서 문구를 테스트해 보세요.
- 녹음과 동일하게 개인 정보 보호 기대치를 유지하십시오. 트리거 감지를 위해서는 마이크 캡처가 활성화되어야 합니다.

## 일반적인 질문

### 녹음이 중지되면 Voice Trigger가 들을 수 있나요?

아니요. Voice Trigger는 활성 세션 중에만 청취합니다.

### 트리거 문구가 스크립트에 저장되나요?

일치하는 문구는 기록 내역에서 제거되고 트리거된 후 분석 입력에서 제외됩니다.
