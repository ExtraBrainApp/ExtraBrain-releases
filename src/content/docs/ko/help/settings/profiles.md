프로필은 ExtraBrain에게 어떤 종류의 실시간 지원에 우선순위를 두어야 하는지 알려줍니다. **설정 -> 프로필**을 열어 자동 또는 고정된 프로필 동작을 선택하세요.

![ExtraBrain 시스템 및 사용자 정의 프로필 컨트롤을 사용한 프로필 설정](/assets/screenshots/help/dark/settings-profiles.png)

## 시스템 프로필

| 윤곽 | 용도 |
| --- | --- |
| 어시스턴트 | 혼합 대화 전반에 걸친 일반 실시간 도움말입니다. |
| 코딩 | 구현 질문, 디버깅, 코드 검토 및 알고리즘 토론. |
| 시스템 설계 | 아키텍처, 장단점, 확장성, 안정성 및 제품 제약. |
| 행동 | 스토리, STAR식 구조, 갈등, 리더십, 팀워크를 경험해보세요. |
| 회의 | 요약, 결정, 위험, 후속 조치 및 실시간 회의 기여. |

## 자동 대 고정

| 방법 | 행동 |
| --- | --- |
| 자동 | ExtraBrain은 감지된 컨텍스트를 기반으로 활성화된 시스템 프로필 중에서 선택합니다. |
| 고정됨 | ExtraBrain은(는) 프로필을 변경할 때까지 선택한 프로필에 유지됩니다. |

자동 모드는 세션이 주제 간에 이동할 때 유용합니다. 고정 모드는 코딩 인터뷰나 시스템 설계 라운드와 같이 전체 세션의 형식이 명확한 경우 더 좋습니다.

## 프로필 관리

- 자동 감지를 사용하지 않으려는 시스템 프로필을 비활성화합니다.
- 안정적인 응답 스타일을 원할 때 프로필을 고정하세요.
- 빠르게 전환해야 할 경우 기본 창에서 프로필을 순환합니다.
- Pro이 활성화되어 있고 기본 제공 프로필 외에 재사용 가능한 프롬프트 안내가 필요한 경우 [사용자 정의 프로필](/ko/help/billing-pro/custom-profiles/)을 사용하세요.

## 일반적인 질문

### 자동 또는 고정 모드를 사용해야 합니까?

혼합 회의 및 탐색 세션에는 자동을 사용하십시오. 세션 형식을 예측할 수 있고 일관된 답변을 원하는 경우 고정됨을 사용하세요.

### 자동 모드에서 사용자 정의 프로필이 사용됩니까?

아니요. 자동 감지는 시스템 프로필을 사용합니다. 사용자 정의 프로필은 선택하거나 고정할 때 사용됩니다.
