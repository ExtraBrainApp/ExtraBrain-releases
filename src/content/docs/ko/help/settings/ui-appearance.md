반복적인 라이브 사용 중에 ExtraBrain이 어떻게 보이는지 조정하려면 **설정 -> UI**을 사용하세요.

![모양 및 코드 테마 컨트롤이 포함된 ExtraBrain UI 설정](/assets/screenshots/help/dark/settings-ui.png)

## 모양 컨트롤

| 제어 | 무엇이 바뀌는가 |
| --- | --- |
| 글꼴 크기 | 앱 전체의 텍스트 밀도. |
| 불투명 | 메인 창 투명도. |
| 모양 사전 설정 | 창 색상 팔레트. |
| 팁 | 인앱 팁 표시 여부. |
| 코드 블록 테마 | 답변에 표시된 코드의 구문 강조 스타일입니다. |

## 권장 설정

1. 압박감 속에서도 빠르게 읽을 수 있는 글꼴 크기를 선택하세요.
2. 문서 스크린샷을 찍거나 최대한의 가독성이 필요한 경우 불투명도를 높게 유지하세요.
3. 가장 많이 사용하는 앱에 적합한 모양 사전 설정을 선택하세요.
4. 현재의 라이트 워크플로나 다크 워크플로에서 구문을 읽을 수 있게 유지하는 코드 블록 테마를 선택하세요.
5. 핵심 컨트롤을 알고 나면 팁을 비활성화하십시오.

불투명도와 모양은 가시성에 영향을 미칩니다. ExtraBrain이 로컬에 저장하는 내용이나 분석 중에 선택한 공급자에게 전송될 수 있는 내용은 변경되지 않습니다.

## 일반적인 질문

### 인터뷰나 회의 중에 불투명도를 낮춰야 하나요?

컨텍스트를 계속 표시하는 데 도움이 되는 경우에만 가능합니다. 가독성, 스크린샷 및 시각적 노이즈 감소를 위해 일반적으로 100% 불투명도가 더 좋습니다.

### 코드 블록 테마가 모델 응답에 영향을 줍니까?

아니요. 앱에 코드가 표시되는 방식만 변경됩니다.
