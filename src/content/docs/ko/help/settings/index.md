ExtraBrain 설정은 워크플로 영역별로 구성됩니다. 기본 창에서 설정을 연 다음 필요한 탭을 선택하세요.

![ExtraBrain 일반 설정 탭](/assets/screenshots/help/dark/settings-general.png)

## 공개 설정 탭

| 꼬리표 | 제어 대상 |
| --- | --- |
| 일반적인 | [개인 컨텍스트, 선호하는 코딩 언어, 분석 확장 및 최신 분석 표시 동작](/ko/help/settings/general-context-language/). |
| 프로필 | [어시스턴트, 코딩, 시스템 설계, 행동, 회의 및 사용자 정의 프로필 동작](/ko/help/settings/profiles/). |
| UI | [글꼴 크기, 불투명도, 모양 사전 설정, 팁 및 코드 블록 테마](/ko/help/settings/ui-appearance/). |
| 단축키 | 녹화, 스크린샷, 분석, 후속 조치, 창 제어, 클릭 연결 및 스크롤 바로가기. |
| 오디오 | [스크립트 제공자, Deepgram 키, 마이크 장치, 스크립트 정리 및 음성 트리거](/ko/help/settings/audio-settings/). |
| 스크린샷 | [활성 창 대 전체 화면 캡처 및 분석 전 캡처](/ko/help/settings/screenshot-settings/). |
| 웹캠 추적 | 현재 빌드에 노출된 경우 [실험적 존재감 및 시선 추적 컨트롤](/ko/help/settings/webcam-tracking-experimental/). |
| LLM 제공자 | OpenAI, Anthropic, Claude 구독, Codex 구독 및 사용자 정의 엔드포인트 설정. |
| 세션 | 로컬 세션 기록, 녹취록, 분석, 사실, 스크린샷 및 삭제. |
| 은둔 | 스크린샷 보호, 앱 가시성, 클릭연결, 호버 지연 및 사용량 공유. |
| 업데이트 | [자동 업데이트 환경설정](/ko/help/settings/automatic-updates/). |
| 특허 | Pro 라이선스 활성화, 상태 및 비활성화. |
| 피드백 | [피드백 메시지, 선택적 이메일 및 제출 상태](/ko/help/settings/send-feedback/). |

원격 탭은 개발 전용이므로 공개 기능으로 문서화해서는 안 됩니다.

## 설정 질문

### 라이브 세션 전에 어떤 설정을 확인해야 합니까?

오디오, LLM 제공자, 스크린샷, 개인정보 보호 및 바로가기를 확인하세요. 이러한 탭은 캡처, 공급자, 화면 컨텍스트, 가시성 및 라이브 워크플로에 가장 영향을 미칠 수 있는 명령 동작을 제어합니다.

### 원격 설정 탭을 문서화하거나 사용해야 합니까?

아니요. 원격 탭은 개발 전용이므로 공개 도움말 센터 기능으로 취급되어서는 안 됩니다.
