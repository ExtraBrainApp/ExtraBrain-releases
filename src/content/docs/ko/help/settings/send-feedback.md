**설정 -> 피드백**을 사용하여 ExtraBrain 내부에서 제품 피드백, 버그 보고서 또는 지원 컨텍스트를 보내세요.

![ExtraBrain 메시지 및 선택적 이메일 필드가 포함된 피드백 설정](/assets/screenshots/help/dark/settings-feedback.png)

## 포함할 내용

| 필드 | 추천 |
| --- | --- |
| 피드백 메시지 | 무슨 일이 일어났는지, 무엇을 기대했는지, 사용하고 있던 작업 흐름을 설명하세요. |
| 선택적 이메일 | 후속 지원을 받으려면 이메일을 추가하세요. |

버그의 경우 기능 영역, 공급자, 전사 모드, macOS 권한 상태 및 온보딩, 기록, 분석, 스크린샷 또는 설정 중에 문제가 발생했는지 여부를 포함합니다.

## 민감한 세부정보를 보내기 전에

API 키, 비공개 인터뷰 프롬프트, 고객 데이터 또는 기밀 스크린샷을 피드백에 붙여넣지 마십시오. 지원에 더 자세한 내용이 필요한 경우 문제를 재현하는 데 필요한 최소한의 상황만 공유하세요.

## 일반적인 질문

### 이메일이 필수인가요?

아니요. 이메일은 선택 사항이지만 이메일을 추가하면 후속 조치가 가능합니다.

### 유용한 버그 보고서란 무엇입니까?

재현 단계, 예상되는 동작, 실제 동작, 공급자/transcription 설정 및 업데이트 후 문제가 시작되었는지 여부를 포함합니다.
