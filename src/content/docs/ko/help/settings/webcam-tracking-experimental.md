웹캠 추적은 현재 앱에서 실험적 설정 탭으로 나타납니다. 의도적으로 카메라 기반 현재 상태 또는 얼굴 추적 동작을 원하는 경우에만 사용하십시오.

![ExtraBrain 실험적인 웹캠 추적 설정](/assets/screenshots/help/dark/settings-webcam-tracking.png)

## 실험적 통제

| 제어 | 그것이 하는 일 |
| --- | --- |
| 웹캠 추적 활성화 | 실험적 기능을 켜거나 끕니다. |
| 카메라 선택기 | 둘 이상의 카메라 장치를 사용할 수 있는 경우 카메라 장치를 선택합니다. |
| 시사 | 선택한 카메라가 사용 가능한 미리보기를 생성하고 있는지 여부를 표시합니다. |
| 상태 | 장치 액세스 및 감지에 따라 활성, 얼굴 없음, 사용할 수 없음 또는 재시도 상태를 나타냅니다. |
| 설정을 열거나 다시 시도하세요. | 카메라 권한이나 장치 문제를 복구하는 데 도움이 됩니다. |

## 개인 정보 보호 참고 사항

카메라 액세스는 마이크 및 화면 권한과 별개입니다. 이 기능을 활성화하기 전에 macOS 카메라 권한을 검토하고 카메라 기반 동작이 필요하지 않은 경우 비활성화하십시오.

이 기능은 실험적입니다. 자체 설정에서 테스트하지 않은 이상 중요한 작업 흐름에 의존하지 마십시오.

## 일반적인 질문

### ExtraBrain을 사용하려면 웹캠 추적이 필요합니까?

아니요. 녹화, 전사, 스크린샷, 분석, 프로필 및 세션 기록은 웹캠 추적 없이 작동합니다.

### 이 기능을 안정적으로 게시해야 합니까, 아니면 의존해야 합니까?

실험적인 것으로 취급하십시오. 로컬에서 테스트하고 워크플로와 일치하지 않으면 비활성화하세요.
