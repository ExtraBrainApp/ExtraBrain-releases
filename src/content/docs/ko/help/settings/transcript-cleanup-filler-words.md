성적 증명서 정리는 성적 증명서 카드 및 분석 입력 전에 일반적인 필러 단어를 제거합니다. **설정 -> 오디오**에서 찾아보세요.

![ExtraBrain 스크립트 정리 제어에 초점을 맞춘 오디오 설정](/assets/screenshots/help/dark/settings-transcript-cleanup.png)

## 정리가 하는 일

| 제어 | 행동 |
| --- | --- |
| 필러 단어 제거 | 성적표 카드 및 분석 전에 필러를 제거합니다. |
| 추가 보충어 | 자신만의 쉼표로 구분된 필러 용어를 추가합니다. |
| 기본값 미리보기 | ExtraBrain이 이미 제거한 내장 단어를 표시합니다. |

정리는 기본적으로 활성화되어 있습니다. 필러 전용 스니펫을 건너뛰고 "uh" 또는 "um"과 같은 인라인 필러를 제거할 수 있으므로 라이브 스크립트 컨텍스트를 귀하와 모델 모두가 더 쉽게 읽을 수 있습니다.

## 사용자 정의할 시기

환경에서 유용하지 않은 문구, 반복되는 언어 습관 또는 회의실 인공물을 반복적으로 기록하는 경우 사용자 정의 필러 단어를 추가하십시오. 목록을 좁게 유지하세요. 의미 있는 단어를 제거하면 스크립트의 정확성이 떨어질 수 있습니다.

## 일반적인 질문

### 정리하면 저장된 기록이 변경되나요?

정리는 성적표 카드와 분석 입력에 영향을 미칩니다. 저장된 세션 기록은 앱에 표시된 처리된 성적표 항목을 반영합니다.

### 내가 싫어하는 반복되는 단어를 모두 추가해야 하나요?

아니요. 지속적으로 소음이 나는 단어만 추가하세요. 기술적인 논의에서 어떤 단어가 의미를 전달할 수 있다면 그 단어를 생략하세요.
