**설정 -> 업데이트**를 사용하여 ExtraBrain이 앱 업데이트를 자동으로 확인하고 적용할지 여부를 제어하세요.

![ExtraBrain 자동 업데이트 토글로 설정 업데이트](/assets/screenshots/help/dark/settings-updates.png)

## 자동 업데이트의 기능

| 제어 | 행동 |
| --- | --- |
| 자동 업데이트 | ExtraBrain이 최신 빌드를 확인하고 백그라운드에서 업데이트를 준비하도록 합니다. |
| 업데이트 알림 | ExtraBrain은 업데이트를 적용해야 하기 전에 알려줍니다. |

자동 업데이트는 공급자 통합, 권한 처리 및 앱 수정 사항을 최신 상태로 유지하는 데 도움이 됩니다. 비활성화한 경우 중요한 세션 전에 릴리스를 수동으로 확인하세요.

## 권장되는 작업 흐름

1. 일반적인 사용을 위해서는 자동 업데이트를 활성화된 상태로 유지하세요.
2. ExtraBrain에서 업데이트 적용 완료를 요청하면 다시 시작하거나 다시 시작하세요.
3. 중요한 세션 전에 보류 중인 업데이트가 완료될 수 있도록 ExtraBrain을 일찍 엽니다.

## 일반적인 질문

### 업데이트를 다운로드하는 동안 ExtraBrain을 사용할 수 있나요?

예. 업데이트는 백그라운드에서 준비됩니다. 메시지가 표시되고 앱을 다시 시작해도 안전할 때 적용하세요.

### 라이브 세션 전에 업데이트를 비활성화해야 합니까?

보통은 그렇지 않습니다. 대신 ExtraBrain을(를) 미리 열고 세션이 시작되기 전에 준비가 되었는지 확인하세요.
