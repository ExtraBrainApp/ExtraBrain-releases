**설정 -> 개인 정보 보호**를 열어 앱 가시성, 오버레이 동작 및 사용 공유를 제어하세요.

![ExtraBrain 개인 정보 보호 제어](/assets/screenshots/help/dark/settings-privacy.png)

## 사용 가능한 컨트롤

| 제어 | 그것이 하는 일 |
| --- | --- |
| 스크린샷 보호 | 운영 체제에서 지원하는 스크린샷 또는 화면 캡처 컨텍스트에서 오버레이를 숨기는 데 도움이 됩니다. |
| Dock 및 메뉴 막대에서 숨기기 | macOS 앱 크롬에서 눈에 보이는 앱 존재를 줄입니다. |
| 트레이에서 숨기기 | 지원되는 경우 트레이 가시성을 숨깁니다. |
| 클릭연결 모드 | 클릭이 오버레이를 통과하도록 합니다. |
| 호버 동작 지연 | 클릭 연결 워크플로에서 활성화되기 전에 마우스 오버 작업이 대기하는 시간을 제어합니다. |
| 익명의 사용 데이터 공유 | ExtraBrain 개선을 위해 사용 데이터를 공유할지 여부를 제어합니다. |

## 숨겨져 있거나 클릭하기 어려운 창에서 복구하기

창이 숨겨져 있거나 클릭 연결로 인해 상호작용이 어려운 경우:

1. 토글 창 단축키를 사용하세요.
2. 연결이 가능한 경우 설정에서 클릭연결을 비활성화하세요.
3. Dock 또는 메뉴 표시줄 가시성이 활성화된 경우 macOS에서 앱을 다시 엽니다.

개인 정보 보호 제어는 가시성 및 원격 측정에 영향을 미칩니다. 클라우드 공급자 분석이 선택한 컨텍스트를 선택한 공급자에게 보낼 수 있다는 사실은 바뀌지 않습니다.

## 개인정보 보호 관련 질문

### 스크린샷 보호가 제공업체의 개인 정보 보호 설정을 대체합니까?

아니요. 스크린샷 보호는 로컬 가시성 제어입니다. 클라우드 LLM 공급자에게 기록 또는 스크린샷에서 파생된 컨텍스트를 분석하도록 요청할 때 전송될 수 있는 내용은 변경되지 않습니다.

### 민감한 세션 전에 무엇을 해야 합니까?

오디오를 로컬로 유지해야 하는 경우 로컬 Parakeet을 선택하고, 사용하려는 AI 공급자를 확인하고, 필요한 경우 익명 사용 공유를 비활성화하고, 보관하지 않으려는 로컬 세션 기록을 삭제하세요.
