ExtraBrain은 라이브 오디오 및 화면 컨텍스트를 사용하기 전에 macOS 권한이 필요합니다. 온보딩 중에 또는 macOS 시스템 설정에서 이를 부여하세요.

![온보딩 중 ExtraBrain 권한 단계](/assets/screenshots/help/dark/onboarding-permissions.png)

## 권한 ExtraBrain 용도

| 허가 | ExtraBrain이(가) 이를 사용하는 이유 |
| --- | --- |
| 마이크로폰 | 라이브 세션 중에 음성 오디오를 녹음합니다. |
| 화면 녹화 | ExtraBrain에게 분석을 요청한 스크린샷과 화면 컨텍스트를 캡처합니다. |
| 시스템 오디오 | 세션에 시스템 사운드가 필요할 때 회의, 통화 또는 비디오 오디오를 캡처합니다. |

## macOS 설정 열기

1. **시스템 설정**을 엽니다.
2. **개인정보 보호 및 보안**으로 이동하세요.
3. macOS에 표시되는 경우 **마이크**, **화면 녹화** 및 시스템 오디오 관련 프롬프트를 확인하세요.
4. ExtraBrain을 활성화합니다.
5. macOS이 요청하거나 권한 상태가 즉시 업데이트되지 않는 경우 ExtraBrain을 다시 시작합니다.

## 권한이 여전히 차단된 것으로 보이는 경우

- 종료하고 ExtraBrain을 다시 엽니다.
- 시스템 설정에서 권한을 켜고 끕니다.
- 화면 녹화가 계속 중단되면 Mac을 다시 시작하세요.
- 다시 시작한 후 온보딩 또는 설정을 다시 엽니다.

"마이크 중지됨", "시스템 오디오 중지됨" 또는 "오디오 중지됨"과 같은 권한 경고는 ExtraBrain이(가) 캡처 파이프라인의 일부에 대한 액세스 권한을 잃었으며 권한 또는 장치 복구가 필요함을 의미합니다.

## 권한 질문

### ExtraBrain에 화면 녹화 권한이 필요한 이유는 무엇입니까?

화면 기록을 사용하면 ExtraBrain이 분석에 명시적으로 사용하는 스크린샷과 화면 컨텍스트를 캡처할 수 있습니다. 그렇지 않으면 스크린샷 캡처 및 화면 컨텍스트 워크플로가 실패할 수 있습니다.

### ExtraBrain에 시스템 오디오 권한이 필요한 이유는 무엇입니까?

시스템 오디오는 지원되는 경우 ExtraBrain 회의, 통화, 비디오 또는 공유 오디오 컨텍스트를 캡처하는 데 도움이 됩니다. 이 기능이 없으면 마이크 녹음본만 볼 수 있습니다.
