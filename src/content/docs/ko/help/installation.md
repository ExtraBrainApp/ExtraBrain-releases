## 지원되는 플랫폼

ExtraBrain은 오늘 macOS입니다. Windows 및 Linux은 계획된 것이며 현재 공개 릴리스 목표는 아닙니다.

이 도움말 센터에 설명된 데스크톱 오버레이, 실시간 녹화 제어, 로컬 세션 기록, 스크린샷 컨텍스트 및 공급자 설정이 필요한 경우 공식 macOS 릴리스를 사용하세요.

![ExtraBrain 설치 후 온보딩 시작 화면](/assets/screenshots/help/dark/onboarding-welcome.png)

## 주요 시사점

ExtraBrain 설치는 라이브 세션 전에 데스크탑 앱, 라이브 녹화 제어, 로컬 세션 기록, 스크린샷, 기록 및 AI 제공자 액세스를 준비하는 macOS 설정 경로입니다.

- ExtraBrain은 현재 Apple Silicon 및 Intel Mac을 포함하여 Mac을 지원합니다.
- Windows 및 Linux은 계획된 것이며 현재 공개 출시 대상이 아닙니다.
- 안정적인 첫 번째 설정에는 앱 실행, 마이크 권한, 화면 녹화 권한, 텍스트 변환 선택, 공급자 확인 등 5가지 확인이 포함됩니다.
- 로컬 Parakeet 전사에는 Deepgram API 키가 필요하지 않습니다. 선택 사항 Deepgram은 Deepgram 계정을 사용합니다.

## GitHub Releases에서 설치

1. [ExtraBrain 다운로드 페이지](/ko/download/)를 엽니다.
2. 현재 macOS 빌드를 다운로드하세요.
3. 다운로드한 설치 프로그램 또는 앱 번들을 엽니다.
4. 릴리스 지침에 따라 앱이 필요한 경우 앱을 애플리케이션으로 이동하세요.
5. ExtraBrain을 실행합니다.

## 첫 출시 체크리스트

- 온보딩을 완료하세요.
- 마이크, 화면 녹화, 시스템 오디오 권한을 부여합니다.
- 로컬 Parakeet 또는 Deepgram 전사를 선택합니다.
- OpenAI, Anthropic, Claude 구독, Codex 구독 또는 사용자 지정 OpenAI-compatible 엔드포인트를 연결합니다.
- 실제 인터뷰나 회의에서 ExtraBrain을 사용하기 전에 짧은 테스트 세션을 한 번 실행해 보세요.

macOS이 마이크 또는 화면 액세스를 차단하는 경우 [macOS 권한 부여](/ko/help/getting-started/macos-permissions/)를 열고 시스템 설정 복구 단계를 따르세요.

:::caution
앱을 처음 설치하려면 인터뷰 시작 5분 전까지 기다리지 마세요. 라이브 세션 전에 릴리스, 권한, 전사 및 공급자 설정을 테스트하십시오.
:::

## 설치 질문

### ExtraBrain은(는) 어디서 다운로드해야 합니까?

공식 [ExtraBrain 다운로드 페이지](/ko/download/)를 이용하세요. 이는 현재 macOS 릴리스를 가리키며 오래된 타사 빌드를 방지합니다.

### ExtraBrain을 설치한 후 무엇을 테스트해야 합니까?

짧은 세션을 시작하고, 기록이 나타나는지 확인하고, 스크린샷을 캡처하고, 분석을 실행하고, 응답이 선택한 공급자를 사용하는지 확인합니다.
