ExtraBrain이(가) 오디오를 캡처하지 않거나, 제공자를 확인할 수 없거나, 스크린샷이 누락되거나, 라이브 세션 중에 복구하기 어려운 경우 이 페이지를 사용하십시오.

![마이크, 화면 및 시스템 오디오 액세스 문제 해결을 위한 ExtraBrain 권한 단계](/assets/screenshots/help/dark/onboarding-permissions.png)

## 주요 시사점

ExtraBrain 문제 해결은 마이크 권한, 화면 녹화 권한, 시스템 오디오, 공급자 확인, Deepgram 확인 및 창 표시 등 가장 일반적인 6가지 차단 요인에 대한 복구 경로입니다.

- 대부분의 캡처 문제는 macOS 개인 정보 보호 및 보안에서 시작되며 ExtraBrain을 종료했다가 다시 열어야 합니다.
- 공급자 오류는 일반적으로 선택한 모델, API 키, 구독 액세스, 기본 URL, 할당량 또는 네트워크 액세스와 관련됩니다.
- 스크린샷 분석에는 활성 세션, 화면 녹화 권한 및 예상 캡처 모드가 필요합니다.
- 녹화가 중지될 때까지 활성 세션을 삭제할 수 없습니다.

## 마이크 권한이 필요합니다

마이크 캡처가 시작되지 않는 경우:

1. **시스템 설정 -> 개인 정보 보호 및 보안 -> 마이크**를 엽니다.
2. ExtraBrain을 활성화합니다.
3. macOS이 요청하면 ExtraBrain을 종료했다가 다시 엽니다.
4. 짧은 테스트 세션을 시작합니다.

[macOS 권한 부여](/ko/help/getting-started/macos-permissions/)를 참조하세요.

## 화면 녹화 또는 시스템 오디오가 작동하지 않음

화면 녹화는 스크린샷과 화면 컨텍스트를 제어합니다. 시스템 오디오는 지원되는 경우 회의, 통화, 비디오 또는 공유 오디오 기록을 제어합니다.

"마이크 중지됨", "시스템 오디오 중지됨" 또는 "오디오 중지됨"과 같은 경고 칩이 있는지 확인하세요. 그런 다음 macOS 개인 정보 보호 및 보안 설정을 다시 열고 액세스 권한을 부여한 후 필요한 경우 ExtraBrain을 다시 시작하세요.

## API 키 검증 실패

OpenAI, Anthropic 또는 사용자 정의 엔드포인트의 경우:

- 키가 현재인지 확인
- 여분의 공백을 제거
- 선택한 모델이 계정에서 사용 가능한지 확인하세요
- 사용자 정의 엔드포인트에 기본 URL과 모델 이름이 있는지 확인
- 프록시 또는 조직 제한 사항을 확인하세요.

그런 다음 **설정 -> LLM 공급자**에서 다시 확인하세요.

## Deepgram 검증 실패

Deepgram에는 유효한 Deepgram API 키가 필요합니다. 검증에 실패하면 새 키를 붙여넣거나 검증을 다시 시도하거나 온보딩 또는 **설정 -> 오디오**에서 로컬 Parakeet로 다시 전환하세요.

## 분석에 스크린샷이 표시되지 않습니다.

다음 사항을 확인하세요.

- 세션이 활성 상태입니다
- 화면 녹화 권한이 부여되었습니다
- **설정 -> 스크린샷**의 캡처 모드가 예상한 것과 일치합니다.
- 스크린샷 항목이 스크립트 패널에 나타납니다.

스크린샷은 로컬 세션 아티팩트입니다. 클라우드 LLM 제공자에게 분석을 요청하면 스크린샷에서 파생된 컨텍스트가 전송될 수 있습니다.

## 기본 창이 숨겨져 있거나 클릭하기 어렵습니다.

오버레이가 숨겨져 있거나 클릭연결로 인해 상호작용이 어려운 경우:

1. 토글 창 단축키를 사용하세요.
2. **설정 -> 개인 정보**에서 클릭연결을 비활성화하세요.
3. 가시적인 복구 경로가 필요한 경우 Dock 또는 메뉴 표시줄 가시성을 다시 활성화하십시오.

## 세션 기록 삭제가 비활성화되었습니다.

활성 세션은 삭제할 수 없습니다. 먼저 녹화를 중지한 후 **설정 -> 세션**으로 돌아가서 세션을 삭제하세요.

## 문제 해결 질문

### ExtraBrain이(가) 녹화되지 않는 경우 먼저 무엇을 확인해야 합니까?

마이크 권한, 시스템 오디오 권한, 선택한 오디오 장치, 세션이 이미 시작 중인지 중지 중인지 여부를 확인하세요.

### 분석이 실패하면 무엇을 먼저 확인해야 합니까?

선택한 AI 공급자, API 키 또는 구독 상태, 사용자 지정 엔드포인트 필드, 현재 세션에 분석할 기록 또는 스크린샷 컨텍스트가 있는지 여부를 확인하세요.
