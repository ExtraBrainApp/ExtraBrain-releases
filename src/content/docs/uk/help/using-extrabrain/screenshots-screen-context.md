Знімки екрана допомагають ExtraBrain зрозуміти код, підказки, діаграми, слайди, термінали, сторінки браузера та інший візуальний контекст.

![Запис знімка екрана в стенограмі ExtraBrain](/assets/screenshots/help/dark/main-screenshot-entry.png)

## Режими захоплення

Відкрийте **Налаштування -> Знімок екрана**, щоб вибрати спосіб роботи знімків екрана.

![Вкладка налаштувань знімка екрана](/assets/screenshots/help/dark/settings-screenshot.png)

| Налаштування | Використовуйте це коли |
| --- | --- |
| Активне вікно | Ви хочете, щоб знімки екрана охоплювали поточне вікно програми. |
| Повний екран | Вам потрібен ширший контекст робочого столу. |
| Захоплення перед аналізом | Ви хочете, щоб ExtraBrain автоматично зробив знімок екрана перед запуском аналізу. |

## Під час сеансу

1. Почніть запис.
2. Натисніть **Захопити**.
3. Переконайтеся, що запис знімка екрана з’являється на панелі стенограми.
4. Натисніть **Запитати**, щоб включити поточний контекст до аналізу.

Якщо знімок екрана не з’являється, підтвердьте, що сеанс активний і надано дозвіл macOS Screen Recording.

## Видалити знімки екрана

Використовуйте видалення знімка екрана, якщо ви захопили неправильний контекст або не хочете, щоб знімок екрана зберігався в локальному записі сеансу.

## Потік даних

Знімки екрана зберігаються локально як артефакти сеансу. Коли ви запитуєте постачальника хмарних послуг про аналіз, вибраному постачальнику може бути надіслано отриманий знімок екрана контекст.

## Запитання щодо скріншотів

### Чи слід використовувати зйомку в активному вікні чи на весь екран?

Використовуйте захоплення активного вікна, якщо вам потрібен вузький контекст із поточної програми. Використовуйте зйомку в повноекранному режимі лише тоді, коли ширший вигляд робочого столу доречний і прийнятний для сеансу.

### Чому скріншоти не відображаються в аналізі?

Перед початком аналізу переконайтеся, що запис активний, надано дозвіл на запис екрана та на панелі стенограми з’являється запис знімка екрана.
