Використовуйте **Налаштування -> Аудіо**, щоб вибрати поведінку транскрипції та вхід із мікрофона.

![ExtraBrain налаштування аудіо з постачальником транскрипції та елементами керування мікрофоном](/assets/screenshots/help/dark/settings-audio.png)

## Елементи керування звуком

| КОНТРОЛЬ | Що це змінює |
| --- | --- |
| Провайдер мовлення в текст | Локальна хмарна транскрипція Parakeet або Deepgram. |
| Ключ Deepgram API | Потрібний, лише якщо вибрано Deepgram. |
| Джерело звуку | Бажаний вхід для мікрофона. |
| Голосовий тригер | Керування голосовою фразою для початку аналізу під час активного сеансу. |
| Очищення стенограми | Видалення слів-заповнювачів перед картками розшифровки та аналізом. |
| Дозвіл на звук системи | Потік дозволів macOS для запису аудіо додатка/system, коли потрібно. |

## Примітки

- Зміни аудіопристрою застосовуються до нових сеансів.
- Local Parakeet зберігає транскрипцію локально.
- Deepgram надсилає аудіо на Deepgram для транскрипції.
- ExtraBrain може знадобитися macOS мікрофон і дозволи системи аудіо перед записом.

## Загальні запитання

### Чому ExtraBrain каже, що пристрої не знайдено?

Можливо, macOS ще не надав дозвіл на використання мікрофона, або вибраний вхід може бути недоступним. Надайте дозвіл, повторно підключіть мікрофон і почніть новий сеанс.

### Чи впливає зміна постачальника транскрипції на поточний сеанс?

Зміни провайдера та пристрою є найбезпечнішими, коли застосовуються до початку сеансу. Зупиніть запис і почніть новий сеанс після серйозних змін звуку.
