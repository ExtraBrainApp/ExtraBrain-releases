ExtraBrain перетворює живу мову на текст за допомогою локального NVIDIA Parakeet або Deepgram.

![Місцева транскрипція, вибрана під час адаптації](/assets/screenshots/help/dark/onboarding-transcription-local.png)

## Швидке порівняння

| Варіант | Найкраще для | Потік даних | Налаштування |
| --- | --- | --- | --- |
| Місцевий Parakeet | Більшість користувачів, конфіденційні сеанси, найшвидше налаштування | Транскрипція виконується на вашому Mac | Ні ключа API |
| Deepgram | Користувачі, які вже покладаються на керовану хмарну транскрипцію | Аудіо надіслано на Deepgram | Потрібен ключ Deepgram API |

## Місцевий Parakeet

Виберіть локальний Parakeet, якщо ви бажаєте найпростіших налаштувань і віддаєте перевагу транскрипції на Mac. Він потребує локального зберігання моделі та використовує локальний ЦП під час роботи моделі.

## Deepgram

Виберіть Deepgram, якщо хмарна транскрипція відповідає вашому робочому процесу або ваша організація вже використовує Deepgram. Для Deepgram потрібен дійсний ключ API.

![Deepgram ключове поле під час реєстрації](/assets/screenshots/help/dark/onboarding-transcription-deepgram-key.png)

Після успішної перевірки ExtraBrain може продовжити підключення з вибраним Deepgram.

![Deepgram успішна перевірка під час реєстрації](/assets/screenshots/help/dark/onboarding-transcription-deepgram-valid.png)

## Примітка про конфіденційність

Локальний Parakeet зберігає транскрипцію локальною. Deepgram надсилає аудіо на Deepgram для транскрипції. Аналіз штучного інтелекту є окремим вибором і може надсилати текст стенограми або контекст, отриманий зі знімка екрана, вибраному вами постачальнику LLM.

## Запитання щодо транскрипції

### Який постачальник транскрипції найкращий для конфіденційності?

Локальний Parakeet є найкращим за умовчанням, коли звук має залишатися на вашому Mac. Для цього не потрібен ключ Deepgram API.

### Коли мені вибрати Deepgram?

Виберіть Deepgram, якщо хмарна транскрипція відповідає сеансу, ваша організація вже використовує Deepgram або ви віддаєте перевагу керованій транскрипції та приймаєте, що аудіо надсилається на Deepgram.
