ExtraBrain підтримує режим ключа OpenAI API та режим підписки Codex.

## OpenAI API Режим клавіш

Використовуйте цей режим, якщо ви хочете, щоб ExtraBrain викликав OpenAI через ключ API, яким ви керуєте.

1. Відкрийте **Налаштування -> LLM Постачальники**.
2. Виберіть **OpenAI**.
3. Вставте свій ключ API.
4. Виберіть модель і міркування, якщо це можливо.
5. Перевірте ключ.
6. Виконайте короткий аналіз, щоб підтвердити, що відповіді надходять від OpenAI.

![OpenAI форма постачальника в реєстрації](/assets/screenshots/help/dark/onboarding-openai-provider-form.png)

## Codex Режим підписки

Використовуйте підписку Codex, якщо ви хочете, щоб ExtraBrain використовував вашу підписку ChatGPT Plus або Pro безпосередньо. Для цього режиму не потрібен ключ API у ExtraBrain.

1. Відкрийте **Налаштування -> LLM Постачальники**.
2. Виберіть **Codex Підписка**.
3. Повторно перевірте статус входу.
4. Виберіть доступну модель.
5. Виконайте тестовий аналіз.

## Усунення несправностей

Якщо перевірка не вдається, переконайтеся, що ключ актуальний, має доступ до вибраної моделі та не заблокований проксі-сервером або політикою організації. Для режиму підписки переконайтеся, що середовище робочого столу може отримати доступ до інструментів постачальника, для якого виконано вхід.

## OpenAI і Codex Запитання

### Чи потрібен мені ключ OpenAI API для режиму підписки Codex?

Ні. Codex Режим підписки використовує прямий доступ за підпискою ChatGPT Plus або Pro і не вимагає ключа OpenAI API у ExtraBrain.

### Що ExtraBrain може надіслати OpenAI або Codex?

Якщо вибрано для аналізу, ExtraBrain може надсилати підказки, контекст стенограми, контекст, отриманий зі знімка екрана, і спеціальні запитання, необхідні для відповіді.
