ExtraBrain використовує обраного вами постачальника штучного інтелекту для аналізу в реальному часі. Налаштування постачальника контролюють, куди можуть надсилатися підказки, контекст стенограми та контекст, отриманий зі знімка екрана.

![Вибір постачальника штучного інтелекту під час адаптації ExtraBrain](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## Режими публічного провайдера

- Ключ OpenAI API.
- Ключ Anthropic API.
- Codex Підписка за допомогою ChatGPT Plus або Pro безпосередньо, без ключа API.
- Claude Підписка за допомогою Claude Pro або безпосередньо Max, без ключа API.
- Спеціальна кінцева точка OpenAI-compatible з базовою URL-адресою, ключем API і назвою моделі.

## Контрольний список налаштування

1. Відкрийте адаптацію або **Налаштування -> LLM Постачальники**.
2. Виберіть сімейство провайдерів.
3. Виберіть ключ API або режим підписки.
4. За потреби введіть облікові дані.
5. Підтвердьте або ще раз перевірте з’єднання.
6. Виконайте короткий тестовий аналіз.

![LLM Вкладка налаштувань постачальників](/assets/screenshots/help/dark/settings-llm-providers.png)

## Потік даних

Коли ви запитуєте ExtraBrain про аналіз у хмарного постачальника, цьому постачальнику можуть надсилатися відповідні підказки, контекст стенограми, контекст, отриманий зі знімків екрана, і спеціальні запитання. Вибраний вами постачальник регулює виставлення рахунків, утримання, квоту та керування обліковим записом.

## Запитання провайдера AI

### Якого постачальника AI мені вибрати в першу чергу?

Виберіть постачальника, якому ви вже довіряєте, і якого ви можете перевірити перед справжнім сеансом. Для більшості користувачів це означає почати з наявного облікового запису OpenAI, Anthropic, Claude або Codex.

### Чи можу я зберегти готовий шлях до кількох постачальників?

так Збереження резервного шляху постачальника корисно перед співбесідами чи зустрічами, де можуть змінитися квота, доступ до мережі або статус облікового запису.
