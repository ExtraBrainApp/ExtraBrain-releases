ExtraBrain підтримує режим ключа Anthropic API та режим підписки Claude.

## Anthropic API Режим клавіш

Використовуйте цей режим, якщо ви хочете, щоб ExtraBrain викликав Anthropic через ключ API, яким ви керуєте.

1. Відкрийте **Налаштування -> LLM Постачальники**.
2. Виберіть **Anthropic**.
3. Вставте свій ключ Anthropic API.
4. Виберіть модель.
5. Перевірте ключ.
6. Виконайте короткий тестовий аналіз.

![LLM Вкладка налаштувань постачальників з вибраним Anthropic](/assets/screenshots/help/dark/settings-llm-providers.png)

## Claude Режим підписки

Використовуйте підписку Claude, якщо ви хочете, щоб ExtraBrain використовував вашу підписку Claude Pro або Max безпосередньо. Для цього режиму не потрібен ключ API у ExtraBrain.

1. Відкрийте **Налаштування -> LLM Постачальники**.
2. Виберіть **Claude Підписка**.
3. Повторно перевірте статус входу.
4. Виберіть доступну модель.
5. Виконайте тестовий аналіз.

## Усунення несправностей

Якщо перевірка не вдалася, підтвердьте, що ключ API належить правильному обліковому запису Anthropic, має доступ до моделі та вставлено без зайвих пробілів. Для режиму підписки підтвердьте, що ваша підписка Claude активна та ви ввійшли там, де цього очікує ExtraBrain.

## Anthropic і Claude Запитання

### Чи потрібен мені ключ Anthropic API для режиму підписки Claude?

Ні. Claude Режим підписки призначений для доступу за підпискою Claude Pro або Max і не потребує ключа Anthropic API всередині ExtraBrain.

### Які дані можна надіслати на Anthropic або Claude?

Якщо вибрано для аналізу, відповідні підказки, контекст стенограми, контекст, отриманий зі знімків екрана, і спеціальні запитання можуть надсилатися до Anthropic або Claude відповідно до режиму цього постачальника.
