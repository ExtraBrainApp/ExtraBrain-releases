Налаштування під час першого запуску отримує ExtraBrain від запуску до сеансу в реальному часі. Потік адаптації охоплює привітання, дозволи macOS, постачальника транскрипції, постачальника штучного інтелекту та завершення.

![ExtraBrain екран привітання](/assets/screenshots/help/dark/onboarding-welcome.png)

## 1. Розпочніть адаптацію

Відкрийте ExtraBrain і продовжте з екрана привітання. Тримайте програму відкритою, поки завершуєте надання дозволів і налаштування постачальника.

## 2. Надайте дозволи macOS

ExtraBrain потребує дозволу, щоб почути та побачити контекст, який ви вибрали:

- Мікрофон для вашої розмови.
- Запис екрана для скріншотів і контексту екрана.
- Системне аудіо для дзвінків, зустрічей, транскрипції відео чи загального аудіо, якщо підтримується.

Перегляньте [Надати macOS дозволи](/uk/help/getting-started/macos-permissions/), щоб дізнатися про кроки відновлення, якщо macOS зберігає дозвіл у стані очікування або відмови.

## 3. Виберіть Транскрипція

Виберіть один режим транскрипції:

- Локальний Parakeet працює на вашому Mac і не вимагає ключа API.
- Deepgram використовує хмарну транскрипцію та потребує ключа Deepgram API.

![Вибір постачальника транскрипції під час реєстрації](/assets/screenshots/help/dark/onboarding-transcription-local.png)

## 4. Підключіть ШІ

Виберіть сімейство постачальників штучного інтелекту та метод підключення, який ExtraBrain має використовувати для аналізу в реальному часі. Режими загальнодоступного постачальника включають OpenAI, Anthropic, Claude підписку, Codex підписку та спеціальні кінцеві точки OpenAI-compatible.

![Вибір постачальника штучного інтелекту під час підготовки](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

Параметр локальної моделі, показаний під час реєстрації, вимкнено, і його не слід розглядати як доступне загальнодоступне налаштування.

## 5. Виконайте короткий тест

Перед справжньою співбесідою чи зустріччю:

- почати запис
- з’являться записи підтвердження стенограми
- зробити один знімок екрана, якщо контекст екрана має значення
- виконати один аналіз
- підтвердьте, що відповідь надійшла від постачальника, якого ви очікували

## Запитання щодо налаштування

### Чи можу я змінити постачальника після першого налаштування?

так Ви можете змінити транскрипцію в **Налаштування -> Аудіо** і змінити постачальників штучного інтелекту в **Налаштування -> LLM Постачальники**. Виконайте короткий тест після зміни будь-якого параметра.

### Що робити, якщо адаптація не може продовжитися?

Перевірте дозволи macOS, перевірку постачальника та обов’язкові поля. Deepgram потребує дійсного ключа, тоді як локальний Parakeet може продовжувати без ключа API.
