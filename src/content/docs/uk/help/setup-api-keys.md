Скористайтеся цим оглядом, коли вам потрібно вибрати посібник із провайдера, який відповідає вашим налаштуванням. ExtraBrain підтримує постачальників ключів API, режими постачальників підписки та спеціальні кінцеві точки OpenAI-compatible.

![ExtraBrain Вибір постачальника AI](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## Ключові висновки

Постачальник штучного інтелекту ExtraBrain — це шлях моделі, який використовує програма, коли перетворює транскрипцію, підказку, знімок екрана або контекст сеансу в аналіз у реальному часі.

- ExtraBrain підтримує Google Gemma 4 локальних AI, OpenAI, Anthropic, Claude підписку, Codex підписку та спеціальні кінцеві точки OpenAI-compatible.
- Ключові режими API вимагають поточних облікових даних провайдера; режими підписки використовують шлях підписки для входу, який підтримується програмою.
- Перевірку постачальника необхідно перевірити один раз перед співбесідою, зустріччю, лекцією чи дослідницьким дзвінком.
- Виставлення рахунків постачальника, утримання, доступ до моделі та квота контролюються вибраним обліковим записом постачальника.

## Контрольний список налаштування постачальника

1. Вирішіть, чи хочете ви: режим ключа API, режим підписки або спеціальну кінцеву точку.
2. Відкрийте **Налаштування -> LLM Постачальники**.
3. Введіть необхідні дані постачальника.
4. Підтвердьте або повторно перевірте підключення до постачальника.
5. Виконайте один тестовий аналіз.
6. Перегляньте [Як ExtraBrain обробляє дані](/uk/help/privacy-security/how-extrabrain-handles-data/), перш ніж використовувати конфіденційний контекст.

## Запитання провайдера

### Чи потрібен мені ключ API для кожного режиму провайдера?

Ключові режими № OpenAI і Anthropic API потребують ключів. Режими підписки Claude та Codex використовують доступ за підпискою та не вимагають ключа API у ExtraBrain.

### Що потрібно перевірити, якщо перевірка постачальника не вдається?

Підтвердьте ключ, доступ до моделі, базову URL-адресу, статус підписки та доступ до мережі. Настроювані кінцеві точки також потребують точної назви моделі, очікуваної кінцевою точкою.
