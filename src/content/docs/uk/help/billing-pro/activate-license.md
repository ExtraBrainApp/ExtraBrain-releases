Відкрийте **Налаштування -> Ліцензія**, щоб купити, активувати або керувати ExtraBrain Pro. Pro — це $9.99/month звичайний ($6.99/month ціна засновника для ранніх користувачів), $79/year або $149 Lifetime (ціна запуску).

![ExtraBrain вкладка налаштувань ліцензії](/assets/screenshots/help/dark/settings-license.png)

## Придбайте або активуйте ліцензію

1. Відкрийте **Налаштування -> Ліцензія**.
2. Виберіть місячну або довічну опцію Pro, якщо вам все ще потрібно придбати.
3. Вставте свій ліцензійний ключ, якщо він у вас уже є.
4. Натисніть **Активувати**.
5. Дочекайтеся підтвердження.
6. Переконайтеся, що з’явився статус Pro.

Використовуйте точний ліцензійний ключ із вашої покупки або електронної пошти облікового запису. Уникайте додавання пробілів перед або після ключа та зберігайте ключ приватним, як і будь-які інші облікові дані облікового запису.

## Після активації

На вкладці «Ліцензія» може відображатися статус ліцензії та замаскований ключ. Pro може розблокувати розширені засоби керування робочим процесом, такі як користувацькі профілі, підказки для багаторазового використання, спеціальну поведінку профілю, багатший контекст сеансу, підсумки після сеансу та елементи керування преміум-моделями, якщо ввімкнено.

Перегляньте [користувацькі профілі](/uk/help/billing-pro/custom-profiles/), якщо вам потрібні багаторазові підказки для певного робочого процесу, стилю співбесіди чи формату зустрічі.

## Дезактивувати

Використовуйте деактивацію, коли переміщуєте ліцензію в інше налаштування або видаляєте Pro з поточного Mac.

Витрати на використання постачальника залишаються окремими від ExtraBrain Pro. OpenAI, Anthropic, Deepgram, Claude, Codex або вартість спеціального постачальника регулюється цими постачальниками.

## Питання щодо активації

### Чому моя ліцензія ExtraBrain Pro не активується?

Переконайтеся, що ключ повний, вставлений без зайвих пробілів і призначений для поточного облікового запису ExtraBrain або пристрою. Також підтвердьте, що Mac може отримати доступ до служби перевірки ліцензії.

### Що змінюється після активації ExtraBrain Pro?

На вкладці Ліцензія має відображатися активний статус Pro. Pro може розблокувати розширені засоби керування робочим процесом, такі як користувацькі профілі, підказки для багаторазового використання, спеціальну поведінку профілю, розширеніший контекст сеансу, підсумки після сеансу та елементи керування преміум-моделлю, де вони доступні в поточному випуску.
