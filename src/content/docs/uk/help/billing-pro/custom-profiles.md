Користувальницькі профілі — це функція Pro для збереження багаторазових підказок. Використовуйте їх, коли вбудований профіль близький, але вам потрібна більш специфічна поведінка. ExtraBrain Pro — це $9.99/month ($6.99 Засновник), $79/year або $149 Lifetime, з придбанням та активацією в **Налаштування -> Ліцензія**.

![ExtraBrain налаштування профілів, зосереджені на елементах керування спеціального профілю Pro](/assets/screenshots/help/dark/settings-custom-profiles.png)

## Що включає спеціальний профіль

| Поле або контроль | призначення |
| --- | --- |
| Ім'я | Коротка мітка, що відображається у списку профілів і в селекторі профілів. |
| опис | Нагадування про те, коли використовувати профіль. |
| Підкажіть | Детальні вказівки щодо того, як ExtraBrain має аналізувати та реагувати. |
| Увімкнено | Контролює доступність спеціального профілю. |
| Pin | Робить профіль активним закріпленим профілем. |
| Видалити | Видаляє спеціальний профіль із локальних налаштувань. |

## Налаштування профілю

Спеціальні профілі також можуть контролювати поведінку робочого процесу:

| Налаштування | Поведінка |
| --- | --- |
| Розгорнути вікно аналізу | Відкриває розширене вікно, коли профіль починає аналіз. |
| Почніть аналіз після знімка екрана області | Запускає аналіз відразу після захоплення області. |
| Використовуйте повний контекст сеансу | Надає кожному аналізу більше історії сеансів, коли цей профіль активний. |

## Етапи налаштування

1. [Активувати ExtraBrain Pro](/uk/help/billing-pro/activate-license/).
2. Відкрийте **Налаштування -> Профілі**.
3. Виберіть **Створити профіль**.
4. Додайте назву, опис і підказку.
5. Налаштувати параметри профілю.
6. Закріпіть профіль, якщо ви хочете, щоб він був активним за умовчанням.

Спеціальний текст профілю зберігається в локальних налаштуваннях. Коли ви виконуєте аналіз хмарного постачальника, вибраному вами постачальнику можуть надсилатися відповідні підказки, контекст стенограми, контекст, отриманий зі знімків екрана, і запитання.

## Загальні запитання

### Чи можу я створювати спеціальні профілі без Pro?

Безкоштовні користувачі можуть використовувати вбудовані системні профілі. Для створення та редагування спеціальних профілів потрібен Pro.

### Що потрібно вказати в запиті спеціального профілю?

Опишіть стиль відповіді, обмеження та пріоритети, яких ExtraBrain має дотримуватися. Зберігайте його багаторазовим і уникайте секретів.
