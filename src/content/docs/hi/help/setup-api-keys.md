इस अवलोकन का उपयोग तब करें जब आपको यह चुनना हो कि कौन सा प्रदाता गाइड आपके सेटअप से मेल खाता है। ExtraBrain API-कुंजी प्रदाताओं, सदस्यता प्रदाता मोड और कस्टम OpenAI-compatible समापन बिंदुओं का समर्थन करता है।

![ExtraBrain AI प्रदाता चयनकर्ता](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## चाबी छीनना

ExtraBrain AI प्रदाता वह मॉडल पथ है जिसका उपयोग ऐप तब करता है जब यह ट्रांसक्रिप्ट, प्रॉम्प्ट, स्क्रीनशॉट या सत्र संदर्भ को लाइव विश्लेषण में बदल देता है।

- ExtraBrain Google Gemma 4 स्थानीय AI, OpenAI, Anthropic, Claude सब्सक्रिप्शन, Codex सब्सक्रिप्शन और कस्टम OpenAI-compatible एंडपॉइंट्स को सपोर्ट करता है।
- API कुंजी मोड के लिए वर्तमान प्रदाता क्रेडेंशियल की आवश्यकता होती है; सदस्यता मोड ऐप द्वारा समर्थित साइन-इन सदस्यता पथ का उपयोग करते हैं।
- लाइव साक्षात्कार, मीटिंग, व्याख्यान, या शोध कॉल से पहले एक बार प्रदाता सत्यापन का परीक्षण किया जाना चाहिए।
- प्रदाता बिलिंग, प्रतिधारण, मॉडल पहुंच और कोटा आपके द्वारा चुने गए प्रदाता खाते द्वारा नियंत्रित किया जाता है।

## प्रदाता सेटअप चेकलिस्ट

1. तय करें कि आप API कुंजी मोड, सदस्यता मोड, या एक कस्टम एंडपॉइंट चाहते हैं।
2. **सेटिंग्स -> LLM प्रदाता** खोलें।
3. आवश्यक प्रदाता विवरण दर्ज करें।
4. प्रदाता कनेक्शन को सत्यापित या पुनः जांचें।
5. एक परीक्षण विश्लेषण चलाएँ.
6. संवेदनशील संदर्भ का उपयोग करने से पहले समीक्षा करें [ExtraBrain डेटा कैसे संभालता है](/hi/help/privacy-security/how-extrabrain-handles-data/)।

## प्रदाता प्रश्न

### क्या मुझे प्रत्येक प्रदाता मोड के लिए API कुंजी की आवश्यकता है?

संख्या OpenAI और Anthropic API कुंजी मोड के लिए कुंजियों की आवश्यकता होती है। Claude सदस्यता और Codex सदस्यता मोड सदस्यता पहुंच का उपयोग करते हैं और ExtraBrain में API कुंजी की आवश्यकता नहीं होती है।

### यदि प्रदाता सत्यापन विफल हो जाता है तो मुझे क्या जांचना चाहिए?

कुंजी, मॉडल पहुंच, आधार यूआरएल, सदस्यता स्थिति और नेटवर्क पहुंच की पुष्टि करें। कस्टम एंडपॉइंट को भी एंडपॉइंट द्वारा अपेक्षित सटीक मॉडल नाम की आवश्यकता होती है।
