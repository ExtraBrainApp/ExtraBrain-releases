## समर्थित प्लेटफार्म

ExtraBrain आज macOS-प्रथम है। Windows और Linux की योजना बनाई गई है, वर्तमान सार्वजनिक रिलीज़ लक्ष्य नहीं।

जब आपको इस सहायता केंद्र में वर्णित डेस्कटॉप ओवरले, लाइव रिकॉर्डिंग नियंत्रण, स्थानीय सत्र इतिहास, स्क्रीनशॉट संदर्भ और प्रदाता सेटअप की आवश्यकता हो तो आधिकारिक macOS रिलीज़ का उपयोग करें।

![ExtraBrain इंस्टालेशन के बाद स्वागत स्क्रीन पर ऑनबोर्डिंग](/assets/screenshots/help/dark/onboarding-welcome.png)

## चाबी छीनना

ExtraBrain इंस्टॉलेशन macOS सेटअप पथ है जो डेस्कटॉप ऐप, लाइव रिकॉर्डिंग नियंत्रण, स्थानीय सत्र इतिहास, स्क्रीनशॉट, ट्रांसक्रिप्शन और एआई प्रदाता एक्सेस को लाइव सत्र से पहले तैयार कर देता है।

- ExtraBrain आज Mac का समर्थन करता है, जिसमें Apple सिलिकॉन और Intel Macs शामिल हैं।
- Windows और Linux की योजना बनाई गई है, वर्तमान सार्वजनिक रिलीज़ लक्ष्य नहीं।
- एक विश्वसनीय पहले सेटअप में 5 जाँचें होती हैं: ऐप लॉन्च, माइक्रोफ़ोन अनुमति, स्क्रीन रिकॉर्डिंग अनुमति, ट्रांसक्रिप्शन विकल्प और प्रदाता सत्यापन।
- स्थानीय Parakeet प्रतिलेखन के लिए Deepgram API कुंजी की आवश्यकता नहीं होती है; वैकल्पिक Deepgram आपके Deepgram खाते का उपयोग करता है।

## GitHub Releases से इंस्टॉल करें

1. [ExtraBrain डाउनलोड पृष्ठ](/hi/download/) खोलें।
2. वर्तमान macOS बिल्ड डाउनलोड करें।
3. डाउनलोड किए गए इंस्टॉलर या ऐप बंडल को खोलें।
4. यदि रिलीज़ निर्देशों के लिए इसकी आवश्यकता हो तो ऐप को एप्लिकेशन में ले जाएं।
5. ExtraBrain लॉन्च करें।

## प्रथम लॉन्च चेकलिस्ट

- पूर्ण ऑनबोर्डिंग.
- माइक्रोफ़ोन, स्क्रीन रिकॉर्डिंग और सिस्टम ऑडियो अनुमतियाँ प्रदान करें।
- स्थानीय Parakeet या Deepgram प्रतिलेखन चुनें।
- OpenAI, Anthropic, Claude सदस्यता, Codex सदस्यता, या एक कस्टम OpenAI-compatible समापन बिंदु कनेक्ट करें।
- किसी वास्तविक साक्षात्कार या मीटिंग में ExtraBrain का उपयोग करने से पहले एक छोटा परीक्षण सत्र चलाएँ।

यदि macOS माइक्रोफ़ोन या स्क्रीन एक्सेस को अवरुद्ध करता है, तो [macOS अनुमतियाँ प्रदान करें](/hi/help/getting-started/macos-permissions/) खोलें और सिस्टम सेटिंग्स पुनर्प्राप्ति चरणों का पालन करें।

:::caution
पहली बार ऐप इंस्टॉल करने के लिए साक्षात्कार से पांच मिनट पहले तक प्रतीक्षा न करें। लाइव सत्र से पहले रिलीज़, अनुमतियाँ, ट्रांसक्रिप्शन और प्रदाता सेटअप का अच्छी तरह से परीक्षण करें।
:::

## स्थापना प्रश्न

### मुझे ExtraBrain कहाँ से डाउनलोड करना चाहिए?

आधिकारिक [ExtraBrain डाउनलोड पृष्ठ](/hi/download/) का उपयोग करें। यह वर्तमान macOS रिलीज़ की ओर इशारा करता है और पुराने तृतीय-पक्ष बिल्ड से बचता है।

### ExtraBrain इंस्टॉल करने के बाद मुझे क्या परीक्षण करना चाहिए?

एक छोटा सत्र शुरू करें, प्रतिलेखन प्रकट होने की पुष्टि करें, एक स्क्रीनशॉट कैप्चर करें, एक विश्लेषण चलाएं, और सत्यापित करें कि प्रतिक्रिया आपके द्वारा चुने गए प्रदाता का उपयोग करती है।
