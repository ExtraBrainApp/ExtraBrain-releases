ExtraBrain एक स्थानीय डेस्कटॉप ऐप है, लेकिन आपका सटीक डेटा प्रवाह आपके द्वारा चुने गए प्रदाताओं और सुविधाओं पर निर्भर करता है।

![ExtraBrain में गोपनीयता सेटिंग्स](/assets/screenshots/help/dark/settings-privacy.png)

## सटीक गोपनीयता शब्दावली

ExtraBrain आपके Mac पर सेटिंग्स, API कुंजियाँ, स्थानीय सत्र इतिहास और स्थानीय Parakeet ट्रांसक्रिप्शन डेटा संग्रहीत करता है। जब आप क्लाउड LLM प्रदाता का उपयोग करते हैं, तो प्रासंगिक पाठ, प्रतिलेख संदर्भ, स्क्रीनशॉट-व्युत्पन्न संदर्भ और संकेत आपके द्वारा चुने गए प्रदाता को भेजे जा सकते हैं। जब आप Deepgram चुनते हैं, तो ट्रांसक्रिप्शन के लिए ऑडियो Deepgram पर भेजा जाता है। अनाम उपयोग साझाकरण अक्षम किया जा सकता है.

## आपके Mac पर क्या रहता है

- ऐप सेटिंग
- प्रदाता कॉन्फ़िगरेशन और API कुंजियाँ ऐप द्वारा संग्रहीत की जाती हैं
- स्थानीय सत्र इतिहास
- प्रतिलेख और स्क्रीनशॉट स्थानीय सत्र इतिहास में सहेजे गए
- स्थानीय Parakeet प्रतिलेखन डेटा

## आपका Mac क्या छोड़ सकता है

| पसंद | क्या भेजा जा सकता है |
| --- | --- |
| OpenAI, Anthropic, Claude सदस्यता, Codex सदस्यता, या कस्टम LLM प्रदाता | संकेत, प्रतिलेख संदर्भ, स्क्रीनशॉट-व्युत्पन्न संदर्भ, कस्टम प्रश्न और अन्य चयनित विश्लेषण संदर्भ। |
| Deepgram प्रतिलेखन | ट्रांसक्रिप्शन के लिए ऑडियो Deepgram पर भेजा गया। |
| अनाम उपयोग साझाकरण | सक्षम होने पर डेटा का उपयोग करें. |

## प्रदाता नियंत्रण

बाहरी प्रदाता प्रतिधारण, बिलिंग, कोटा, मॉडल पहुंच और खाता नीतियां आपके द्वारा चुने गए प्रदाता द्वारा नियंत्रित की जाती हैं। यदि आप संवेदनशील साक्षात्कार, कार्यस्थल, ग्राहक या शोध सामग्री संभालते हैं तो उन प्रदाता सेटिंग्स की समीक्षा करें।

## डेटा प्रबंधन प्रश्न

### सबसे निजी प्रतिलेखन सेटअप क्या है?

जब ऑडियो ट्रांसक्रिप्शन Mac पर रहना चाहिए तो स्थानीय Parakeet का उपयोग करें। उन सत्रों के लिए Deepgram से बचें जहां ऑडियो क्लाउड ट्रांसक्रिप्शन प्रदाता को नहीं भेजा जाना चाहिए।

### क्लाउड प्रदाता प्रतिधारण को कौन नियंत्रित करता है?

आपके द्वारा चुना गया प्रदाता इसकी अवधारण, बिलिंग, कोटा और खाता नीतियों को नियंत्रित करता है। संवेदनशील संदर्भ भेजने से पहले OpenAI, Anthropic, Claude, Codex, Deepgram, या कस्टम एंडपॉइंट सेटिंग्स की समीक्षा करें।
