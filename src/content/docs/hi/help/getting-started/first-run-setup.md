प्रथम-रन सेटअप को लॉन्च से लेकर प्रयोग करने योग्य लाइव सत्र तक ExtraBrain मिलता है। ऑनबोर्डिंग प्रवाह में स्वागत, macOS अनुमतियाँ, ट्रांसक्रिप्शन प्रदाता, AI प्रदाता और फिनिश शामिल हैं।

![ExtraBrain ऑनबोर्डिंग स्वागत स्क्रीन](/assets/screenshots/help/dark/onboarding-welcome.png)

## 1. ऑनबोर्डिंग प्रारंभ करें

ExtraBrain खोलें और स्वागत स्क्रीन से जारी रखें। अनुमतियाँ और प्रदाता सेटअप पूरा करते समय ऐप को खुला रखें।

## 2. अनुदान macOS अनुमतियाँ

ExtraBrain को आपके द्वारा उपयोग किए जाने वाले संदर्भ को सुनने और देखने के लिए अनुमति की आवश्यकता है:

- आपके बोले गए ऑडियो के लिए माइक्रोफ़ोन.
- स्क्रीनशॉट और स्क्रीन संदर्भ के लिए स्क्रीन रिकॉर्डिंग।
- समर्थित होने पर कॉल, मीटिंग, वीडियो या साझा-ऑडियो ट्रांसक्रिप्शन के लिए सिस्टम ऑडियो।

यदि macOS किसी अनुमति को लंबित या अस्वीकृत स्थिति में रखता है तो पुनर्प्राप्ति चरणों के लिए [macOS अनुमतियाँ प्रदान करें](/hi/help/getting-started/macos-permissions/) देखें।

## 3. प्रतिलेखन चुनें

एक ट्रांसक्रिप्शन मोड चुनें:

- स्थानीय Parakeet आपके Mac पर चलता है और इसके लिए API कुंजी की आवश्यकता नहीं होती है।
- Deepgram क्लाउड ट्रांसक्रिप्शन का उपयोग करता है और इसके लिए Deepgram API कुंजी की आवश्यकता होती है।

![ऑनबोर्डिंग में प्रतिलेखन प्रदाता चयन](/assets/screenshots/help/dark/onboarding-transcription-local.png)

## 4. एआई कनेक्ट करें

एआई प्रदाता परिवार चुनें और कनेक्शन विधि ExtraBrain को लाइव विश्लेषण के लिए उपयोग करना चाहिए। सार्वजनिक प्रदाता मोड में OpenAI, Anthropic, Claude सदस्यता, Codex सदस्यता, और कस्टम OpenAI-compatible समापन बिंदु शामिल हैं।

![ऑनबोर्डिंग में एआई प्रदाता चयनकर्ता](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

ऑनबोर्डिंग में दिखाया गया स्थानीय मॉडल विकल्प अक्षम है और इसे उपलब्ध सार्वजनिक सेटअप के रूप में नहीं माना जाना चाहिए।

## 5. एक लघु परीक्षण चलाएँ

वास्तविक साक्षात्कार या मीटिंग से पहले:

- रिकॉर्डिंग प्रारंभ करें
- पुष्टि करें कि प्रतिलेख प्रविष्टियाँ दिखाई देती हैं
- यदि स्क्रीन संदर्भ मायने रखता है तो एक स्क्रीनशॉट कैप्चर करें
- एक विश्लेषण चलाएँ
- पुष्टि करें कि उत्तर उस प्रदाता से आया है जिसकी आपको अपेक्षा थी

## सेटअप प्रश्न

### क्या मैं प्रथम-रन सेटअप के बाद प्रदाता बदल सकता हूँ?

हाँ। आप ट्रांसक्रिप्शन को **सेटिंग्स -> ऑडियो** में बदल सकते हैं और एआई प्रदाताओं को **सेटिंग्स -> LLM प्रोवाइडर्स** में बदल सकते हैं। किसी भी सेटिंग को बदलने के बाद एक छोटा परीक्षण चलाएँ।

### यदि ऑनबोर्डिंग जारी नहीं रह पाती तो मुझे क्या करना चाहिए?

macOS अनुमतियाँ, प्रदाता सत्यापन और आवश्यक फ़ील्ड जाँचें। Deepgram को एक वैध कुंजी की आवश्यकता होती है, जबकि स्थानीय Parakeet API कुंजी के बिना जारी रह सकता है।
