ExtraBrain सेटिंग्स वर्कफ़्लो क्षेत्र द्वारा व्यवस्थित की जाती हैं। मुख्य विंडो से सेटिंग्स खोलें, फिर वह टैब चुनें जिसकी आपको आवश्यकता है।

![ExtraBrain सामान्य सेटिंग टैब](/assets/screenshots/help/dark/settings-general.png)

## सार्वजनिक सेटिंग्स टैब

| टैब | यह क्या नियंत्रित करता है |
| --- | --- |
| सामान्य | [व्यक्तिगत संदर्भ, पसंदीदा कोडिंग भाषा, विस्तार-पर-विश्लेषण, और नवीनतम-विश्लेषण प्रदर्शन व्यवहार](/hi/help/settings/general-context-language/)। |
| प्रोफाइल | [सहायक, कोडिंग, सिस्टम डिज़ाइन, व्यवहार, मीटिंग और कस्टम प्रोफ़ाइल व्यवहार](/hi/help/settings/profiles/)। |
| UI | [फ़ॉन्ट आकार, अस्पष्टता, उपस्थिति प्रीसेट, युक्तियाँ, और कोड ब्लॉक थीम](/hi/help/settings/ui-appearance/)। |
| शॉर्टकट | रिकॉर्डिंग, स्क्रीनशॉट, विश्लेषण, फॉलो-अप, विंडो नियंत्रण, क्लिक-थ्रू और स्क्रॉलिंग शॉर्टकट। |
| ऑडियो | [ट्रांसक्रिप्शन प्रदाता, Deepgram कुंजी, माइक्रोफ़ोन डिवाइस, ट्रांसक्रिप्ट क्लीनअप, और वॉयस ट्रिगर](/hi/help/settings/audio-settings/)। |
| स्क्रीनशॉट | [सक्रिय-विंडो बनाम फ़ुल-स्क्रीन कैप्चर और कैप्चर-बिफोर-विश्लेषण](/hi/help/settings/screenshot-settings/)। |
| वेबकैम ट्रैकिंग | [प्रयोगात्मक उपस्थिति और टकटकी ट्रैकिंग नियंत्रण](/hi/help/settings/webcam-tracking-experimental/) जब वर्तमान निर्माण में उजागर होता है। |
| LLM प्रदाता | OpenAI, Anthropic, Claude सदस्यता, Codex सदस्यता, और कस्टम एंडपॉइंट सेटअप। |
| सत्र | स्थानीय सत्र इतिहास, प्रतिलेख, विश्लेषण, तथ्य, स्क्रीनशॉट और विलोपन। |
| गोपनीयता | स्क्रीनशॉट सुरक्षा, ऐप दृश्यता, क्लिक-थ्रू, होवर विलंब और उपयोग साझाकरण। |
| अपडेट | [स्वचालित अद्यतन प्राथमिकता](/hi/help/settings/automatic-updates/). |
| लाइसेंस | Pro लाइसेंस सक्रियण, स्थिति, और निष्क्रियकरण। |
| प्रतिक्रिया | [प्रतिक्रिया संदेश, वैकल्पिक ईमेल, और सबमिट स्थिति](/hi/help/settings/send-feedback/)। |

रिमोट टैब केवल विकास के लिए है और इसे सार्वजनिक सुविधा के रूप में प्रलेखित नहीं किया जाना चाहिए।

## सेटिंग्स प्रश्न

### लाइव सत्र से पहले मुझे कौन सी सेटिंग्स जांचनी चाहिए?

ऑडियो, LLM प्रदाता, स्क्रीनशॉट, गोपनीयता और शॉर्टकट जांचें। ये टैब कैप्चर, प्रदाता, स्क्रीन संदर्भ, दृश्यता और कमांड व्यवहार को नियंत्रित करते हैं जो लाइव वर्कफ़्लो को प्रभावित करने की सबसे अधिक संभावना है।

### क्या मुझे दस्तावेज़ बनाना चाहिए या रिमोट सेटिंग्स टैब का उपयोग करना चाहिए?

नहीं, रिमोट टैब केवल विकास के लिए है और इसे सार्वजनिक सहायता-केंद्र सुविधा के रूप में नहीं माना जाना चाहिए।
