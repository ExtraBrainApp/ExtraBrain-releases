ExtraBrain लाइव विश्लेषण के लिए आपके द्वारा चुने गए AI प्रदाता का उपयोग करता है। प्रदाता सेटअप नियंत्रित करता है कि संकेत, प्रतिलेख संदर्भ और स्क्रीनशॉट-व्युत्पन्न संदर्भ कहाँ भेजे जा सकते हैं।

![ExtraBrain ऑनबोर्डिंग में AI प्रदाता चयनकर्ता](/assets/screenshots/help/dark/onboarding-ai-provider-chooser.png)

## सार्वजनिक प्रदाता मोड

- OpenAI API कुंजी.
- Anthropic API कुंजी.
- Codex सदस्यता API कुंजी के बिना, सीधे ChatGPT प्लस या Pro का उपयोग करके।
- Claude सदस्यता API कुंजी के बिना सीधे Claude Pro या Max का उपयोग करके।
- आधार URL, API कुंजी और मॉडल नाम के साथ कस्टम OpenAI-compatible समापन बिंदु।

## सेटअप चेकलिस्ट

1. ऑनबोर्डिंग या **सेटिंग्स -> LLM प्रदाता** खोलें।
2. प्रदाता परिवार चुनें.
3. API कुंजी या सदस्यता मोड चुनें।
4. आवश्यकता पड़ने पर क्रेडेंशियल दर्ज करें।
5. कनेक्शन सत्यापित करें या दोबारा जांचें.
6. एक लघु परीक्षण विश्लेषण चलाएँ.

![LLM प्रदाता सेटिंग टैब](/assets/screenshots/help/dark/settings-llm-providers.png)

## डेटा प्रवाह

जब आप किसी क्लाउड प्रदाता से विश्लेषण के लिए ExtraBrain पूछते हैं, तो प्रासंगिक संकेत, प्रतिलेख संदर्भ, स्क्रीनशॉट-व्युत्पन्न संदर्भ और कस्टम प्रश्न उस प्रदाता को भेजे जा सकते हैं। प्रदाता बिलिंग, प्रतिधारण, कोटा और खाता नियंत्रण आपके द्वारा चुने गए प्रदाता द्वारा नियंत्रित होते हैं।

## एआई प्रदाता प्रश्न

### मुझे सबसे पहले कौन सा AI प्रदाता चुनना चाहिए?

वह प्रदाता चुनें जिस पर आप पहले से ही भरोसा करते हैं और वास्तविक सत्र से पहले सत्यापित कर सकते हैं। अधिकांश उपयोगकर्ताओं के लिए, इसका मतलब मौजूदा OpenAI, Anthropic, Claude, या Codex खाते से शुरू करना है।

### क्या मैं एक से अधिक प्रदाता पथ तैयार रख सकता हूँ?

हाँ। साक्षात्कार या बैठकों से पहले बैकअप प्रदाता पथ रखना उपयोगी होता है जहां कोटा, नेटवर्क पहुंच या खाता स्थिति बदल सकती है।
