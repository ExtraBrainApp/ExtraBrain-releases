ExtraBrain OpenAI API कुंजी मोड और Codex सदस्यता मोड का समर्थन करता है।

## OpenAI API कुंजी मोड

इस मोड का उपयोग तब करें जब आप चाहते हैं कि ExtraBrain आपके द्वारा प्रबंधित API कुंजी के माध्यम से OpenAI को कॉल करे।

1. **सेटिंग्स -> LLM प्रदाता** खोलें।
2. **OpenAI** चुनें।
3. अपनी API कुंजी चिपकाएँ।
4. उपलब्ध होने पर मॉडल और तर्क प्रयास चुनें।
5. कुंजी सत्यापित करें.
6. OpenAI से आने वाली प्रतिक्रियाओं की पुष्टि करने के लिए एक संक्षिप्त विश्लेषण चलाएँ।

![OpenAI प्रदाता फॉर्म ऑनबोर्डिंग में](/assets/screenshots/help/dark/onboarding-openai-provider-form.png)

## Codex सदस्यता मोड

जब आप चाहते हैं कि ExtraBrain सीधे आपके ChatGPT प्लस या Pro सदस्यता का उपयोग करे तो Codex सदस्यता का उपयोग करें। इस मोड को ExtraBrain में API कुंजी की आवश्यकता नहीं है।

1. **सेटिंग्स -> LLM प्रदाता** खोलें।
2. **Codex सदस्यता** चुनें।
3. साइन-इन स्थिति दोबारा जांचें.
4. उपलब्ध मॉडल चुनें.
5. एक परीक्षण विश्लेषण चलाएँ.

## समस्या निवारण

यदि सत्यापन विफल हो जाता है, तो जांचें कि कुंजी चालू है, आपके द्वारा चुने गए मॉडल तक पहुंच है, और प्रॉक्सी या संगठन नीति द्वारा अवरुद्ध नहीं है। सदस्यता मोड के लिए, पुष्टि करें कि डेस्कटॉप वातावरण साइन-इन प्रदाता टूलिंग तक पहुंच सकता है।

## OpenAI और Codex प्रश्न

### क्या मुझे Codex सदस्यता मोड के लिए OpenAI API कुंजी की आवश्यकता है?

नहीं, Codex सदस्यता मोड सीधे ChatGPT प्लस या Pro सदस्यता एक्सेस का उपयोग करता है और ExtraBrain में OpenAI API कुंजी की आवश्यकता नहीं होती है।

### ExtraBrain OpenAI या Codex को क्या भेज सकता है?

विश्लेषण के लिए चुने जाने पर, ExtraBrain प्रतिक्रिया के लिए आवश्यक संकेत, प्रतिलेख संदर्भ, स्क्रीनशॉट-व्युत्पन्न संदर्भ और कस्टम प्रश्न भेज सकता है।
