ExtraBrain Anthropic API कुंजी मोड और Claude सदस्यता मोड का समर्थन करता है।

## Anthropic API कुंजी मोड

इस मोड का उपयोग तब करें जब आप चाहते हैं कि ExtraBrain आपके द्वारा प्रबंधित API कुंजी के माध्यम से Anthropic को कॉल करे।

1. **सेटिंग्स -> LLM प्रदाता** खोलें।
2. **Anthropic** चुनें।
3. अपनी Anthropic API कुंजी चिपकाएँ।
4. मॉडल चुनें.
5. कुंजी सत्यापित करें.
6. एक लघु परीक्षण विश्लेषण चलाएँ.

![LLM प्रदाता सेटिंग टैब Anthropic चयनित के साथ](/assets/screenshots/help/dark/settings-llm-providers.png)

## Claude सदस्यता मोड

जब आप चाहते हैं कि ExtraBrain आपकी Claude Pro या Max सदस्यता का सीधे उपयोग करे तो Claude सदस्यता का उपयोग करें। इस मोड को ExtraBrain में API कुंजी की आवश्यकता नहीं है।

1. **सेटिंग्स -> LLM प्रदाता** खोलें।
2. **Claude सदस्यता** चुनें।
3. साइन-इन स्थिति दोबारा जांचें.
4. उपलब्ध मॉडल चुनें.
5. एक परीक्षण विश्लेषण चलाएँ.

## समस्या निवारण

यदि सत्यापन विफल हो जाता है, तो पुष्टि करें कि API कुंजी सही Anthropic खाते से संबंधित है, इसमें मॉडल पहुंच है, और अतिरिक्त रिक्त स्थान के बिना चिपकाया गया है। सदस्यता मोड के लिए, पुष्टि करें कि आपकी Claude सदस्यता सक्रिय है और वहां साइन इन है जहां ExtraBrain इसकी अपेक्षा करता है।

## Anthropic और Claude प्रश्न

### क्या मुझे Claude सदस्यता मोड के लिए Anthropic API कुंजी की आवश्यकता है?

नहीं, Claude सदस्यता मोड Claude Pro या अधिकतम सदस्यता पहुंच के लिए है और इसके लिए ExtraBrain के अंदर Anthropic API कुंजी की आवश्यकता नहीं है।

### Anthropic या Claude पर कौन सा डेटा भेजा जा सकता है?

विश्लेषण के लिए चुने जाने पर, प्रासंगिक संकेत, प्रतिलेख संदर्भ, स्क्रीनशॉट-व्युत्पन्न संदर्भ और कस्टम प्रश्न उस प्रदाता मोड के अनुसार Anthropic या Claude पर भेजे जा सकते हैं।
