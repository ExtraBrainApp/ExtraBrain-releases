जब आपका प्रदाता या प्रॉक्सी OpenAI-शैली API को उजागर करता है तो कस्टम OpenAI-compatible एंडपॉइंट का उपयोग करें।

![ExtraBrain कस्टम OpenAI-compatible प्रदाता सेटिंग्स बेस यूआरएल और मॉडल नाम फ़ील्ड के साथ](/assets/screenshots/help/dark/settings-custom-provider.png)

## आवश्यक फील्ड्स

| मैदान | क्या दर्ज करें |
| --- | --- |
| आधार यूआरएल | प्रदाता या प्रॉक्सी API आधार URL। |
| API कुंजी | उस समापन बिंदु के लिए आवश्यक कुंजी. |
| मॉडल नाम | समापन बिंदु जिस सटीक मॉडल पहचानकर्ता की अपेक्षा करता है। |

## सेटअप चरण

1. ऑनबोर्डिंग या **सेटिंग्स -> LLM प्रदाता** खोलें।
2. कस्टम प्रदाता विकल्प चुनें.
3. आधार यूआरएल दर्ज करें.
4. API कुंजी दर्ज करें.
5. मॉडल का नाम दर्ज करें.
6. कॉन्फ़िगरेशन सत्यापित करें.
7. एक लघु परीक्षण विश्लेषण चलाएँ.

## सामान्य गलतियां

- जब प्रदाता इसकी अपेक्षा करता है तो `/v1` गुम हो जाता है।
- API मॉडल पहचानकर्ता के बजाय मॉडल डिस्प्ले नाम का उपयोग करना।
- गलत प्रदाता या प्रॉक्सी के लिए कुंजी चिपकाना।
- यह भूल जाना कि प्रदाता प्रतिधारण, बिलिंग और एक्सेस नियम कस्टम एंडपॉइंट ऑपरेटर द्वारा नियंत्रित किए जाते हैं।

कस्टम प्रदाता अनुरोधों में संकेत, प्रतिलेख संदर्भ, स्क्रीनशॉट-व्युत्पन्न संदर्भ और कस्टम प्रश्न शामिल हो सकते हैं।

## कस्टम समापन बिंदु प्रश्न

### समापनबिंदु OpenAI-compatible क्या बनाता है?

एंडपॉइंट को आपके द्वारा ExtraBrain में दर्ज किए गए बेस यूआरएल, कुंजी और मॉडल नाम का उपयोग करके चैट या प्रतिक्रियाओं के लिए OpenAI-शैली API अनुरोध स्वीकार करना चाहिए।

### कस्टम एंडपॉइंट सहेजने के बाद मुझे क्या परीक्षण करना चाहिए?

गैर-संवेदनशील प्रतिलेख या स्क्रीनशॉट संदर्भ के साथ एक संक्षिप्त विश्लेषण चलाएँ। पुष्टि करें कि समापन बिंदु एक प्रतिक्रिया देता है और मॉडल का नाम आपके प्रदाता या प्रॉक्सी की अपेक्षा से मेल खाता है।
