Diese Datenschutzübersicht verweist auf die aktuellen detaillierten Datenschutzleitfäden und fasst die wichtigsten Unterschiede im Datenfluss zusammen.

![ExtraBrain Registerkarte „Datenschutzeinstellungen“](/assets/screenshots/help/dark/settings-privacy.png)

## Wichtige Erkenntnisse

Der Datenschutz von ExtraBrain wird durch den Datenpfad gesteuert, den Sie für Transkription, Screenshots, Eingabeaufforderungen, Modellanfragen, Anbieteranmeldeinformationen und den lokalen Sitzungsverlauf auswählen.

– Die lokale Parakeet-Transkription kann die Sprach-zu-Text-Arbeit auf dem Mac beibehalten.
- Local Gemma 4 kann AI-Eingabeaufforderungen lokal halten, wenn es installiert und mit Mac kompatibel ist.
- Externe Modellanbieter können Transkripttext, von Screenshots abgeleiteten Kontext, Eingabeaufforderungen und Notizen erhalten, wenn Sie ExtraBrain bitten, diese zu verwenden.
– Optional kann Deepgram Audio für die Cloud-Transkription empfangen, wenn Sie es konfigurieren.

- [Datenschutzkontrollen](/de/help/privacy-security/privacy-controls/)

ExtraBrain speichert Einstellungen, API-Schlüssel, lokalen Sitzungsverlauf und lokale Parakeet-Transkriptionsdaten auf Ihrem Mac. Wenn Sie einen Cloud-LLM-Anbieter verwenden, werden möglicherweise relevanter Text, Transkriptkontext, von Screenshots abgeleiteter Kontext und Eingabeaufforderungen an den von Ihnen ausgewählten Anbieter gesendet. Wenn Sie Deepgram wählen, wird das Audio zur Transkription an Deepgram gesendet. Die anonyme Nutzungsfreigabe kann deaktiviert werden.

## Datenschutz-Checkliste

– Verwenden Sie Local Parakeet, wenn die Audiotranskription auf Mac bleiben soll.
- Überprüfen Sie den von Ihnen ausgewählten LLM-Anbieter, bevor Sie vertrauliche Transkripte oder aus Screenshots abgeleitete Kontexte senden.
- Deaktivieren Sie die anonyme Nutzungsfreigabe, wenn Sie nicht möchten, dass Nutzungsdaten weitergegeben werden.
- Löschen Sie den lokalen Sitzungsverlauf, den Sie nicht mehr benötigen.
- Befolgen Sie die Richtlinien für Vorstellungsgespräche, Arbeitsplätze, Schulen und Kunden, bevor Sie KI-Unterstützung in Anspruch nehmen.

## Datenschutzfragen

### Sendet ExtraBrain alles an einen Server?

Nein. ExtraBrain speichert Einstellungen, API Schlüssel und den lokalen Sitzungsverlauf auf Ihrem Mac. Cloud-Anbieter erhalten nur dann Kontext, wenn Ihr ausgewählter Workflow Inhalte an sie sendet.

### Kann der Screenshot-Kontext mein Mac verlassen?

Ja, vom Screenshot abgeleiteter Kontext kann gesendet werden, wenn Sie einen Cloud-LLM-Anbieter um eine Analyse bitten. Nutzen Sie Datenschutzkontrollen und Anbieterauswahl entsprechend der Sitzung.
