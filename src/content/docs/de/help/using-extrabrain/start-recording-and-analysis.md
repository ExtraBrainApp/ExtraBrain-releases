Das Hauptfenster von ExtraBrain besteht aus Aufzeichnung, Transkriptkontext, Screenshots und Analyse.

![ExtraBrain Leerlauf-Hauptfenster mit Live-Steuerelementen](/assets/screenshots/help/dark/main-idle-controls.png)

## Hauptsteuerelemente

| Kontrolle | Was es tut |
| --- | --- |
| Aufnahme starten | Startet eine Live-Sitzung und beginnt mit der Aufnahme aktivierter Audioquellen. |
| Stopp | Beendet die aktive Sitzung. |
| Fragen | Sendet den aktuellen Kontext zur Analyse an den ausgewählten KI-Anbieter. |
| Erfassen | Fügt der aktiven Sitzung einen Screenshot hinzu. |
| Erweitern oder reduzieren | Schaltet zwischen kompaktem und erweitertem Fensterlayout um. |

## Grundlegender Arbeitsablauf

1. Öffnen Sie ExtraBrain, bevor der Anruf beginnt.
2. Klicken Sie auf **Aufnahme starten**.
3. Warten Sie auf Transkripteinträge oder erkannte Themenkarten.
4. Klicken Sie auf **Erfassen**, wenn der Bildschirmkontext wichtig ist.
5. Klicken Sie auf **Fragen**, um eine Analyse anzufordern.
6. Verwenden Sie Follow-ups oder geben Sie eine benutzerdefinierte Frage ein.

![ExtraBrain Aufnahme mit erkanntem Thema](/assets/screenshots/help/dark/main-recording-topic.png)

## Wenn Schaltflächen deaktiviert sind

Schaltflächen können deaktiviert werden, während ExtraBrain startet, stoppt, analysiert, den Anbieterzugriff validiert oder auf die erforderliche Berechtigung und den Sitzungsstatus wartet. Wenn eine Schaltfläche weiterhin deaktiviert bleibt, überprüfen Sie die [Fehlerbehebung](/de/help/troubleshooting/).

Überprüfen Sie vor wichtigen Sitzungen die [Audioeinstellungen](/de/help/settings/audio-settings/), [Screenshot-Einstellungen](/de/help/settings/screenshot-settings/) und [Profile](/de/help/settings/profiles/).

## Datenschutzerinnerung

Wenn Sie bei ausgewähltem Cloud-LLM-Anbieter auf **Fragen** klicken, werden möglicherweise relevanter Transkripttext, vom Screenshot abgeleiteter Kontext, Eingabeaufforderungen und benutzerdefinierte Fragen an diesen Anbieter gesendet.

## Fragen aufzeichnen

### Wann sollte ich auf „Fragen“ klicken?

Klicken Sie auf **Fragen**, wenn ein nützlicher Transkriptkontext, ein erkanntes Thema, eine erkannte Frage oder ein Screenshot verfügbar ist. Sie können auch mit minimalem Kontext um eine schnelle Eingabeaufforderung bitten.

### Was passiert, wenn ich die Aufnahme beende?

ExtraBrain beendet die aktive Sitzung. Im lokalen Sitzungsverlauf können Transkripte, Analysen, Screenshots, Fakten und Einträge gespeichert werden, es sei denn, Sie löschen die Sitzung später.
