Screenshots helfen ExtraBrain, Code, Eingabeaufforderungen, Diagramme, Folien, Terminals, Browserseiten und anderen visuellen Kontext zu verstehen.

![Screenshot-Eintrag in einem ExtraBrain-Transkript](/assets/screenshots/help/dark/main-screenshot-entry.png)

## Aufnahmemodi

Öffnen Sie **Einstellungen -> Screenshot**, um auszuwählen, wie Screenshots funktionieren.

![Registerkarte „Screenshot-Einstellungen“](/assets/screenshots/help/dark/settings-screenshot.png)

| Einstellung | Verwenden Sie es, wenn |
| --- | --- |
| Aktives Fenster | Sie möchten, dass Screenshots auf das aktuelle App-Fenster beschränkt sind. |
| Vollbild | Sie benötigen einen breiteren Desktop-Kontext. |
| Erfassung vor der Analyse | Sie möchten, dass ExtraBrain automatisch einen Screenshot erstellt, bevor die Analyse ausgeführt wird. |

## Während einer Sitzung

1. Starten Sie die Aufnahme.
2. Klicken Sie auf **Erfassen**.
3. Bestätigen Sie, dass der Screenshot-Eintrag im Transkriptfenster angezeigt wird.
4. Klicken Sie auf **Fragen**, um den aktuellen Kontext in die Analyse einzubeziehen.

Wenn kein Screenshot angezeigt wird, vergewissern Sie sich, dass die Sitzung aktiv ist und die Berechtigung zur Bildschirmaufzeichnung macOS erteilt wurde.

## Screenshots löschen

Verwenden Sie die Screenshot-Löschung, wenn Sie den falschen Kontext erfasst haben oder nicht möchten, dass ein Screenshot im lokalen Sitzungsdatensatz gespeichert wird.

## Datenfluss

Screenshots werden lokal als Sitzungsartefakte gespeichert. Wenn Sie einen Cloud-Anbieter um eine Analyse bitten, kann der aus dem Screenshot abgeleitete Kontext an den ausgewählten Anbieter gesendet werden.

## Screenshot-Fragen

### Sollte ich die Aufnahme im aktiven Fenster oder im Vollbildmodus verwenden?

Verwenden Sie die Erfassung im aktiven Fenster, wenn Sie einen engeren Kontext aus der aktuellen App wünschen. Verwenden Sie die Vollbildaufnahme nur, wenn die breitere Desktop-Ansicht für die Sitzung relevant und akzeptabel ist.

### Warum werden Screenshots nicht in der Analyse angezeigt?

Überprüfen Sie, ob die Aufzeichnung aktiv ist, die Berechtigung zur Bildschirmaufzeichnung erteilt wurde und ein Screenshot-Eintrag im Transkriptfenster angezeigt wird, bevor die Analyse beginnt.
