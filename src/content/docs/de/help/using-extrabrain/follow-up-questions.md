Nachdem ExtraBrain eine Analyse abgeschlossen hat, kann die Karte vorgeschlagene Folgefragen anzeigen. Verwenden Sie sie, um die Sitzung am Laufen zu halten, ohne den Kontext neu zu schreiben.

![Ausgefüllte Analysekarte mit Folgefragen](/assets/screenshots/help/dark/main-analysis-followups.png)

## Empfohlene Folgemaßnahmen

Vorgeschlagene Folgemaßnahmen sind Schaltflächen auf der abgeschlossenen Analysekarte. Klicken Sie auf eine, um eine verwandte Frage unter Verwendung des aktuellen Sitzungskontexts und der Quellanalyse zu stellen.

## Benutzerdefinierte Fragen

Verwenden Sie das Feld „Fragen“, wenn die vorgeschlagenen Folgemaßnahmen nicht spezifisch genug sind. Gute benutzerdefinierte Fragen sind kurz und direkt:

– „Geben Sie mir Randfälle für diese Eingabeaufforderung an.“
- „Welchen Kompromiss soll ich als nächstes erläutern?“
- „Machen Sie daraus Aktionspunkte.“
- „Was ist das Risiko bei diesem Entwurf?“

## Analyse kopieren

Verwenden Sie Kopiersteuerelemente auf einer Analysekarte, wenn Sie eine Antwort in Notizen, ein Dokument oder einen anderen lokalen Workflow verschieben müssen.

## Tastaturkürzel

Wenn Verknüpfungshinweise aktiviert sind, können Folgeverknüpfungen auf den neuesten verfügbaren Folgeschaltflächen angezeigt werden. Bearbeiten Sie Verknüpfungen unter [Tastaturkürzel](/de/help/settings/keyboard-shortcuts/).

## Folgefragen

### Wann sollte ich die empfohlenen Folgemaßnahmen nutzen?

Verwenden Sie vorgeschlagene Folgemaßnahmen, wenn die erste Analyse richtungsweisend ist und Sie Kompromisse, nächste Schritte, Randfälle oder Risiken untersuchen möchten, ohne den Kontext erneut eingeben zu müssen.

### Wann sollte ich eine benutzerdefinierte Frage eingeben?

Geben Sie eine benutzerdefinierte Frage ein, wenn die Sitzung ein bestimmtes Ziel hat, z. B. die Vorbereitung einer Antwort, die Bitte um prägnante Aufzählungszeichen oder die Konzentration auf einen Screenshot oder ein Transkriptsegment.
