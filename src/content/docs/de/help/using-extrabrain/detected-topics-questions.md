ExtraBrain kann während einer aktiven Sitzung wichtige Themen und Fragen im Transkript erkennen. Diese erscheinen als Systemkarten im Transkriptfenster.

![Themenkarte während der Aufnahme erkannt](/assets/screenshots/help/dark/main-recording-topic.png)

## Was die Karten bedeuten

| Karte | Bedeutung |
| --- | --- |
| Neues Thema | ExtraBrain hat ein Thema erkannt, das es wert ist, analysiert oder verfolgt zu werden. |
| Neue Frage | ExtraBrain hat im Gespräch eine Frage erkannt. |
| Vertrauen | Die geschätzte Stärke der Erkennung. |
| Analysieren | Startet die Analyse unter Verwendung des erkannten Themas oder der erkannten Frage als Fokus. |

## Gute Verwendungsmöglichkeiten

- Erfassen Sie eine Codierungsaufforderung, nachdem sie gesprochen wurde.
- Verfolgen Sie eine Systemdesignanforderung.
- Ziehen Sie eine Besprechungsfrage heraus.
- Bitten Sie um eine prägnante Antwort auf das aktuelle Thema.

Abhängig von Ihren Verknüpfungseinstellungen werden möglicherweise nur für das neueste Thema oder die neueste Frage Verknüpfungshinweise angezeigt.

## Fragen zur Erkennung

### Warum hat ExtraBrain ein Thema statt einer Frage erkannt?

Themen- und Fragenkarten hängen vom Kontext des Transkripts ab. Eine breite Diskussion kann zu einem neuen Thema werden, während eine direkt gestellte Frage zu einer neuen Frage werden kann.

### Was soll ich mit einer erkannten Themenkarte tun?

Verwenden Sie **Analysieren**, wenn das Thema wichtig genug ist, um den ausgewählten KI-Anbieter nach Struktur, Kompromissen, nächsten Schritten oder einer prägnanten Antwort zu fragen.
