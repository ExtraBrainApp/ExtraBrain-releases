Verwenden Sie **Einstellungen -> Allgemein**, um ExtraBrain einen stabilen Kontext über Sie bereitzustellen und die Darstellung der Analyse während einer Live-Sitzung anzupassen.

![ExtraBrain allgemeine Einstellungen mit persönlichem Kontext und Sprachsteuerung](/assets/screenshots/help/dark/settings-general.png)

## Was zu konfigurieren ist

| Einstellung | Was es ändert |
| --- | --- |
| Ihr Kontext | Hintergrund, den ExtraBrain beim Generieren von Antworten verwenden kann, z. B. Ihre Rolle, Ihre Interviewziele oder Ihren bevorzugten Kommunikationsstil. |
| Bevorzugte Sprache | Die Programmiersprache ExtraBrain sollte davon ausgehen, dass der Codierungskontext nicht eindeutig ist. |
| Fenster zur Analyse erweitern | Öffnet die erweiterte Zwei-Panel-Ansicht, wenn eine neue Analyse beginnt. |
| Nur aktuelle Analyse anzeigen | Konzentriert sich das Analysefenster auf die neueste Antwort, anstatt ältere Antworten zu stapeln. |

## Empfohlenes Setup

1. Fügen Sie einen prägnanten Kontext hinzu, damit die Antworten zu Ihrer Situation passen.
2. Wählen Sie die Programmiersprache, die Sie am häufigsten verwenden.
3. Lassen Sie **Fenster zur Analyse erweitern** aktiviert, wenn Sie möchten, dass die Antworten sofort sichtbar sind.
4. Aktivieren Sie **Nur aktuelle Analyse anzeigen**, wenn Sie einen ruhigeren Live-Workflow bevorzugen.
5. Starten Sie eine kurze Testaufzeichnung und bitten Sie um eine Analyse, um das Verhalten zu bestätigen.

Ein guter Kontext ist spezifisch, aber nicht überladen. Geben Sie beispielsweise Ihre Rolle, die Art des Zielinterviews, den Produktbereich oder Ihre Vortragspräferenz an. Vermeiden Sie das Hinzufügen von Geheimnissen, Kundendaten oder Details, die nicht in den an den von Ihnen ausgewählten KI-Anbieter gesendeten Eingabeaufforderungen enthalten sein sollen.

## Häufige Fragen

### Was soll ich in Ihren Kontext einfügen?

Verwenden Sie kurze, aussagekräftige Leitlinien: Ihre Rolle, die Art des Interviews, die bevorzugte Programmiersprache und den Antwortstil. Fügen Sie keine vertraulichen Projektdetails ein.

### Überschreibt die bevorzugte Sprache Screenshots?

Nein. Es hilft, wenn der Kontext nicht eindeutig ist. Wenn ein Screenshot oder ein Transkript deutlich eine andere Sprache zeigt, kann ExtraBrain diesen sichtbaren Kontext trotzdem verwenden.
