Verwenden Sie **Einstellungen -> UI**, um das Aussehen von ExtraBrain bei wiederholter Live-Nutzung anzupassen.

![ExtraBrain UI Einstellungen mit Steuerelementen für Aussehen und Codedesign](/assets/screenshots/help/dark/settings-ui.png)

## Aussehenskontrollen

| Kontrolle | Was es ändert |
| --- | --- |
| Schriftgröße | Textdichte in der gesamten App. |
| Deckkraft | Transparenz des Hauptfensters. |
| Voreinstellungen für das Erscheinungsbild | Fensterfarbpalette. |
| Tipps | Ob In-App-Tipps angezeigt werden. |
| Codeblock-Thema | Syntaxhervorhebungsstil für Code, der in Antworten angezeigt wird. |

## Empfohlenes Setup

1. Wählen Sie eine Schriftgröße, die Sie unter Druck schnell lesen können.
2. Halten Sie die Deckkraft hoch, wenn Sie Dokumentations-Screenshots erstellen oder maximale Lesbarkeit benötigen.
3. Wählen Sie eine Voreinstellung für das Erscheinungsbild, die für die Apps geeignet ist, die Sie am häufigsten verwenden.
4. Wählen Sie ein Codeblock-Design, das die Syntax in Ihrem aktuellen hellen oder dunklen Workflow lesbar hält.
5. Deaktivieren Sie die Tipps, sobald Sie die wichtigsten Steuerelemente kennen.

Deckkraft und Aussehen wirken sich auf die Sichtbarkeit aus. Sie ändern nicht, was ExtraBrain lokal speichert oder was während der Analyse an die von Ihnen ausgewählten Anbieter gesendet werden kann.

## Häufige Fragen

### Sollte ich die Deckkraft bei Interviews oder Besprechungen verringern?

Nur wenn es Ihnen hilft, den Kontext sichtbar zu halten. Für Lesbarkeit, Screenshots und reduziertes visuelles Rauschen ist die Deckkraft von 100% normalerweise besser.

### Beeinflusst das Codeblock-Thema die Modellantwort?

Nein. Es ändert nur die Art und Weise, wie Code in der App angezeigt wird.
