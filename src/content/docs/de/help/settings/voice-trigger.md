Mit Voice Trigger kann ExtraBrain mit der Analyse beginnen, wenn es während einer aktiven Sitzung einen kurzen konfigurierten Satz hört. Finden Sie es unter **Einstellungen -> Audio**.

![ExtraBrain Audioeinstellungen konzentrieren sich auf Sprachauslöser-Steuerelemente](/assets/screenshots/help/dark/settings-voice-trigger.png)

## Wie es funktioniert

| Detail | Verhalten |
| --- | --- |
| Nur aktive Sitzung | ExtraBrain wartet nur auf Triggerphrasen, während die Aufnahme aktiv ist. |
| Phrasenliste | Sie können die Standardphrasen verwenden oder Ihre eigenen kurzen Phrasen hinzufügen. |
| Transkriptbereinigung | Übereinstimmende Auslösephrasen werden aus dem Transkriptverlauf entfernt und von der Analyseeingabe ausgeschlossen, nachdem sie ausgelöst wurden. |
| Analyseverhalten | Die Phrase fungiert als gesprochenes Steuerelement zum Starten der Analyse. |

## Phrasentipps

- Verwenden Sie kurze Sätze, die in normalen Gesprächen wahrscheinlich nicht vorkommen.
- Vermeiden Sie gebräuchliche Wörter oder Ausdrücke, die ein Teilnehmer von Natur aus sagen würde.
- Testen Sie die Phrase in einer kurzen Sitzung, bevor Sie sich live darauf verlassen.
- Halten Sie die gleichen Erwartungen an den Datenschutz wie bei der Aufnahme: Für die Auslösererkennung muss die Mikrofonaufnahme aktiv sein.

## Häufige Fragen

### Hört Voice Trigger zu, wenn die Aufnahme gestoppt wird?

Nein. Voice Trigger hört nur während einer aktiven Sitzung zu.

### Werden Triggerphrasen im Transkript gespeichert?

Übereinstimmende Phrasen werden aus dem Transkriptverlauf entfernt und von der Analyseeingabe ausgeschlossen, nachdem sie ausgelöst wurden.
