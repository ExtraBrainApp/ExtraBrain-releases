Profile teilen ExtraBrain mit, welche Art von Live-Hilfe Priorität haben soll. Öffnen Sie **Einstellungen -> Profile**, um das automatische oder angeheftete Profilverhalten auszuwählen.

![ExtraBrain Profileinstellungen mit System- und benutzerdefinierten Profilsteuerungen](/assets/screenshots/help/dark/settings-profiles.png)

## Systemprofile

| Profil | Verwenden Sie es für |
| --- | --- |
| Assistent | Allgemeine Live-Hilfe bei gemischten Gesprächen. |
| Codierung | Fragen zur Implementierung, Debugging, Codeüberprüfung und Algorithmendiskussion. |
| Systemdesign | Architektur, Kompromisse, Skalierbarkeit, Zuverlässigkeit und Produktbeschränkungen. |
| Verhalten | Erleben Sie Geschichten, Struktur im STAR-Stil, Konflikte, Führung und Teamarbeit. |
| Treffen | Zusammenfassungen, Entscheidungen, Risiken, Folgemaßnahmen und Beiträge zu Live-Meetings. |

## Auto vs. Angepinnt

| Modus | Verhalten |
| --- | --- |
| Auto | ExtraBrain wählt basierend auf dem erkannten Kontext zwischen aktivierten Systemprofilen aus. |
| Angepinnt | ExtraBrain bleibt auf dem von Ihnen ausgewählten Profil, bis Sie es ändern. |

Der automatische Modus ist nützlich, wenn eine Sitzung zwischen Themen wechselt. Der angeheftete Modus ist besser, wenn die gesamte Sitzung ein klares Format hat, z. B. ein Coding-Interview oder eine Systemdesign-Runde.

## Profile verwalten

- Deaktivieren Sie Systemprofile, die nicht von der automatischen Erkennung verwendet werden sollen.
- Pinnen Sie ein Profil, wenn Sie einen stabilen Antwortstil wünschen.
- Wechseln Sie zwischen Profilen im Hauptfenster, wenn Sie schnell wechseln müssen.
– Verwenden Sie [benutzerdefinierte Profile](/de/help/billing-pro/custom-profiles/), wenn Pro aktiv ist und Sie über die integrierten Profile hinaus wiederverwendbare Eingabeaufforderungsanweisungen benötigen.

## Häufige Fragen

### Sollte ich den automatischen oder den angehefteten Modus verwenden?

Verwenden Sie Auto für gemischte Besprechungen und Erkundungssitzungen. Verwenden Sie „Angepinnt“, wenn das Sitzungsformat vorhersehbar ist und Sie konsistente Antworten wünschen.

### Werden benutzerdefinierte Profile im Auto-Modus verwendet?

Nein. Die automatische Erkennung verwendet Systemprofile. Benutzerdefinierte Profile werden verwendet, wenn sie ausgewählt oder angeheftet sind.
