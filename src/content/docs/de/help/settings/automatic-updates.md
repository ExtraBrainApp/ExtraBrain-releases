Verwenden Sie **Einstellungen -> Updates**, um zu steuern, ob ExtraBrain automatisch nach App-Updates sucht und diese anwendet.

![ExtraBrain aktualisiert die Einstellungen mit automatischer Update-Umschaltung](/assets/screenshots/help/dark/settings-updates.png)

## Was automatische Updates bewirken

| Kontrolle | Verhalten |
| --- | --- |
| Automatische Updates | Lässt ExtraBrain nach neueren Builds suchen und Updates im Hintergrund vorbereiten. |
| Update-Benachrichtigung | ExtraBrain benachrichtigt Sie, bevor ein Update angewendet werden muss. |

Automatische Updates tragen dazu bei, Anbieterintegrationen, Berechtigungsverwaltung und App-Korrekturen auf dem neuesten Stand zu halten. Wenn Sie sie deaktivieren, überprüfen Sie die Releases vor wichtigen Sitzungen manuell.

## Empfohlener Workflow

1. Lassen Sie automatische Updates für den normalen Gebrauch aktiviert.
2. Starten Sie neu oder starten Sie neu, wenn ExtraBrain Sie auffordert, die Anwendung eines Updates abzuschließen.
3. Öffnen Sie vor einer kritischen Sitzung ExtraBrain früh genug, damit alle ausstehenden Updates abgeschlossen werden können.

## Häufige Fragen

### Kann ich ExtraBrain verwenden, während ein Update heruntergeladen wird?

Ja. Updates werden im Hintergrund vorbereitet. Wenden Sie sie an, wenn Sie dazu aufgefordert werden und ein Neustart der App sicher ist.

### Sollte ich Updates vor einer Live-Sitzung deaktivieren?

Normalerweise nein. Öffnen Sie stattdessen ExtraBrain im Voraus und bestätigen Sie, dass es bereit ist, bevor die Sitzung beginnt.
