Verwenden Sie **Einstellungen -> Feedback**, um Produkt-Feedback, Fehlerberichte oder Support-Kontext aus ExtraBrain heraus zu senden.

![ExtraBrain Feedback-Einstellungen mit Nachrichten- und optionalen E-Mail-Feldern](/assets/screenshots/help/dark/settings-feedback.png)

## Was einzuschließen ist

| Feld | Empfehlung |
| --- | --- |
| Feedback-Nachricht | Beschreiben Sie, was passiert ist, was Sie erwartet haben und welchen Arbeitsablauf Sie verwendet haben. |
| Optionale E-Mail | Fügen Sie eine E-Mail hinzu, wenn Sie möchten, dass der Support nachfragt. |

Geben Sie bei Fehlern den Funktionsbereich, den Anbieter, den Transkriptionsmodus, den macOS-Berechtigungsstatus an und geben Sie an, ob das Problem während des Onboardings, der Aufzeichnung, der Analyse, der Screenshots oder der Einstellungen aufgetreten ist.

## Bevor Sie vertrauliche Details senden

Fügen Sie keine API-Schlüssel, private Interviewaufforderungen, Kundendaten oder vertrauliche Screenshots in das Feedback ein. Wenn der Support detailliertere Informationen benötigt, geben Sie nur den Mindestkontext weiter, der zur Reproduktion des Problems erforderlich ist.

## Häufige Fragen

### Ist eine E-Mail-Adresse erforderlich?

Nein. E-Mail ist optional, aber das Hinzufügen ermöglicht eine Nachverfolgung.

### Was macht einen nützlichen Fehlerbericht aus?

Geben Sie Schritte zur Reproduktion, erwartetes Verhalten, tatsächliches Verhalten, Provider/transcription-Einstellungen und ob das Problem nach einem Update aufgetreten ist, an.
