Beginnen Sie hier, wenn Sie ExtraBrain zum ersten Mal auf macOS einrichten. Die folgenden Leitfäden decken den kürzesten Weg vom Start bis zu einer erfolgreichen Live-Sitzung ab.

![ExtraBrain Onboarding-Begrüßungsbildschirm](/assets/screenshots/help/dark/onboarding-welcome.png)

## Wichtige Erkenntnisse

Der Einstieg in ExtraBrain ist ein 6-stufiger macOS-Einrichtungsablauf: Starten Sie die App, erteilen Sie Berechtigungen, wählen Sie die Transkription, verbinden Sie einen KI-Anbieter, überprüfen Sie die Datenschutzkontrollen und führen Sie eine kurze Probe durch.

- ExtraBrain ist heute für Mac verfügbar, einschließlich Apple Silicon und Intel Macs.
– Bei der lokalen Parakeet-Transkription bleibt der Transkriptionspfad lokal; Deepgram ist optional.
– Die Anbietereinrichtung kann OpenAI, Anthropic, Claude-Abonnement, Codex-Abonnement oder einen benutzerdefinierten OpenAI-compatible-Endpunkt verwenden.
- Bei einer ersten Probe sollten Aufnahme, Screenshots, Transkription und eine Analyse vor einem echten Interview oder Treffen getestet werden.

## Empfohlene Setup-Reihenfolge

1. Lesen Sie die Produktübersicht, wenn Sie neu bei ExtraBrain sind.
2. Schließen Sie das Onboarding ab.
3. Erteilen Sie Berechtigungen für Mikrofon, Bildschirmaufzeichnung und Systemaudio.
4. Wählen Sie Lokale Parakeet- oder Deepgram-Transkription.
5. Verbinden Sie den KI-Anbieter, den ExtraBrain für die Analyse verwenden soll.
6. Führen Sie vor einem echten Interview oder Meeting eine kurze Testsitzung durch.

## Fragen zum Einstieg

### Wie kann ich am schnellsten mit der Verwendung von ExtraBrain beginnen?

Schließen Sie das Onboarding ab, wählen Sie „Lokale Parakeet-Transkription“, verbinden Sie einen KI-Anbieter und testen Sie dann die Aufzeichnung und Analyse mit einer kurzen, nicht sensiblen Sitzung.

### Was sollte ich vor einem Live-Interview oder Meeting konfigurieren?

Bestätigen Sie Berechtigungen, Mikrofonverhalten, Transkriptionsanbieter, KI-Anbietervalidierung, Screenshot-Erfassung und die Datenschutzkontrollen, die Sie verwenden möchten.
