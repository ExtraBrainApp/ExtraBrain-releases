## Unterstützte Plattform

ExtraBrain ist heute macOS-first. Windows und Linux sind geplant, keine aktuellen Ziele für die öffentliche Veröffentlichung.

Verwenden Sie die offizielle macOS-Version, wenn Sie das in dieser Hilfe beschriebene Desktop-Overlay, Live-Aufzeichnungssteuerelemente, den lokalen Sitzungsverlauf, den Screenshot-Kontext und die Anbietereinrichtung benötigen.

![ExtraBrain Onboarding-Begrüßungsbildschirm nach der Installation](/assets/screenshots/help/dark/onboarding-welcome.png)

## Wichtige Erkenntnisse

Die ExtraBrain-Installation ist der macOS-Setup-Pfad, der die Desktop-App, Live-Aufzeichnungssteuerelemente, den lokalen Sitzungsverlauf, Screenshots, Transkription und den Zugriff auf den KI-Anbieter vor einer Live-Sitzung bereitstellt.

- ExtraBrain unterstützt heute Mac, einschließlich Apple Silicon und Intel Macs.
- Windows und Linux sind geplant, keine aktuellen Ziele für die öffentliche Veröffentlichung.
- Eine zuverlässige Ersteinrichtung umfasst 5 Prüfungen: App-Start, Mikrofonberechtigung, Bildschirmaufzeichnungsberechtigung, Transkriptionsauswahl und Anbietervalidierung.
- Für die lokale Parakeet-Transkription ist kein Deepgram-API-Schlüssel erforderlich. optional Deepgram verwendet Ihr Deepgram-Konto.

## Von GitHub Releases installieren

1. Öffnen Sie die [ExtraBrain-Downloadseite](/de/download/).
2. Laden Sie den aktuellen macOS-Build herunter.
3. Öffnen Sie das heruntergeladene Installationsprogramm oder App-Bundle.
4. Verschieben Sie die App in „Anwendungen“, wenn die Veröffentlichungsanweisungen dies erfordern.
5. Starten Sie ExtraBrain.

## Checkliste für den ersten Start

- Vollständiges Onboarding.
- Gewähren Sie Berechtigungen für Mikrofon, Bildschirmaufzeichnung und Systemaudio.
- Wählen Sie die lokale Transkription Parakeet oder Deepgram.
- Verbinden Sie OpenAI, Anthropic, Claude-Abonnement, Codex-Abonnement oder einen benutzerdefinierten OpenAI-compatible-Endpunkt.
- Führen Sie eine kurze Testsitzung durch, bevor Sie ExtraBrain in einem echten Interview oder Meeting verwenden.

Wenn macOS den Zugriff auf das Mikrofon oder den Bildschirm blockiert, öffnen Sie [Berechtigungen für macOS erteilen] (/help/getting-started/macos-permissions/) und befolgen Sie die Schritte zur Wiederherstellung der Systemeinstellungen.

:::Vorsicht
Warten Sie nicht bis fünf Minuten vor einem Vorstellungsgespräch, um die App zum ersten Mal zu installieren. Testen Sie die Freigabe, Berechtigungen, Transkription und Anbietereinrichtung lange vor der Live-Sitzung.
:::

## Fragen zur Installation

### Wo soll ich ExtraBrain herunterladen?

Verwenden Sie die offizielle [ExtraBrain-Downloadseite](/de/download/). Es verweist auf die aktuelle macOS-Version und vermeidet veraltete Builds von Drittanbietern.

### Was sollte ich nach der Installation von ExtraBrain testen?

Starten Sie eine kurze Sitzung, bestätigen Sie, dass die Transkription angezeigt wird, machen Sie einen Screenshot, führen Sie eine Analyse durch und überprüfen Sie, ob die Antwort den von Ihnen ausgewählten Anbieter verwendet.
