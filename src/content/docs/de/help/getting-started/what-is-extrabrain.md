ExtraBrain ist ein macOS-erster Live-KI-Assistent. Es hilft Ihnen zuzuhören, den Kontext zu erfassen und um strukturierte Hilfe zu bitten, während noch ein Interview, eine Besprechung oder eine technische Diskussion stattfindet.

![ExtraBrain Hauptfenster mit Live-Transkript und Analyse](/assets/screenshots/help/dark/main-analysis-followups.png)

## Wobei es hilft

Verwenden Sie ExtraBrain, um:

- Transkribieren Sie Live-Sprache von Ihrem Mikrofon und Systemaudio
- Screenshots für den Bildschirmkontext aufnehmen
- Bitten Sie den von Ihnen ausgewählten KI-Anbieter um eine Analyse
- Verwenden Sie Profile für Assistenten-, Codierungs-, Systemdesign-, Verhaltens- und Besprechungsworkflows
- Stellen Sie Folgefragen, ohne den aktuellen Sitzungskontext zu verlieren
- Überprüfen Sie den gespeicherten Sitzungsverlauf nach dem Gespräch

ExtraBrain ist kein gehosteter Meeting-Bot. Es läuft auf Ihrem Mac und nimmt nicht als Teilnehmer an Anrufen teil.

## Der Kernworkflow

1. Starten Sie die Aufnahme.
2. Lassen Sie das Transkript und die erkannten Themen aufbauen.
3. Machen Sie einen Screenshot, wenn der Bildschirm wichtig ist.
4. Bitten Sie ExtraBrain um eine Analyse.
5. Nutzen Sie vorgeschlagene Folgemaßnahmen oder geben Sie Ihre eigene Frage ein.
6. Überprüfen Sie den gespeicherten Sitzungsverlauf später, wenn Sie den Kontext erneut aufrufen müssen.

## ExtraBrain Fragen

### Ist ExtraBrain ein Meeting-Bot?

Nein. ExtraBrain ist eine Mac Desktop-App. Es nimmt nicht als Teilnehmer an einer Besprechung teil und funktioniert über lokale App-Steuerung, Transkription, Screenshots und den von Ihnen ausgewählten KI-Anbieter.

### Was unterscheidet ExtraBrain von einem Web-Chat-Tool?

ExtraBrain ist für den Live-Desktop-Kontext konzipiert. Es kann Transkriptkontext, von Screenshots abgeleiteten Kontext, Profile, Folgefragen, Verknüpfungen und den lokalen Sitzungsverlauf kombinieren, während Sie im aktuellen Workflow bleiben.
