Benutzerdefinierte Profile sind eine Pro-Funktion zum Speichern wiederverwendbarer Eingabeaufforderungsanweisungen. Verwenden Sie sie, wenn ein integriertes Profil in der Nähe ist, Sie aber ein spezifischeres Verhalten wünschen. ExtraBrain Pro ist $9.99/month ($6.99 Gründer), $79/year oder $149 Lifetime, mit Kauf und Aktivierung in **Einstellungen -> Lizenz**.

![ExtraBrain Profileinstellungen konzentrieren sich auf benutzerdefinierte Profil-Pro-Steuerelemente](/assets/screenshots/help/dark/settings-custom-profiles.png)

## Was ein benutzerdefiniertes Profil beinhaltet

| Feld oder Kontrolle | Zweck |
| --- | --- |
| Name | Kurze Bezeichnung, die in der Profilliste und der Profilauswahl angezeigt wird. |
| Beschreibung | Erinnerung daran, wann das Profil verwendet werden soll. |
| Aufforderung | Detaillierte Anleitung, wie ExtraBrain analysieren und reagieren sollte. |
| Aktiviert | Steuert, ob das benutzerdefinierte Profil verfügbar ist. |
| Pin | Macht das Profil zum aktiven angehefteten Profil. |
| Löschen | Entfernt das benutzerdefinierte Profil aus den lokalen Einstellungen. |

## Profileinstellungen

Benutzerdefinierte Profile können auch das Workflow-Verhalten steuern:

| Einstellung | Verhalten |
| --- | --- |
| Fenster zur Analyse erweitern | Öffnet das erweiterte Fenster, wenn das Profil mit der Analyse beginnt. |
| Analyse nach Regions-Screenshot starten | Führt die Analyse unmittelbar nach einer Regionserfassung durch. |
| Vollständigen Sitzungskontext verwenden | Gibt jeder Analyse mehr Sitzungsverlauf, wenn dieses Profil aktiv ist. |

## Einrichtungsschritte

1. [ExtraBrain Pro aktivieren](/de/help/billing-pro/activate-license/).
2. Öffnen Sie **Einstellungen -> Profile**.
3. Wählen Sie **Profil erstellen**.
4. Fügen Sie einen Namen, eine Beschreibung und eine Eingabeaufforderung hinzu.
5. Profileinstellungen konfigurieren.
6. Pinnen Sie das Profil an, wenn Sie möchten, dass es standardmäßig aktiv ist.

Benutzerdefinierter Profiltext wird in den lokalen Einstellungen gespeichert. Wenn Sie eine Cloud-Anbieter-Analyse durchführen, werden möglicherweise relevante Eingabeaufforderungen, Transkriptkontext, aus Screenshots abgeleiteter Kontext und Fragen an den von Ihnen ausgewählten Anbieter gesendet.

## Häufige Fragen

### Kann ich benutzerdefinierte Profile ohne Pro erstellen?

Nein. Kostenlose Benutzer können die integrierten Systemprofile verwenden. Für das Erstellen und Bearbeiten benutzerdefinierter Profile ist Pro erforderlich.

### Was sollte ich in eine Eingabeaufforderung für ein benutzerdefiniertes Profil eingeben?

Beschreiben Sie den Reaktionsstil, die Einschränkungen und die Prioritäten, denen ExtraBrain folgen soll. Halten Sie es wiederverwendbar und vermeiden Sie Geheimnisse.
