Öffnen Sie **Einstellungen -> Lizenz**, um ExtraBrain Pro zu kaufen, zu aktivieren oder zu verwalten. Pro ist $9.99/month regulär ($6.99/month Founder-Preis für Erstbenutzer), $79/year oder $149 Lifetime (Einführungspreis).

![ExtraBrain Registerkarte „Lizenzeinstellungen“](/assets/screenshots/help/dark/settings-license.png)

## Kaufen oder aktivieren Sie eine Lizenz

1. Öffnen Sie **Einstellungen -> Lizenz**.
2. Wählen Sie die monatliche oder lebenslange Pro-Option, wenn Sie noch einen Kauf tätigen müssen.
3. Fügen Sie Ihren Lizenzschlüssel ein, falls Sie bereits einen haben.
4. Klicken Sie auf **Aktivieren**.
5. Warten Sie auf die Bestätigung.
6. Bestätigen Sie, dass der Status Pro angezeigt wird.

Verwenden Sie den genauen Lizenzschlüssel aus Ihrer Kauf- oder Konto-E-Mail. Vermeiden Sie das Einfügen von Leerzeichen vor oder nach dem Schlüssel und halten Sie den Schlüssel wie alle anderen Kontoanmeldeinformationen vertraulich.

## Nach der Aktivierung

Auf der Registerkarte „Lizenz“ können der Lizenzstatus und ein maskierter Schlüssel angezeigt werden. Pro kann erweiterte Workflow-Steuerelemente wie benutzerdefinierte Profile, wiederverwendbare Eingabeaufforderungsführung, profilspezifisches Verhalten, umfangreicheren Sitzungskontext, Zusammenfassungen nach der Sitzung und Premium-Modellsteuerelemente freischalten, sofern diese aktiviert sind.

Sehen Sie sich [benutzerdefinierte Profile](/de/help/billing-pro/custom-profiles/) an, wenn Sie wiederverwendbare Eingabehilfen für einen bestimmten Arbeitsablauf, Interviewstil oder Besprechungsformat benötigen.

## Deaktivieren

Verwenden Sie die Deaktivierung, wenn Sie eine Lizenz in ein anderes Setup verschieben oder Pro aus dem aktuellen Mac entfernen.

Die Nutzungskosten des Anbieters bleiben getrennt von ExtraBrain Pro. OpenAI, Anthropic, Deepgram, Claude, Codex oder benutzerdefinierte Anbieterkosten unterliegen den jeweiligen Anbietern.

## Aktivierungsfragen

### Warum wird meine ExtraBrain Pro-Lizenz nicht aktiviert?

Überprüfen Sie, ob der Schlüssel vollständig ist, ohne zusätzliche Leerzeichen eingefügt wurde und für das aktuelle ExtraBrain-Konto oder Gerät bestimmt ist. Stellen Sie außerdem sicher, dass Mac den Lizenzvalidierungsdienst erreichen kann.

### Was ändert sich nach der Aktivierung von ExtraBrain Pro?

Auf der Registerkarte „Lizenz“ sollte der Status „Aktiv Pro“ angezeigt werden. Pro kann erweiterte Workflow-Steuerelemente wie benutzerdefinierte Profile, wiederverwendbare Eingabeaufforderungsführung, profilspezifisches Verhalten, umfangreicheren Sitzungskontext, Zusammenfassungen nach der Sitzung und Premium-Modellsteuerelemente dort freischalten, wo sie in der aktuellen Version verfügbar sind.
