ExtraBrain は、インタビュー、会議、コーディング ラウンド、システム設計ディスカッション、行動インタビュー、トラブルシューティング、および密度の高い技術的な会話のための macOS 初のライブ AI アシスタントです。このヘルプセンターを使用して、アプリのセットアップ、プロバイダーの選択、プライバシーの理解、一般的な権限やプロバイダーの問題からの回復を行います。

![ExtraBrain トランスクリプトと分析パネルを備えた拡張ライブ セッション](/assets/screenshots/help/dark/main-analysis-followups.png)

## 重要なポイント

ExtraBrain は、無料のコア アプリ、オプションの Pro ワークフロー コントロール、ライブ文字起こし、スクリーンショット、プロバイダーによる分析、インストールされ互換性のあるローカル Gemma 4 オンデバイス AI、およびセッション後のレビューを備えた、ローカル ファーストの Mac デスクトップ AI インタビュー アシスタントおよび会議副操縦士です。

- ヘルプ センターを使用して、インストール、権限、文字起こし、AI プロバイダー アクセスの 4 つのセットアップ領域を移動します。
- ExtraBrain は現在、Apple Silicon および Intel Mac を含む Mac をサポートしています。
- このアプリは、ローカル NVIDIA Parakeet トランスクリプション、オプションの Deepgram、OpenAI、Anthropic、Claude サブスクリプション、Codex サブスクリプション、およびカスタム OpenAI-compatible エンドポイントをサポートしています。
- プライバシーは、選択したデータ パスによって異なります。ローカル Parakeet トランスクリプションとローカル Gemma 4 は、トランスクリプションと AI プロンプトを Mac 上に維持できますが、クラウド プロバイダーは、送信することを選択したコンテキストを受信します。

## よくある質問

### ExtraBrain はすべてをサーバーに送信しますか?

いいえ。ExtraBrain は、設定、API キー、ローカル セッション履歴、およびローカル Parakeet 転写データを Mac に保存します。クラウド LLM プロバイダーを使用すると、関連するテキスト、トランスクリプト コンテキスト、スクリーンショットから派生したコンテキスト、およびプロンプトが、選択したプロバイダーに送信される場合があります。 Deepgram を選択すると、音声は文字起こしのために Deepgram に送信されます。

### ExtraBrain は Windows または Linux をサポートしますか?

今日は ExtraBrain が macOS の最初です。 Windows と Linux は計画されており、現在の一般リリースの目標ではありません。

### [リモート設定] タブは公開されていますか?

いいえ。「リモート」タブは開発専用であり、公開機能として文書化されていません。
