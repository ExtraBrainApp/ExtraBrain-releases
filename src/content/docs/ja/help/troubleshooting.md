ExtraBrain が音声をキャプチャしていない場合、プロバイダーを検証できない場合、スクリーンショットを見逃した場合、またはライブ セッション中に回復することが難しい場合は、このページを使用してください。

![マイク、画面、システム音声アクセスのトラブルシューティングのためのExtraBrain 権限の手順](/assets/screenshots/help/dark/onboarding-permissions.png)

## 重要なポイント

ExtraBrain トラブルシューティングは、マイクの許可、画面録画の許可、システム オーディオ、プロバイダーの検証、Deepgram の検証、ウィンドウの可視性の 6 つの最も一般的なブロッカーに対する回復パスです。

- ほとんどのキャプチャの問題は macOS プライバシーとセキュリティで始まり、その後 ExtraBrain を終了して再度開く必要があります。
- プロバイダーの障害には通常、選択したモデル、API キー、サブスクリプション アクセス、ベース URL、クォータ、またはネットワーク アクセスが関係します。
- スクリーンショット分析には、アクティブなセッション、画面録画権限、および予期されるキャプチャ モードが必要です。
- アクティブなセッションは、記録が停止するまで削除できません。

## マイクの許可が必要です

マイクキャプチャが開始されない場合:

1. **[システム設定] -> [プライバシーとセキュリティ] -> [マイク]** を開きます。
2. ExtraBrain を有効にします。
3. macOS が要求した場合は、終了して ExtraBrain を再度開きます。
4. 短いテスト セッションを開始します。

[macOS 権限を付与する](/ja/help/getting-started/macos-permissions/) を参照してください。

## 画面録画またはシステム音声が機能しない

画面録画は、スクリーンショットと画面のコンテキストを制御します。システム オーディオは、サポートされている場合、会議、通話、ビデオ、または共有音声の文字起こしを制御します。

「マイクが停止しました」、「システムオーディオが停止しました」、または「オーディオが停止しました」などの警告チップがないか確認します。次に、macOS の [プライバシーとセキュリティ] 設定を再度開き、アクセスを許可し、必要に応じて ExtraBrain を再起動します。

## API キーの検証に失敗しました

OpenAI、Anthropic、またはカスタム エンドポイントの場合:

- キーが最新であることを確認します
- 余分なスペースを削除する
- 選択したモデルがアカウントで使用できることを確認します
- カスタム エンドポイントにベース URL とモデル名があることを確認します。
- プロキシまたは組織の制限を確認する

次に、**設定 -> LLM プロバイダー** で再度検証します。

## Deepgram 検証に失敗しました

Deepgram には有効な Deepgram API キーが必要です。検証が失敗した場合は、新しいキーを貼り付けるか、検証を再試行するか、オンボーディングまたは **[設定] -> [オーディオ]** からローカル Parakeet に戻ります。

## スクリーンショットが分析に表示されない

次のことを確認してください。

- セッションがアクティブです
- 画面録画の許可が与えられています
- **[設定] -> [スクリーンショット]** のキャプチャ モードが期待どおりである
- スクリーンショットのエントリがトランスクリプトパネルに表示されます

スクリーンショットはローカル セッションの成果物です。クラウド LLM プロバイダーに分析を依頼すると、スクリーンショットから派生したコンテキストが送信される場合があります。

## メインウィンドウが隠れているかクリックしにくい

オーバーレイが非表示になっている場合、またはクリックスルーによって操作が困難な場合:

1. ウィンドウの切り替えショートカットを使用します。
2. **[設定] -> [プライバシー]** でクリックスルーを無効にします。
3. 回復パスを表示する必要がある場合は、Dock またはメニュー バーの表示を再度有効にします。

## セッション履歴の削除が無効になっています

アクティブなセッションは削除できません。まず録画を停止し、**[設定] -> [セッション]** に戻ってセッションを削除します。

## トラブルシューティングの質問

### ExtraBrain が録画できない場合、まず何を確認すればよいですか?

マイクの許可、システムオーディオの許可、選択したオーディオデバイス、セッションがすでに開始されているか停止しているかを確認してください。

### 解析が失敗した場合、まず何を確認すればよいですか?

選択した AI プロバイダー、API キーまたはサブスクリプションのステータス、カスタム エンドポイント フィールド、および現在のセッションに分析するトランスクリプトまたはスクリーンショットのコンテキストがあるかどうかを確認します。
