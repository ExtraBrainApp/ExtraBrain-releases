**[設定] -> UI** を使用して、繰り返しライブで使用する際の ExtraBrain の外観を調整します。

![ExtraBrain UI 外観およびコード テーマ コントロールを含む設定](/assets/screenshots/help/dark/settings-ui.png)

## 外観コントロール

| コントロール | 何が変わるのか |
| --- | --- |
| フォントサイズ | アプリ全体のテキスト密度。 |
| 不透明度 | メインウィンドウの透明度。 |
| 外観のプリセット | ウィンドウのカラーパレット。 |
| ヒント | アプリ内ヒントが表示されるかどうか。 |
| コードブロックのテーマ | 回答に表示されるコードの構文強調表示スタイル。 |

## 推奨されるセットアップ

1. プレッシャーがかかってもすぐに読めるフォント サイズを選択してください。
2. ドキュメントのスクリーンショットを撮る場合、または最大限の可読性が必要な場合は、不透明度を高く保ちます。
3. 最もよく使用するアプリで機能する外観プリセットを選択してください。
4. 現在のライト ワークフローまたはダーク ワークフローで構文を読みやすく保つコード ブロック テーマを選択してください。
5. 主要なコントロールを理解したら、ヒントを無効にします。

不透明度と外観は視認性に影響します。 ExtraBrain がローカルに保存する内容や、分析中に選択したプロバイダーに送信される内容は変更されません。

## よくある質問

### 面接や会議中は不透明度を下げる必要がありますか?

コンテキストを可視化しておくのに役立つ場合に限ります。読みやすさ、スクリーンショット、視覚的なノイズの低減を考慮すると、通常は 100% の不透明度の方が優れています。

### コード ブロックのテーマはモデルの応答に影響しますか?

いいえ。アプリ内でのコードの表示方法のみが変更されます。
