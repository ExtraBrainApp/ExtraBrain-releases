**[設定] -> [フィードバック]** を使用して、ExtraBrain 内から製品のフィードバック、バグ レポート、またはサポート コンテキストを送信します。

![ExtraBrain メッセージおよびオプションの電子メール フィールドを含むフィードバック設定](/assets/screenshots/help/dark/settings-feedback.png)

## 含めるもの

| 分野 | おすすめ |
| --- | --- |
| フィードバックメッセージ | 何が起こったのか、何を期待していたのか、そして使用していたワークフローについて説明してください。 |
| オプションの電子メール | サポートによるフォローアップが必要な場合は、メールを追加してください。 |

バグの場合は、機能領域、プロバイダー、文字起こしモード、macOS 権限の状態、および問題がオンボーディング、記録、分析、スクリーンショット、または設定中に発生したかどうかを含めます。

## 機密情報を送信する前に

API キー、プライベートなインタビューのプロンプト、顧客データ、または機密のスクリーンショットをフィードバックに貼り付けないでください。サポートにさらに詳細な情報が必要な場合は、問題の再現に必要な最小限のコンテキストのみを共有してください。

## よくある質問

### 電子メールは必要ですか?

いいえ。電子メールはオプションですが、追加するとフォローアップが可能になります。

### 役に立つバグレポートとは何でしょうか?

再現手順、予想される動作、実際の動作、provider/transcription 設定、および問題が更新後に発生したかどうかを含めます。
