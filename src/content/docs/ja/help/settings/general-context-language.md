**[設定] -> [一般]** を使用して、ExtraBrain にあなたに関する安定したコンテキストを提供し、ライブ セッション中に分析がどのように表示されるかを調整します。

![ExtraBrain 個人的なコンテキストと言語制御を含む一般設定](/assets/screenshots/help/dark/settings-general.png)

## 設定内容

| 設定 | 何が変わるのか |
| --- | --- |
| あなたのコンテキスト | 背景 ExtraBrain は、あなたの役割、面接の目標、好みのコミュニケーション スタイルなど、回答を生成するときに使用できます。 |
| 優先言語 | プログラミング言語 ExtraBrain は、コーディングのコンテキストがあいまいな場合を想定する必要があります。 |
| 分析ウィンドウを拡大する | 新しい解析が開始されると、展開された 2 つのパネル ビューが開きます。 |
| 最新の分析のみを表示 | 分析パネルは、古い回答を積み上げるのではなく、最新の回答に焦点を当て続けます。 |

## 推奨されるセットアップ

1. 回答が状況に一致するように簡潔なコンテキストを追加します。
2. 最も頻繁に使用するコーディング言語を選択してください。
3. 回答をすぐに表示したい場合は、**分析時にウィンドウを展開** を有効にしておきます。
4. より静かなライブ ワークフローを希望する場合は、**最新の分析のみを表示** を有効にします。
5. 短いテスト記録を開始し、動作を確認するための分析を依頼します。

適切なコンテキストは具体的ですが、過負荷ではありません。たとえば、あなたの役割、対象となるインタビューの種類、製品分野、または話し方の好みなどを含めます。選択した AI プロバイダーに送信されるプロンプトに含めたくないシークレット、顧客データ、または詳細を追加しないでください。

## よくある質問

### コンテキストには何を入れるべきですか?

自分の役割、面接の種類、優先コーディング言語、応答スタイルなど、短くて永続的なガイダンスを使用します。機密のプロジェクトの詳細を貼り付けないでください。

### 優先言語はスクリーンショットを上書きしますか?

いいえ。コンテキストがあいまいな場合に役立ちます。スクリーンショットまたはトランスクリプトに別の言語が明確に示されている場合でも、ExtraBrain はその表示されたコンテキストを使用できます。
