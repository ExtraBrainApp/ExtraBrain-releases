Web カメラ トラッキングは、現在のアプリの実験的な設定タブとして表示されます。意図的にカメラベースのプレゼンスまたは顔追跡動作が必要な場合にのみ使用してください。

![ExtraBrain 実験的な Web カメラ追跡設定](/assets/screenshots/help/dark/settings-webcam-tracking.png)

## 実験的対照

| コントロール | 何をするのか |
| --- | --- |
| Webカメラ追跡を有効にする | 実験的機能をオンまたはオフにします。 |
| カメラセレクター | 複数のカメラ デバイスが利用可能な場合は、カメラ デバイスを選択します。 |
| プレビュー | 選択したカメラが使用可能なプレビューを生成しているかどうかを示します。 |
| 状態 | デバイスのアクセスと検出に応じて、アクティブ、顔なし、利用不可、または再試行の状態を示します。 |
| 設定を開くか、再試行してください | カメラの許可またはデバイスの問題から回復するのに役立ちます。 |

## プライバシーに関する注意事項

カメラへのアクセスは、マイクや画面の許可とは別のものです。この機能を有効にする前に macOS カメラの権限を確認し、カメラベースの動作が必要ない場合は無効にしてください。

この機能は実験的なものです。独自の設定でテストしていない限り、重要なワークフローでこれに依存しないでください。

## よくある質問

### ExtraBrain を使用するには Web カメラの追跡が必要ですか?

いいえ。記録、文字起こし、スクリーンショット、分析、プロファイル、セッション履歴は、Web カメラの追跡なしで機能します。

### この機能を安定版として公開するか、それとも信頼する必要がありますか?

実験的なものとして扱ってください。ローカルでテストし、ワークフローに合わない場合は無効にします。
