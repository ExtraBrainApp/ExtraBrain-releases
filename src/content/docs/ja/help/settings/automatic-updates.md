**[設定] -> [更新]** を使用して、ExtraBrain がアプリの更新を自動的に確認して適用するかどうかを制御します。

![ExtraBrain は自動更新トグルで設定を更新します](/assets/screenshots/help/dark/settings-updates.png)

## 自動更新の機能

| コントロール | 行動 |
| --- | --- |
| 自動更新 | ExtraBrain で新しいビルドをチェックし、バックグラウンドで更新を準備しましょう。 |
| 更新通知 | ExtraBrain は、更新を適用する必要がある前に通知します。 |

自動更新により、プロバイダーの統合、権限の処理、アプリの修正を最新の状態に保つことができます。無効にした場合は、重要なセッションの前にリリースを手動で確認してください。

## 推奨されるワークフロー

1. 通常の使用では自動更新を有効にしておいてください。
2. ExtraBrain が更新プログラムの適用の終了を要求したら、再起動または再起動します。
3. 重要なセッションの前に、保留中の更新が完了するのに十分な早めに ExtraBrain を開きます。

## よくある質問

### アップデートのダウンロード中に ExtraBrain を使用できますか?

はい。更新はバックグラウンドで準備されます。プロンプトが表示され、アプリを安全に再起動できるときに適用します。

### ライブセッションの前にアップデートを無効にする必要がありますか?

通常はいいえ。代わりに、事前に ExtraBrain を開いて、セッションが開始する前に準備ができていることを確認してください。
