**[設定] -> [ショートカット]** を開いて、ショートカットを表示、編集、リセットします。

![ExtraBrain ショートカット設定タブ](/assets/screenshots/help/dark/settings-shortcuts.png)

## デフォルトのショートカット

ExtraBrain は macOS ファーストであるため、以下のデフォルトではユーザーが押す Mac キーが表示されます: <kbd>⌘</kbd> コマンド、<kbd>⌥</kbd> オプション、および <kbd>⇧</kbd> シフト。

## 編集またはリセット

[ショートカット] タブを使用して、個々のショートカットを編集したり、すべてのショートカットをデフォルトにリセットしたりできます。メイン UI でコントロールの近くに利用可能なショートカットを表示する場合は、ショートカット ヒントを有効にします。

## ショートカットの質問

### メイン ウィンドウでショートカットのヒントを非表示にすることはできますか?

はい。よりクリーンなライブ インターフェイスやドキュメントのスクリーンショットが必要な場合は、**[設定] -> [ショートカット]** を開き、ショートカット ヒントをオフにします。

### 最初にどのショートカットを学べばよいでしょうか?

記録の切り替え、スクリーンショットのキャプチャ、分析の切り替え、ウィンドウの切り替え、クリックスルーの切り替えから始めます。これらのコントロールは、最も一般的なライブ セッションの回復パスをカバーします。
