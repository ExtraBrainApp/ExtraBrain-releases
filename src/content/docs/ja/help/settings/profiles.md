プロファイルは、どの種類のライブ ヘルプを優先するかを ExtraBrain に伝えます。 **[設定] -> [プロファイル]** を開いて、自動または固定プロファイルの動作を選択します。

![ExtraBrain システムおよびカスタム プロファイル コントロールを使用したプロファイル設定](/assets/screenshots/help/dark/settings-profiles.png)

## システムプロファイル

| プロフィール | 用途 |
| --- | --- |
| アシスタント | 混合会話による一般的なライブヘルプ。 |
| コーディング | 実装に関する質問、デバッグ、コードレビュー、アルゴリズムのディスカッション。 |
| システム設計 | アーキテクチャ、トレードオフ、スケーラビリティ、信頼性、製品の制約。 |
| 行動的 | 経験談、STAR スタイルの構造、対立、リーダーシップ、チームワーク。 |
| ミーティング | 概要、決定事項、リスク、フォローアップ、およびライブ会議への貢献。 |

## 自動と固定

| モード | 行動 |
| --- | --- |
| 自動 | ExtraBrain は、検出されたコンテキストに基づいて、有効なシステム プロファイルの中から選択します。 |
| 固定された | ExtraBrain は、変更するまで、選択したプロファイルに残ります。 |

自動モードは、セッションがトピック間を移動する場合に便利です。固定モードは、コーディング インタビューやシステム設計ラウンドなど、セッション全体が明確な形式である場合に適しています。

## プロファイルの管理

- 自動検出で使用したくないシステム プロファイルを無効にします。
- 安定した応答スタイルが必要な場合は、プロフィールをピン留めします。
- 素早く切り替える必要がある場合は、メイン ウィンドウからプロファイルを切り替えます。
- Pro がアクティブで、組み込みプロファイルを超えた再利用可能なプロンプト ガイダンスが必要な場合は、[カスタム プロファイル](/ja/help/billing-pro/custom-profiles/) を使用します。

## よくある質問

### 自動モードまたは固定モードを使用する必要がありますか?

混合会議や調査セッションには自動を使用します。セッション形式が予測可能で、一貫した回答が必要な場合は、固定を使用します。

### カスタム プロファイルは自動モードで使用されますか?

いいえ。自動検出ではシステム プロファイルが使用されます。カスタム プロファイルは、選択または固定されたときに使用されます。
