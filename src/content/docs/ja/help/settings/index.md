ExtraBrain 設定はワークフロー領域ごとに編成されています。メイン ウィンドウから設定を開き、必要なタブを選択します。

![ExtraBrain 一般設定タブ](/assets/screenshots/help/dark/settings-general.png)

## 公開設定タブ

| タブ | 何を制御するのか |
| --- | --- |
| 一般的な | [個人的なコンテキスト、優先コーディング言語、分析の展開、および最新の分析の表示動作](/ja/help/settings/general-context-language/)。 |
| プロフィール | [アシスタント、コーディング、システム設計、動作、会議、およびカスタム プロファイルの動作](/ja/help/settings/profiles/)。 |
| UI | [フォント サイズ、不透明度、外観プリセット、ヒント、コード ブロック テーマ](/ja/help/settings/ui-appearance/)。 |
| ショートカット | 記録、スクリーンショット、分析、フォローアップ、ウィンドウ コントロール、クリックスルー、スクロール ショートカット。 |
| オーディオ | [文字起こしプロバイダー、Deepgram キー、マイク デバイス、文字起こしのクリーンアップ、および音声トリガー](/ja/help/settings/audio-settings/)。 |
| スクリーンショット | [アクティブ ウィンドウと全画面キャプチャ、分析前のキャプチャ](/ja/help/settings/screenshot-settings/)。 |
| ウェブカメラの追跡 | [実験的なプレゼンスと視線追跡コントロール](/ja/help/settings/webcam-tracking-experimental/) (現在のビルドで公開される場合)。 |
| LLM プロバイダー | OpenAI、Anthropic、Claude サブスクリプション、Codex サブスクリプション、およびカスタム エンドポイントのセットアップ。 |
| セッション | ローカル セッションの履歴、トランスクリプト、分析、事実、スクリーンショット、削除。 |
| プライバシー | スクリーンショット保護、アプリの可視性、クリックスルー、ホバー遅延、使用状況の共有。 |
| アップデート | [自動更新設定](/ja/help/settings/automatic-updates/)。 |
| ライセンス | Pro ライセンスのアクティブ化、ステータス、および非アクティブ化。 |
| フィードバック | [フィードバック メッセージ、オプションの電子メール、送信ステータス](/ja/help/settings/send-feedback/)。 |

「リモート」タブは開発専用であり、公開機能として文書化すべきではありません。

## 設定に関する質問

### ライブセッションの前にどの設定を確認する必要がありますか?

オーディオ、LLM プロバイダー、スクリーンショット、プライバシー、およびショートカットを確認します。これらのタブは、ライブ ワークフローに影響を与える可能性が最も高いキャプチャ、プロバイダー、画面コンテキスト、可視性、およびコマンド動作を制御します。

### [リモート設定] タブを文書化するか、使用する必要がありますか?

いいえ。[リモート] タブは開発専用であり、公開ヘルプセンター機能として扱うべきではありません。
