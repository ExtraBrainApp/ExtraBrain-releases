スクリーンショットは、ExtraBrain がコード、プロンプト、図、スライド、端末、ブラウザ ページ、その他の視覚的なコンテキストを理解するのに役立ちます。

![ExtraBrain トランスクリプト内のスクリーンショット エントリ](/assets/screenshots/help/dark/main-screenshot-entry.png)

## キャプチャモード

**[設定] -> [スクリーンショット]** を開いて、スクリーンショットの動作を選択します。

![スクリーンショット設定タブ](/assets/screenshots/help/dark/settings-screenshot.png)

| 設定 | いつ使用するか |
| --- | --- |
| アクティブウィンドウ | 現在のアプリ ウィンドウを範囲とするスクリーンショットが必要です。 |
| 全画面表示 | より広範なデスクトップ コンテキストが必要です。 |
| 分析前のキャプチャ | 分析を実行する前に、ExtraBrain でスクリーンショットを自動的にキャプチャしたいと考えています。 |

## セッション中

1. 録音を開始します。
2. [**キャプチャ**] をクリックします。
3. スクリーンショットのエントリがトランスクリプトパネルに表示されることを確認します。
4. [**質問**] をクリックして、現在のコンテキストを分析に含めます。

スクリーンショットが表示されない場合は、セッションがアクティブであり、macOS 画面録画権限が付与されていることを確認してください。

## スクリーンショットの削除

間違ったコンテキストをキャプチャした場合、またはスクリーンショットをローカル セッション レコードに保存したくない場合は、スクリーンショットの削除を使用します。

## データフロー

スクリーンショットはセッション アーティファクトとしてローカルに保存されます。クラウド プロバイダーに分析を依頼すると、スクリーンショットから派生したコンテキストが選択したプロバイダーに送信される場合があります。

## スクリーンショットに関する質問

### アクティブ ウィンドウまたは全画面キャプチャを使用する必要がありますか?

現在のアプリからより狭いコンテキストが必要な場合は、アクティブ ウィンドウ キャプチャを使用します。全画面キャプチャは、より広範なデスクトップ ビューがセッションに関連し、許容される場合にのみ使用してください。

### スクリーンショットが分析に表示されないのはなぜですか?

分析が開始される前に、記録がアクティブであること、画面記録の許可が付与されていること、およびスクリーンショット エントリがトランスクリプト パネルに表示されていることを確認してください。
