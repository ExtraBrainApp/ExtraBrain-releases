ExtraBrain は、セッションのアクティブ中にトランスクリプト内の注目すべきトピックと質問を検出できます。これらはトランスクリプト パネルにシステム カードとして表示されます。

![記録中にトピック カードが検出されました](/assets/screenshots/help/dark/main-recording-topic.png)

## カードの意味

| カード | 意味 |
| --- | --- |
| 新しいトピック | ExtraBrain は、分析または追跡する価値のあるトピックを検出しました。 |
| 新しい質問 | ExtraBrain が会話中に質問を検出しました。 |
| 自信 | 検出の推定強度。 |
| 分析する | 検出されたトピックまたは質問を焦点として使用して分析を開始します。 |

## 良い使い方

- コーディングプロンプトが話された後にそれをキャプチャします。
- システム設計要件を追跡します。
- 会議の質問を引き出します。
- 最新のトピックについて簡潔な回答を求めます。

ショートカットの設定によっては、最新のトピックまたは質問のみにショートカット ヒントが表示される場合があります。

## 検出の質問

### ExtraBrain が質問ではなくトピックを検出したのはなぜですか?

トピックと質問カードはトランスクリプトのコンテキストによって異なります。広範な議論は新しいトピックになる可能性がありますが、直接口頭での質問は新しい質問になる場合があります。

### 検出されたトピック カードはどうすればよいですか?

選択した AI プロバイダーに構造、トレードオフ、次のステップ、または簡潔な回答を求めるほどトピックが重要である場合は、**分析** を使用します。
