メインの ExtraBrain ウィンドウは、記録、トランスクリプトのコンテキスト、スクリーンショット、分析を中心に構築されています。

![ExtraBrain ライブ コントロールを備えたアイドル状態のメイン ウィンドウ](/assets/screenshots/help/dark/main-idle-controls.png)

## メインコントロール

| コントロール | 何をするのか |
| --- | --- |
| 録音を開始する | ライブ セッションを開始し、有効なオーディオ ソースのキャプチャを開始します。 |
| 停止 | アクティブなセッションを終了します。 |
| 聞く | 現在のコンテキストを分析のために選択した AI プロバイダーに送信します。 |
| 捕獲 | アクティブなセッションにスクリーンショットを追加します。 |
| 展開または折りたたむ | コンパクトなウィンドウ レイアウトと拡張されたウィンドウ レイアウトを切り替えます。 |

## 基本的なワークフロー

1. 通話が始まる前に ExtraBrain を開きます。
2. [**記録の開始**] をクリックします。
3. トランスクリプト エントリまたは検出されたトピック カードを待ちます。
4. 画面のコンテキストが重要な場合は、[**キャプチャ**] をクリックします。
5. [**質問**] をクリックして分析をリクエストします。
6. フォローアップを使用するか、カスタムの質問を入力します。

![ExtraBrain 検出されたトピックを記録しています](/assets/screenshots/help/dark/main-recording-topic.png)

## ボタンが無効になっている場合

ExtraBrain が開始、停止、分析、プロバイダー アクセスの検証中、または必要な許可とセッション状態を待機している間、ボタンを無効にすることができます。ボタンが無効なままの場合は、[トラブルシューティング](/ja/help/troubleshooting/) を確認してください。

重要なセッションの前に、[オーディオ設定](/ja/help/settings/audio-settings/)、[スクリーンショット設定](/ja/help/settings/screenshot-settings/)、および [プロファイル](/ja/help/settings/profiles/) を確認してください。

## プライバシーリマインダー

クラウド LLM プロバイダーを選択して [**質問**] をクリックすると、関連するトランスクリプト テキスト、スクリーンショットから派生したコンテキスト、プロンプト、およびカスタムの質問がそのプロバイダーに送信される場合があります。

## 質問を録音する

### どのような場合に「質問」をクリックすればよいですか?

有用なトランスクリプトのコンテキスト、検出されたトピック、検出された質問、またはスクリーンショットが利用可能になったら、[**質問**] をクリックします。最小限のコンテキストで簡単なプロンプトを求めることもできます。

### 録音を停止するとどうなりますか?

ExtraBrain はアクティブなセッションを終了します。ローカル セッション履歴には、後でそのセッションを削除しない限り、トランスクリプト、分析、スクリーンショット、事実、エントリが保存されます。
