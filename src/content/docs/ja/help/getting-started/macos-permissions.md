ExtraBrain がライブオーディオと画面コンテキストを使用するには、macOS 権限が必要です。これらをオンボーディング中、または macOS システム設定から付与します。

![オンボーディング中のExtraBrain権限ステップ](/assets/screenshots/help/dark/onboarding-permissions.png)

## ExtraBrain が使用する権限

| 許可 | ExtraBrain がそれを使用する理由 |
| --- | --- |
| マイクロフォン | ライブセッション中に話した音声を文字に起こします。 |
| 画面録画 | ExtraBrain に分析を依頼したスクリーンショットと画面コンテキストをキャプチャします。 |
| システムオーディオ | セッションでシステム サウンドが必要な場合に、会議、通話、またはビデオの音声をキャプチャします。 |

## macOS 設定を開く

1. **システム設定**を開きます。
2. **プライバシーとセキュリティ**に移動します。
3. **マイク**、**画面録画**、およびシステム オーディオ関連のプロンプトが macOS に表示される場合は、それらを確認してください。
4. ExtraBrain を有効にします。
5. macOS が要求した場合、またはアクセス許可の状態がすぐに更新されない場合は、ExtraBrain を再起動します。

## アクセス許可がまだブロックされているように見える場合

- 終了して、ExtraBrain を再度開きます。
- システム設定で権限のオフとオンを切り替えます。
- 画面録画が停止したままの場合は、Mac を再起動します。
- 再起動後にオンボーディングまたは設定を再度開きます。

「マイクが停止しました」、「システムオーディオが停止しました」、または「オーディオが停止しました」などのアクセス許可の警告は、ExtraBrain がキャプチャ パイプラインの一部へのアクセスを失ったため、アクセス許可またはデバイスの回復が必要であることを意味します。

## 許可に関する質問

### ExtraBrain に画面録画権限が必要なのはなぜですか?

画面録画を使用すると、ExtraBrain で分析に明示的に使用するスクリーンショットと画面コンテキストをキャプチャできます。これがないと、スクリーンショットのキャプチャや画面コンテキストのワークフローが失敗する可能性があります。

### ExtraBrain にはシステム オーディオの許可が必要なのはなぜですか?

システム オーディオは、サポートされている場合、ExtraBrain が会議、通話、ビデオ、または共有オーディオ コンテキストをキャプチャするのに役立ちます。これがないと、マイクの文字起こししか表示されない可能性があります。
