ExtraBrain は、OpenAI API キー モードと Codex サブスクリプション モードをサポートします。

## OpenAI API キーモード

このモードは、管理する API キーを介して ExtraBrain が OpenAI を呼び出す場合に使用します。

1. **[設定] -> [LLM プロバイダー]** を開きます。
2. **OpenAI** を選択します。
3. API キーを貼り付けます。
4. 可能な場合は、モデルと推論の労力を選択します。
5. キーを検証します。
6. 短い分析を実行して、OpenAI からの応答を確認します。

![オンボーディングのOpenAIプロバイダーフォーム](/assets/screenshots/help/dark/onboarding-openai-provider-form.png)

## Codex サブスクリプション モード

ExtraBrain が ChatGPT Plus または Pro サブスクリプションを直接使用する場合は、Codex サブスクリプションを使用します。このモードでは、ExtraBrain の API キーは必要ありません。

1. **[設定] -> [LLM プロバイダー]** を開きます。
2. **Codex サブスクリプション** を選択します。
3. サインイン状態を再確認します。
4. 利用可能なモデルを選択してください。
5. テスト分析を実行します。

## トラブルシューティング

検証が失敗した場合は、キーが最新であること、選択したモデルにアクセスできること、プロキシまたは組織のポリシーによってブロックされていないことを確認してください。サブスクリプション モードの場合、デスクトップ環境がサインインしたプロバイダー ツールにアクセスできることを確認します。

## OpenAI および Codex の質問

### Codex サブスクリプション モードには OpenAI API キーが必要ですか?

いいえ。Codex サブスクリプション モードは、ChatGPT Plus または Pro サブスクリプション アクセスを直接使用し、ExtraBrain の OpenAI API キーを必要としません。

### ExtraBrain は OpenAI または Codex に何を送信できますか?

分析用に選択されると、ExtraBrain はプロンプト、トランスクリプトのコンテキスト、スクリーンショットから派生したコンテキスト、および応答に必要なカスタムの質問を送信することがあります。
