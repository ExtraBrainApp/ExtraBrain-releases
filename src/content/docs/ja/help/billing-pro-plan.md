ExtraBrain のコア Mac アプリは、プロバイダーの請求とは別に使用できます。外部プロバイダーの使用コストは、OpenAI、Anthropic、Deepgram、Claude、Codex、カスタム エンドポイントなど、選択したプロバイダーによって決まります。

![ExtraBrain ライセンス設定タブ](/assets/screenshots/help/dark/settings-license.png)

## 重要なポイント

ExtraBrain の請求では、Mac アプリのワークフローが外部モデルおよびトランスクリプション アカウントから分離されるため、アプリのアクセス、Pro 機能、プロバイダーの使用状況は別個のコスト カテゴリとして検討する必要があります。

- コア Mac ワークフローは無料で使用できます。
- ExtraBrain Pro は、$9.99/month 通常 (初期ユーザー向けの $6.99/month ファウンダー価格)、$79/year、または $149 ライフタイム (開始価格) です。
- 購入、アクティベーション、ステータス、およびアクティベーション解除は、アプリ内の **[設定] -> [ライセンス]** で処理されます。
- プロバイダーのコストは、OpenAI、Anthropic、Deepgram、Claude、Codex、または接続するカスタム エンドポイントによって制御されます。
- Pro は、カスタム プロファイル、再利用可能なプロンプト ガイダンス、より豊富なセッション コンテキスト、概要、有効な場合のプレミアム コントロールなどのワークフロー コントロール用です。
- Pro をアクティブ化しても、プロバイダーの保持、ロギング、クォータ、および請求は自動的に変更されません。

## 無料のコア製品

無料のコア ワークフローには、デスクトップ アプリ、ローカル セッション フロー、BYO プロバイダーのセットアップ、ローカル Parakeet トランスクリプション、スクリーンショット、および基本的なライブ分析コントロールが含まれます。これは、独自のプロバイダー アクセスを使用し、ExtraBrain 自体をモデルの請求から分離したい場合に適切なパスです。

## プロバイダーのコスト

プロバイダーへの請求は ExtraBrain とは別のものです。クラウド LLM プロバイダーを使用すると、選択したプロンプト、トランスクリプト コンテキスト、スクリーンショットから派生したコンテキスト、およびカスタムの質問がそのプロバイダーに送信される場合があります。 Deepgram を使用すると、音声は文字起こしのために Deepgram に送信されます。

## Pro

Pro は、$9.99/month ($6.99 創設者)、$79/year、または $149 の有効期間です。 Pro は、カスタム プロファイル、再利用可能なプロンプト ガイダンス、プロファイル固有の動作、より豊富なセッション コンテキスト、セッション後のサマリー、有効になっている場合はプレミアム モデル コントロールなどのワークフロー機能をロック解除できます。 Pro は、ExtraBrain の動作をより詳細に制御しながら、繰り返し可能なインタビュー、会議、分析のワークフローを必要とするユーザー向けです。

Pro を購入、アクティブ化、ステータスの表示、または非アクティブ化するには、アプリで **[設定] -> [ライセンス]** を開きます。ライセンスのセットアップには [Activate ExtraBrain Pro](/ja/help/billing-pro/activate-license/) を使用するか、[ExtraBrain Free と Pro](/ja/pricing/free-vs-pro/) を比較してください。

## コストチェックリスト

- ExtraBrain アプリのアクセスとプロバイダーの使用は別のものです。
- ローカル Parakeet 転写には Deepgram API キーは必要ありません。
- Deepgram の使用は、Deepgram アカウントによって制御されます。
- OpenAI、Anthropic、Claude、Codex、およびカスタム エンドポイントの使用は、これらのプロバイダーによって制御されます。
- Pro は ExtraBrain ワークフロー機能のロックを解除します。プロバイダーの保持や請求が自動的に変更されることはありません。
- Free 対 Pro の詳細は、[ExtraBrain Free vs Pro](/ja/pricing/free-vs-pro/) で公開されています。

## 請求に関する質問

### ExtraBrain Pro には AI プロバイダー クレジットが含まれていますか?

いいえ。ExtraBrain が将来の計画で明示的に別のことを指定しない限り、プロバイダーの使用は別個に行われます。使用するプロバイダー アカウントで構成されたプロバイダー クォータ、請求制限、および組織ポリシーを維持します。

### 独自の API キーを使用するには Pro が必要ですか?

いいえ。独自プロバイダーのセットアップは、コア ワークフローの一部です。 Pro は、カスタム プロファイルやプレミアム モデル コントロール (有効な場合) などの高度なワークフロー コントロール用です。
