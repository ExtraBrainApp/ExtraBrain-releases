ExtraBrain はローカル デスクトップ アプリですが、正確なデータ フローは選択したプロバイダーと機能によって異なります。

![ExtraBrain のプライバシー設定](/assets/screenshots/help/dark/settings-privacy.png)

## プライバシーに関する正確な文言

ExtraBrain は、設定、API キー、ローカル セッション履歴、およびローカル Parakeet 転写データを Mac に保存します。クラウド LLM プロバイダーを使用すると、関連するテキスト、トランスクリプト コンテキスト、スクリーンショットから派生したコンテキスト、およびプロンプトが、選択したプロバイダーに送信される場合があります。 Deepgram を選択すると、音声は文字起こしのために Deepgram に送信されます。匿名の使用状況の共有は無効にすることができます。

## Mac に残るもの

- アプリの設定
- プロバイダー設定とアプリによって保存された API キー
- ローカルセッション履歴
- ローカルセッション履歴に保存されたトランスクリプトとスクリーンショット
- ローカル Parakeet 転写データ

## Mac に何が残るのか

| 選択 | 送信される可能性のあるもの |
| --- | --- |
| OpenAI、Anthropic、Claude サブスクリプション、Codex サブスクリプション、またはカスタム LLM プロバイダー | プロンプト、トランスクリプトコンテキスト、スクリーンショットから得られたコンテキスト、カスタム質問、およびその他の選択された分析コンテキスト。 |
| Deepgram 転写 | 音声は文字起こしのために Deepgram に送信されます。 |
| 匿名での使用量の共有 | 有効時の使用状況データ。 |

## プロバイダー制御

外部プロバイダーの保持、請求、クォータ、モデル アクセス、およびアカウント ポリシーは、選択したプロバイダーによって制御されます。機密性の高いインタビュー、職場、顧客、または研究資料を扱う場合は、これらのプロバイダーの設定を確認してください。

## データ処理に関する質問

### 最もプライベートな文字起こし設定は何ですか?

音声転写を Mac に残す必要がある場合は、ローカル Parakeet を使用します。音声をクラウド文字起こしプロバイダーに送信すべきではないセッションでは、Deepgram を避けてください。

### クラウド プロバイダーの維持を管理するのは誰ですか?

選択したプロバイダーは、保持、請求、クォータ、アカウント ポリシーを制御します。機密コンテキストを送信する前に、OpenAI、Anthropic、Claude、Codex、Deepgram、またはカスタム エンドポイント設定を確認してください。
