**[設定] -> [プライバシー]** を開いて、アプリの表示設定、オーバーレイの動作、使用状況の共有を制御します。

![ExtraBrain プライバシー管理](/assets/screenshots/help/dark/settings-privacy.png)

## 利用可能なコントロール

| コントロール | 何をするのか |
| --- | --- |
| スクリーンショットの保護 | オペレーティング システムでサポートされているスクリーンショットまたはスクリーン キャプチャ コンテキストからオーバーレイを非表示にするのに役立ちます。 |
| Dock とメニュー バーから非表示にする | macOS アプリ Chrome に表示されるアプリの存在を減らします。 |
| トレイから隠す | サポートされている場合、トレイの表示を非表示にします。 |
| クリックスルーモード | クリックがオーバーレイを通過できるようにします。 |
| ホバーアクションの遅延 | クリックスルー ワークフローでホバー アクションがアクティブになるまでの待機時間を制御します。 |
| 匿名の使用状況データを共有する | ExtraBrain を改善するために使用状況データを共有するかどうかを制御します。 |

## 隠れたウィンドウまたはクリックしにくいウィンドウからの回復

ウィンドウが非表示になっている場合、またはクリックスルーによって操作が困難な場合は、次のようにします。

1. ウィンドウの切り替えショートカットを使用します。
2. アクセスできる場合は、[設定] からクリックスルーを無効にします。
3. Dock またはメニュー バーの表示が有効になっている場合は、macOS からアプリを再度開きます。

プライバシー制御は可視性とテレメトリに影響を与えます。クラウド プロバイダーの分析によって、選択したコンテキストが選択したプロバイダーに送信される可能性があるという事実は変わりません。

## プライバシー管理に関する質問

### スクリーンショット保護はプロバイダーのプライバシー設定に代わるものですか?

いいえ。スクリーンショット保護はローカルの可視性制御です。クラウド LLM プロバイダーにトランスクリプトまたはスクリーンショットから派生したコンテキストの分析を依頼したときに送信される内容は変わりません。

### デリケートなセッションの前に何をすべきですか?

オーディオをローカルに維持する必要がある場合は、ローカル Parakeet を選択し、使用する予定の AI プロバイダーを確認し、必要に応じて匿名の使用状況の共有を無効にし、保持したくないローカル セッション履歴を削除します。
