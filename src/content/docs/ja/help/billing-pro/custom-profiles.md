Custom profiles are a Pro feature for saving reusable prompt guidance. Use them when a built-in profile is close but you want more specific behavior. ExtraBrain Pro は、$9.99/month ($6.99 ファウンダー)、$79/year、または $149 の有効期間であり、**[設定] -> [ライセンス]** で購入およびアクティブ化できます。

![ExtraBrain プロファイル設定はカスタム プロファイル Pro コントロールに重点を置いています](/assets/screenshots/help/dark/settings-custom-profiles.png)

## カスタム プロファイルの内容

| フィールドまたはコントロール | 目的 |
| --- | --- |
| 名前 | プロファイル リストとプロファイル セレクターに表示される短いラベル。 |
| 説明 | プロファイルをいつ使用するかを思い出させます。 |
| プロンプト | ExtraBrain がどのように分析して対応するかについての詳細なガイダンス。 |
| 有効 | カスタム プロファイルを使用できるかどうかを制御します。 |
| ピン | プロファイルをアクティブな固定プロファイルにします。 |
| 消去 | ローカル設定からカスタム プロファイルを削除します。 |

## プロファイル設定

カスタム プロファイルは、ワークフローの動作を制御することもできます。

| 設定 | 行動 |
| --- | --- |
| 分析ウィンドウを拡大する | プロファイルの分析が開始されると、展開されたウィンドウが開きます。 |
| 領域のスクリーンショット後に分析を開始する | 領域をキャプチャした直後に分析を実行します。 |
| 完全なセッションコンテキストを使用する | そのプロファイルがアクティブな場合、各分析にさらに多くのセッション履歴が提供されます。 |

## セットアップ手順

1. [ExtraBrain Pro をアクティブ化](/ja/help/billing-pro/activate-license/)。
2. **[設定] -> [プロファイル]** を開きます。
3. [**プロファイルの作成**] を選択します。
4. 名前、説明、プロンプトを追加します。
5. プロファイル設定を構成します。
6. デフォルトでアクティブにする場合は、プロファイルをピン留めします。

カスタム プロファイル テキストはローカル設定に保存されます。クラウド プロバイダー分析を実行すると、関連するプロンプト ガイダンス、トランスクリプトのコンテキスト、スクリーンショットから得られたコンテキスト、および質問が、選択したプロバイダーに送信される場合があります。

## よくある質問

### Pro を使用せずにカスタム プロファイルを作成できますか?

いいえ。無料ユーザーは組み込みのシステム プロファイルを使用できます。カスタム プロファイルの作成と編集には Pro が必要です。

### カスタム プロファイル プロンプトには何を入力すればよいですか?

ExtraBrain が従うべき応答スタイル、制約、および優先順位を説明します。再利用できるようにし、秘密を避けてください。
